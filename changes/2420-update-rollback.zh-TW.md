- **新服務起不來的更新會再次回滾（#2420）。** 自 2.3 的安裝程式（#2264）起，重啟失敗會讓 fleet 停在新版本、帶著新的 unit，而第二次 `agend update` 也什麼都不做。現在之前的套件（含內建的 Node）、它的 systemd unit（使用者或系統）或 launchd plist，以及之前的服務都會回來，更新會說明並以 1 結束——與 2.2 的更新程式相同。在 macOS 上，新 fleet 必須真的在 launchd 下跑起來（launchd 不會等它，且會無限重啟一個一啟動就結束的 fleet），更新才算完成。回滾用的副本需要 npm prefix 所在磁碟約 235 MB 的可用空間；不足時更新會在變更任何東西之前拒絕並說明。成功的更新不受影響。
