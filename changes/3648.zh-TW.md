- **直接在聊天裡看 Agent 在做什麼（#3648）。** 登入的 admin 在網頁聊天裡，每則 Agent 回覆上方有一個區塊，列出它為了這則回覆做了什麼——做了哪些事、中途說的話和工具呼叫（開啟後也有思考）——進行中的那一輪是一行即時摘要（目前步驟 · N 個工具 · 已經過的時間），點開是步驟；回覆送出後縮成「工具歷程 · 用了 N 個工具」。由各 Agent 自己的 `tool_progress` 決定：`off` 不顯示、`standard` 每一步的摘要（不含指令參數與輸出）、`verbose` 再加上指令、參數與輸出。訪客、公開連結和唯讀 session 一律收不到——伺服器直接拒絕讀取。目前只支援 Claude Code 的 instance（Codex 維持現狀，等有真實、已遮罩的 Codex 對話紀錄證明後再開）；步驟依對話紀錄裡既有的 id 對應到回覆，靠文字或時間對應的區塊會標明。Agent 工作目錄內的路徑改以相對路徑顯示。思考（`web.log_thinking`，設定 → 網頁儀表板）是獨立的開關，**預設關閉**；關閉時 AgEnD 不會動 Claude 的設定，開啟後會在該 Agent 下次啟動時請 Claude Code 寫出思考摘要（可能改變每一輪的花費）。聊天的 ⋯ 選單有「顯示活動」與「顯示思考」，只影響這個瀏覽器。
