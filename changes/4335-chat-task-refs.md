- **Refer to a task card in an instance's web chat.** Type `#` in the chat box to pick a card from the board (by number or by words of the title); the box holds its number, `#M-3`. A `#M-3` typed by hand counts too (a bare `M-3` is just text). In the conversation a number that is a card becomes a chip with its number, title and status that opens the card, and when the message is sent the agent gets the card's number, status, title and owner under your words, with how to read it in full, in the form that instance can use (`task get M-3` with `detail: true`, or `agend-agent task get M-3 --detail` in CLI mode; an instance whose tool set has no `task` tool is told it has none). A number that is no card is just text. An instance with its task board switched off gets only your words, and the chat says which instance it is and where to turn the board on. Nothing new is stored, so older chats read as before; Telegram and Discord messages are unchanged.
