- **Annotate a chat image and quote it to the agent (#3727).** The image viewer has **Annotate**: a drawing view of the picture with a pen, boxes, arrows and text, four colours, undo, redo and clear, for a mouse, a pen or a finger. **Quote to agent** puts the marked-up picture in the message box as a new PNG attachment and starts a reply to the message it came from; in split chat it can go to the other pane instead. The original file is never changed, and the picture is drawn in the browser: nothing is sent anywhere else. ✕ or Esc closes without sending.
