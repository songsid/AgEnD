- Since Claude Code 2.1.319, AgEnD mistook the card that asks before a connector sends an ordinary-named file from your computer (for example an email attachment) for a dangerous-command prompt. It then declined the send and told the agent the command was dangerous. AgEnD now recognises the card by its own first line and leaves the choice to a person, as it already did for names that use look-alike characters. It also recognises Claude Code 2.1.322's new look-alike warning. (#3590)
