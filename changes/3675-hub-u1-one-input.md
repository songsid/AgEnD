section: Changed
---
- **Settings → Hub: connecting to a Hub needs one box.** Type the Hub's address (`hub.example.com` is enough) or paste a company link. Before you press **Sign in with company account**, the page checks the Hub and shows its name and the name this Fleet will appear under: this computer's name, which you can change with **Rename**. The Fleet name field is gone. If something is wrong, one sentence says what happened and what to do: an http address, a Hub that cannot be reached, an untrusted certificate, a server that is not a Hub, company sign-in turned off, the same host name as this Fleet, or a Hub whose identity changed. While you sign in, the Fleet card shows a countdown with **Reopen tab** and **Cancel**. It also shows when the Hub is holding the request: another pairing-code connection in progress, the Fleet limit reached, no permission, or the Hub being busy. Once you are connected, the Hub's sign-in tab closes itself. A pairing code typed in the same box opens **Other ways** with the code filled in.
- **The connection card names the Hub and its owner,** with the company account that connected it and this Fleet's name. A connection that was revoked, refused, expired or disconnected has one **Reconnect** button. It disconnects, starts over and signs in again for the same address and name; on a Hub that supports it, the old Fleet is retired in the same step, so it is not left behind as a second active Fleet. **Remove this connection** asks once and then removes the connection. On a Hub that supports it, the Fleet tells the Hub it is leaving, so the Hub stops listing it as active.
- **Set up a Hub** now comes after the connection card, and folds into one line once this Fleet is connected.
