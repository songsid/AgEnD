- **Every Claude sign-in in use is warned about before it ends (#3572).** A Claude sign-in has a fixed end date that renewing can't move. Before, only sign-ins with "Keep sign-in alive" on were warned about it. Now every Claude sign-in an agent or a ClassicBot room uses — the default one and each profile — shows in Needs you (and in General's chat) a day before its end date, and again once it has ended, with a Sign in button. The warning gives the date and time in the host's own time. Settings → Agent → AI accounts already shows each sign-in's end date.
