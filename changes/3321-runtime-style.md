section: Changed
---
- **Settings → Runtime: consistent fields, loading and commands.** The Connect a computer address, the pairing code and the Rename field now use the same rounded input as the rest of Settings. Rename has Cancel and Save at the bottom like other dialogs. While a paired computer's install setting is still loading, Install a CLI shows a loading state instead of disabled buttons with empty versions, and a failed read says so with a Retry button. The commands to run on that computer are labelled, with a Copy button. One computer or CLI is counted as "1 computer" and "1 CLI".
