section: Changed
---
- **The task board's cards are wider, calmer and show who is working.** The board and the list fill the page instead of stopping at 1240 px (in the list the title takes the extra width), and a column is 272–360 px wide however many statuses there are (more than fit scroll sideways), so a title no longer breaks onto a third line; a card is as tall as its content, with the title at two lines and one line of status at most (cut with "…", the whole text on hover). In the list the "Running" mark of a running card comes before its title. The status line now says one thing, in order: why it is stuck, whom it waits for, what is running, what is next, the sub tasks' progress. The coloured bar on the left edge is gone, in every status. The assignee's avatar on a card and in the list is now a button: it opens the same picker as the card's page and the choice saves at once (a card changed meanwhile says so); pointing at it shows the instance's state, what it is doing, how many cards it holds, whether it leads the project and who dispatched the card. Over a read-only link the avatar only shows. On a card's page, the activity is a stream: each comment (and progress note) is a card of its own, what the system did is a thin row between them (every run of them, even one line, folds into "› N activities"), and the comment box is the last card. An author's avatar there is larger and shows the same info card as the board's — pointing, the keyboard's focus or a tap — with a link to the instance's Agent page (none over a read-only link, none for a person, and an instance you cannot see has no card at all); a comment is formatted as the instance chat's window formats a message (Markdown, tables, JSON and other code blocks with Wrap and Copy, long ones folded); the "Progress" tag and filter explain themselves on hover. Tasks is dressed as Settings is: the same page head (a large title, the description under it, the actions at the right), search field, list container and cards, so the two read as one product. Layout and style only: nothing about the API, the stored data or the public link's rules changed.
