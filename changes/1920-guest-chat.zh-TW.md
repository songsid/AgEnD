---
section: Security
---
- **網頁：訪客可以和自己的 agent 聊天（#1920）。目前還沒有人能以訪客登入。**
  - **訪客能做的事：** 傳送訊息、附加檔案、點選回覆上的按鈕、按「取消」，就像在平台上該主題或房間的成員一樣，但只限訪客自己的 agent。按鈕只在訪客看得到的回覆上有效。
  - **Agent 看到的：** 訪客送的訊息和按下的按鈕，agent 看到的都是 `[user:<名稱> via web (guest), id:<對方帳號 id>]`。這和所有網頁訊息一樣只用於辨識，絕不當成已驗證的人。
  - **不能下指令：** 訪客絕不會送出指令，以 `/` 開頭的文字都會被拒絕，因此像 `/raw` 這類都送不出去。
  - **唯讀訪客：** `web.guests.chat: false` 會讓訪客只能讀。
  - **偏好與名稱：** 訪客看得到主機的外觀（主題、語言），但看不到任何提到 agent 的偏好，例如側欄順序、最愛、卡片大小、側欄小工具，頁面上也不會出現。訪客目前還不能修改偏好，但可以設定自己的網頁名稱。
