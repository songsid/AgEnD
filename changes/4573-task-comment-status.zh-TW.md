- **任務卡上的留言會顯示目前處理到哪裡，Tasks 頁也會告訴你哪些是給你的新動態（#4335）。** 寫給 agent 的留言底下，每個 agent 一行，說明進度：「已送給 dev」→「dev 已讀」→「dev 處理中…」→「dev 已回覆」（連到它的回覆）；沒有開始處理時會寫原因：agent 離線或已暫停、它的任務板是關閉的、留言被擋下（防迴圈、沒有這個 agent、關閉了留言喚醒），或這張卡已經不需要它處理；編輯了一則通知還在排隊的留言、而替換的通知沒送出時，也會寫出這個原因，而不是顯示「已撤回」。「處理中」與離線、暫停是從 agent 的狀態推論，和卡片的「執行中」標記相同；通知送到哪一步則來自傳送佇列；順利完成的狀態在一天後不再顯示，失敗的一律保留。對你本人：側欄 Fleet 那一列的數字、卡片與列表上的圓點、看板與首頁上方的提示條，以及留言上的「新」標籤，會告訴你有 agent 回覆了你的留言、提到你，或把卡片交給你確認或回答；打開卡片就算已讀。只計算未取消的卡片與最近 30 天的留言，第一次開啟頁面的人不會一開始就有一堆未讀；你讀過什麼是記在你自己的 key 底下，所以兩個名字一樣的帳號不會共用已讀狀態。唯讀的 session 看不到這些。未讀只在看板有變動或你打開卡片時才重新計算，不會因為每次送達狀態更新就重算，所以沒有動靜時開著頁面幾乎不佔 fleet 的資源。不會改寫任何資料，降版也不會遺失：`task_entries.wakes`、`task_card_reads`、`task_reads_floor` 與留言時間的索引都是新增的，舊版不會讀它們。
