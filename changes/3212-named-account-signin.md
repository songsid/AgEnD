section: Changed
---
- **Settings → Accounts: a named Claude Code account signs in like the default one (#3212).** **Sign in** on a named account used to open the older web-terminal dialog: a temporary public link, a sign-in terminal page and a one-time access code. It now opens the same dialog as the default account, titled with the account: press **Sign in**, open the provider's page, paste the returned code back. The login is written to that account's own folder and never touches the default account's; closing the dialog ends the sign-in, and **Cancel sign-in and remove** ends it too. The dialog no longer carries the first-install page's heading and lead, the **Check sign-ins** button or **Sign in later**; **Use console fallback**, which opens the older flow for the same account, is a small link at the bottom. Only the agents on that account are woken or restarted after a sign-in. Named Kiro and Codex accounts keep their existing flow.
