section: Upgrade Notes
---
- **On an existing fleet, the task board's comments and progress now wake agents; a new fleet has the task board on (#4335).** Nothing in `fleet.yaml` is rewritten, and every switch below is read at each card change, so a change applies to the next one. What a fleet gets without editing anything: (1) a comment on a card wakes its assignee, and an `@<instance name>` in a comment wakes that instance, as a `[Task board]` notice (`defaults.task_board.comment_wakes`, on; `false` brings back "a comment notifies nobody"); (2) when a card is finished, goes to review, is sent back, is blocked or changes hands, the instance that handed it out, the instances that watch it and the leader of its project are told (`defaults.task_board.progress_wakes`, on; `false` switches all of it off) — a project's lead, which until now only chose where Needs you's buttons go, is now that leader, and `defaults.task_board.leader` names one for the cards no project lead covers (none by default); (3) an agent's change to a card is told after the same 10 second gather as a person's, with no wait and no "told already" folding. Agents answering each other on a card stop waking each other after 4 turns until a person writes on it. A new `fleet.yaml` (`agend init`, `agend quickstart`, the setup page) no longer writes `defaults.dashboard.task_board: false`, so the task board is on; an existing file is never rewritten and a `false` in it stays. The only stored change is the additive `task_watchers` table; older versions ignore it.
