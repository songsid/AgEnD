- **沒有連接聊天平台的 fleet，可用 8 碼代碼讓新裝置登入（#3061）。** dashboard 自己位址上的登入頁新增「使用其他裝置登入」，會顯示代碼與五分鐘倒數。已登入且已驗證擁有者的裝置（AgEnD 電腦的管理員，或用驗證器從外面登入的人），到「設定 → 存取與安全 → 登入與授權 → 裝置與登入 → 新增裝置」，確認是哪個瀏覽器在要求後核准。核准不會把登入狀態複製給新裝置：它會建立自己的工作階段，且不含擁有者授權。代碼只能用一次、五分鐘後失效並有頻率限制；核准端輸錯代碼會暫停核准。公開連結上、有連接聊天平台的 fleet、以及網頁授權關閉時（沒有人能核准）都不提供。限流看連線本身的位址（IPv6 以 /64 計算），所以放在本機反向代理後面的裝置會共用同一個額度。
