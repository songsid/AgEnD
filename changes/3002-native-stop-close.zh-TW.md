- **停止原生 Windows agent 會真的停止它的 CLI；達到每台電腦的 agent 上限時，AgEnD 會明說並列出佔用名額的 agent。**
  - **`stop_instance` 會停止 CLI。** 以前它只會讓 AgEnD 與原生 Windows 窗格斷開：CLI 仍在那台 Windows 電腦上執行、無人監管、繼續佔用一個 agent 名額，工具卻回覆「已停止」。現在它會關閉窗格、確認 CLI 已結束，再釋放名額。若無法確認已結束，停止會失敗並說明原因，不會回覆「已停止」。
  - **上限被擋時會明說。** 因這台電腦同時執行的 agent 已達上限而被拒的訊息，現在會說出上限，並列出佔用名額的 agent（結果未知的會特別標示），不再只顯示籠統的「無法接收這則訊息」。(#3002)
