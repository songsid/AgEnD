- **`/login` 安裝缺少的 CLI 時不再卡在提問，並把輸出顯示在聊天中。** 安裝程式現在在沒有終端機可提問的環境下執行（`setsid`、stdin 來自 `/dev/null`），沒人能回答的問題（sudo 密碼、kiro 的「要取代嗎？」、codex 新增的提問）會立刻失敗並附上最後幾行，而不是讓安裝視窗卡滿 10 分鐘。安裝以較低的 CPU 與磁碟優先權執行，下載並解壓約 0.5 GB 的版本時，fleet 和各聊天仍能正常運作。關閉視窗（取消、10 分鐘逾時、fleet 停止）現在會停止整個安裝。安裝程式會拿到你帳號的登入 shell，PATH 設定因此寫進你自己終端機會讀的 rc 檔。立刻結束的安裝程式不再遺失結束代碼。發起安裝的聊天會收到一則訊息，每隔幾秒更新為安裝程式的最後 15 行（去除 ANSI、遮蔽機密），結束時顯示最終狀態：完成、失敗或逾時停止。原本「可在 View 頁面看進度」的提示指向一個從未顯示安裝的頁面，已移除。(#2980)
