- **agent 回覆裡的 `#M-3` 會變成卡片標籤，agent 也知道要這樣寫。** 在 instance 的網頁聊天裡，使用者訊息中的 `#M-3` 會變成標籤（編號、標題、狀態）並可開啟那張卡，但 agent 回覆裡同樣的 `#M-3` 只是一般文字，而且沒有任何地方告訴 agent 有這個格式，所以它會自己拼 `http://localhost:…/ui/fleet?card=M-3` 這種在別的電腦或手機上打不開的連結。現在 agent 的回覆也會為真的存在的卡顯示標籤，規則和使用者訊息相同（程式碼、連結文字、網址裡的不算；不是任務卡的編號維持文字）。每個有任務板的 agent 都會被告知一句話：回覆裡引用卡片要寫 `#M-3`，不要寫網址。MCP 模式的 agent 在 `task` 工具的說明裡看到；CLI 模式（`agent_mode: cli`）的 agent 在 CLI 指令參考的任務板指令那一段看到（任務板對它關閉時會跟著那些指令一起拿掉）；已經在跑、保留舊工具說明的 agent，會在下一則訊息前的 what's-new 通知裡被告知一次。看不到的卡（例如公開連結下隱藏 instance 的卡）仍不會出現在標籤的回應裡：編號維持文字，不會顯示標題、狀態或負責人。沒有多存任何東西，也沒有改任何設定。
