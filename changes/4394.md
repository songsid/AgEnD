- **"No project" is hard to miss on Fleet › Tasks (#4394).** When the board has projects and some live cards are in none, Home opens with "No project: N to file": the five newest, each with a picker that files it in a project at once, and "See all N". The No project tile comes first with an "N to file" badge, and each project's board header links to it ("N in No project →").
- **Fleet › Tasks on a phone is laid out for the width (#4394).** A project's board puts the way back, Instances and New main task in one row, with the name and Stats under it; the toolbar is one row ([Board | List] … Filter, Display, 🔍), and the search opens from the 🔍; the statuses are one row of pills that scrolls sideways; the cards run the full width without the column's frame. Home's title row holds Instances and New project. Every control is a 44px tap target that is not drawn bigger, and no two targets overlap. On a desktop nothing changes.
