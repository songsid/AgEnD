- **Guests see the lines between agents that the agent's topic shows (#2848).** A message one agent sends another was already posted to both agents' Discord or Telegram topics (by `cross_instance_visibility`: the whole message, one line, or nothing). A web guest now sees those same lines in the agent's chat, and nothing the topic didn't show. Lines kept from before this version stay hidden from guests. An agent whose chat a guest can't see any of now says so, instead of looking empty.
