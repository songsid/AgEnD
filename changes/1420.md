---
section: Upgrade Notes
---
- **Node.js ^22.14.0 || ^23.6.0 || >=24 is now required.** `better-sqlite3` v13 uses Node-API 10, which was added in Node 22.14.0 and 23.6.0. Earlier 22.x or 23.x releases (and all Node 20/21 releases) crash at the native DB constructor. The install script and `agend update` now reject incompatible runtimes before attempting an install. Update to Node.js 22.14.0 LTS (or 23.6.0+, or 24+) before upgrading AgEnD. The quick-start one-liner installs the current LTS via nvm.
- **`better-sqlite3` upgraded to v13 (N-API, `^13.0.3`).** The native SQLite binding now ships prebuilt N-API binaries for every supported platform inside the npm package; no separate GitHub download occurs at install time, and no compiler is needed. The prebuilds are ABI-stable across Node versions, so macOS installs no longer require Xcode Command Line Tools.
