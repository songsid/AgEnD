- **Agent 可以對網頁聊天的訊息加上 reaction（#2305）：補上各平台原本就有的最小回覆。** 只需要確認的訊息（「OK」、「謝謝」），可以在對方的泡泡下方用一個 emoji 回應，而不是回覆。
  - **即時且會保留：** 回應會立刻出現，並和聊天紀錄一起保存，所以重新整理、換一台裝置或重新啟動後都還在。訪客在自己看得到的訊息上也看得到。
  - **頻道副本：** 如果那則網頁訊息有複製到 agent 的 Discord/Telegram topic 或 ClassicBot 房間，副本也會有同樣的回應。
  - **算作答覆：** 和 Discord、Telegram 一樣，回應會完成這一輪，所以聊天不再顯示 agent 結束這一輪卻沒有回覆，AgEnD 也不會再要求補送結論。
  - **Emoji：** 使用 Telegram 的固定回應集合（所有平台同一套），且不會用 AgEnD 標示送達狀態的 emoji。其他 emoji 會被拒絕，錯誤訊息會列出可用的。
  - **說明：** agent 的指示與 `react` 工具說明寫清楚什麼時候用回應就夠了。
