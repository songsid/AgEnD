section: Fixed
---
- **Kiro instances that share a working directory no longer see each other (#906, #1410).**
  - Each kiro instance now runs as its own kiro agent, holding only its own AgEnD MCP server and its instructions.
  - It resumes its own conversation by id.
  - Two kiro instances in one directory used to start each other's AgEnD server and read each other's instructions.
    One could even come back as the other: plain `--resume` took the directory's newest conversation together with
    the agent it was saved under.
  - Your own MCP servers (global and workspace `mcp.json`) are still loaded.
  - Requires kiro-cli 2.21 or newer; an older one runs as before and says so when the instance starts.
