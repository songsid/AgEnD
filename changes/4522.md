- Install and update AgEnD on npm 12, which skips a package's install scripts unless they are allowed: the installer, `agend update`, the Hub update and install.sh now allow AgEnD's own, so the bundled Node is verified and AgEnD starts. If a plain `npm install -g` skipped them, AgEnD now says so and prints the command that works: `npm install -g --allow-scripts=@songsid/agend @songsid/agend`. An update stops before changing anything when npm is set to skip all install scripts (`ignore-scripts`).
