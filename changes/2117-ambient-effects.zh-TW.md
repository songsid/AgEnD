- **agent 的網頁聊天可以有環境效果：飄落的花瓣、雪花、上升的燈籠、閃爍的星星、點擊時散開的星星（#2117）。** agent 用 `set_web_ambient` 設定：一個預設樣式（`fall`、`rise`、`twinkle`、`burst-on-click`）、最多 4 個符號或小圖片、顏色與幾個數值。儀表板把它畫在訊息後方，也絕不攔截點擊。它只是資料，因此不需要同意，預設就會播放，臨時公開連結也一樣。每個聊天可以有一個循環效果與一個點擊效果。聊天的 ⋯ 選單會說明效果為何沒有顯示，也提供 **清除環境效果**／**清除點擊效果**。**鎖定主題**、**重設主題…**、Mod 與 General（`set_web_settings`）都能管理它。
- **設定 → 網頁外觀 → 效果：跟隨系統的「減少動態效果」設定（#2117）。** 預設關閉，所以即使系統要求減少動態效果，agent 的效果仍會播放。在這樣的裝置上，聊天會提示一次，並附 **在這裡關閉**，按下即為那台裝置勾選這個開關。
