section: Changed
---
- **設定 →「Agent 預設值」改名為「Agent 共用設定」，並說明每個設定的用途（#3065）。** 這一頁原本叫「預設值」，容易讓人以為只管新 Agent；實際上在這裡改，所有沒有自己設定的 Agent（新的、舊的）都會跟著變。現在分成兩張卡片：**Agent 共用設定**（個別 Agent 可以自己改掉：預設後端與模型、閒置自動暫停、工具進度，以及進階裡的 Agent 之間的訊息、要求送出回覆、原生回覆觸發、工具集、Agent 模式、Log 等級和 Dashboard 權限）與**系統與頻道**（整個 Fleet 一個值：語言、每日提示、專案資料夾，以及進階裡的卡住偵測和啟動設定）。
  - **誰在用這個值。** 每個共用欄位顯示「6/7 套用中 · artist 自訂」；滑過去會列出在 Agents 頁自己設定了這一項的 Agent，這裡改了不影響它們。
  - **改了才說會怎樣。** 不再常駐顯示「立即生效／重新啟動此 Agent」。改動欄位後，欄位下方才出現一行提示，依設定 schema 說明儲存後的影響：幾個 Agent 會套用新值、其中執行中的幾個會重新啟動、哪些不受影響、需要重新啟動 AgEnD，或需要 Fleet 管理員確認。改回原值提示就消失，底部儲存列會把提示彙總起來。
  - **看得懂的選項。** 工具進度、Agent 之間的訊息、Agent 模式改成分段按鈕；每日提示、要求送出回覆、原生回覆觸發改成開關；工具集和 Log 等級的每個選項都附說明。每個欄位有 ⓘ 說明用途與何時會用到。「預設後端」標示**此主機**，並用灰色說明只檢查這台主機的 CLI，Windows 電腦上的 CLI 請在個別 Agent 的設定裡選。
  - 沒有任何設定被移除：每個設定都還在，寫入同樣的 `fleet.yaml` 欄位；欄位的錨點、設定搜尋和「到 Agent 共用設定變更」連結都不變。
