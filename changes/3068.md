- Windows installer: on a network that inspects HTTPS, when Windows already trusts the intercepting root certificate, the installer shows its name, SHA-256 fingerprint and store and asks (y/N) to import only that one certificate into AgEnD's Linux. It also sets NODE_EXTRA_CA_CERTS so Node.js and npm trust it, then checks the network again. The certificate is matched by name and key identifier and checked with openssl. TLS verification is never turned off, and no other root is imported. Also fixed: a WSL_CONF_OK marker that leaked onto the screen, the install-log path wrapping mid-path, the distro's label, and a certificate help line wrapping to the left margin. (#3068)
