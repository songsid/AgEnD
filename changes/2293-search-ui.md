- **Global search on the dashboard (#2293): find which agent you asked about something.**
  - **Opening it:** **Search** in the sidebar (under Needs you, with its shortcut), **Ctrl+K** / **⌘K** anywhere, or the header's 🔍 when the sidebar is hidden and on a phone. **Ctrl+F** in an agent's chat opens it narrowed to that agent.
  - **Results:** a Spotlight-style dialog (full screen on a phone) with results as you type, grouped by agent, each badged Chat, Message or Task with the words marked.
  - **Keys and filters:** ↑↓, Enter, Esc or a click outside, plus folded filters: agent, team, time, kinds, Only mine. Recent searches show when the box is empty.
  - **Opening a result:** a chat message opens its chat at the message, flashed. A message between agents, a task, or a chat message the chat no longer keeps opens as the copy search kept.
  - **Access:** fleet admins only, never a guest or over the public link.
