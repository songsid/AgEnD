- **`/update` 不會再因為安裝途中時鐘被調整而失敗。** 只讓正在進行的更新自己的 npm 安裝通過的檢查，原本用掛鐘時間的文字比對更新程序的啟動時間；npm 執行期間只要時鐘被調整（NTP、VM 或 WSL 重新對時），更新程序就可能被當成已經結束而拒絕安裝，聊天裡只看到「npm error code 1」，重試通常就會成功。現在 Linux 上改用核心記錄的程序啟動時間，時鐘怎麼調都不會變；其他系統、以及舊版 2.2 beta 寫下的鎖，差距在 2 秒以內都算同一個程序。程序檢查在忙碌的主機上也有更多時間。安裝被拒絕時，聊天現在會顯示 AgEnD 自己的原因（「AgEnD cannot be installed here: …」），不再只有 npm 的結束代碼；更新程序本身是這個版本或更新版本的升級才會顯示。(#1947)
