- **Install OpenCode on a paired Windows computer from Settings → Runtime (#3521).** OpenCode joins Claude Code and Codex in **Install a CLI**: the same guarantees as before — one pinned version of the `opencode-ai` npm package (1.18.34) and its two Windows x64 packages, the registry's sha512 of each checked, `npm audit signatures`, and the Authenticode signature of the program (Anomaly Innovations, Inc) — installed per user into the Runtime's own folder, no administrator, no vendor script, and only while that computer's owner has turned the `install` switch on. Grok, Antigravity and Kiro stay "official command only", and the page now says **why** for each: Grok's Windows program is not signed by its publisher, Antigravity's vendor script installs whatever version is current (a fixed, signed download exists and is planned), and Kiro's installer needs an administrator.
