- **在聊天室確認、退回、回覆看板卡片（#2246，第 3 步）。** 等你確認和卡住的卡片現在會出現在**等你處理**：每個 bot 在
  General 的那則訊息會列出自己 agent 的卡，寫出卡片在問什麼或還缺什麼；等你確認的卡有**確認**和**退回**按鈕，卡住的
  卡有**回覆**按鈕（fleet 管理員才按得動，一次最多三張卡）。退回和回覆需要寫內容：回覆 bot 發的那則提示訊息，你的回覆
  就是退回理由或答案。agent 派出去的卡不會在聊天室重複列出，由那個 agent 告訴你（包括等你確認的時候）；網頁的「等你
  處理」清單點了就會打開卡片。提示還在等回覆時再按一次退回或回覆，會告訴你已經問過，不會再發一則。公開連結上的「等你處理」不會列出看板在那裡隱藏的卡。詳見[功能說明](features.zh-TW.md#在網頁上fleet--tasks)。
