- **網頁訪客新增「信任」等級：唯讀的「檢視」和搜尋（#2855）。** 在設定 → 存取與安全 → 訪客，每個人現在是**聊天**（預設，和以前一樣）或**信任**（`web.guests.grants.<帳號>.level: trusted`）。「信任」的訪客還可以唯讀地看它的 agent 畫面（不能打字或按鍵，畫面上會註明只能觀看），並搜尋它本來就看得到的聊天訊息（它的頻道顯示過的，或它自己寫的；最多 20 筆；不含 agent 之間的訊息、任務、團隊或設定）。把人改成「信任」和加 agent 一樣，要等 fleet 管理員在 General 確認；改回「聊天」立即生效，兩者都會列在這一區的「最近的變更」。每位訪客的限制：每秒讀畫面 2 次、同時 2 個 agent，每分鐘搜尋 6 次、一次一個；觀看同一個 agent 的所有訪客每 500 毫秒共用一份畫面，全部訪客同時最多 3 個搜尋。在儀表板自己的連接埠上，訪客的畫面讀取也一樣要經過這些檢查。
