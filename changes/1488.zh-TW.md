---
section: Upgrade Notes
---
- **在 AgEnD 沒有自帶 Node 的平台上從 2.1.12 更新（#1488）。** AgEnD 2.2 為 Linux（glibc 2.28 以上，x64/arm64）與 macOS 11 以上（x64/arm64）附帶自己的 Node；其他平台（musl Linux、32 位元、其他作業系統）需要 Node 22.14 以上，Node 太舊時會拒絕安裝。2.1.12 的 `agend update` 會先移除已安裝的 AgEnD 再安裝新版，所以在那裡被拒絕會讓 `agend` 整個消失。在這類平台上，請先把 Node 升到 22.14 以上，或改用 `npm install -g @songsid/agend` 更新，而不是 `agend update`。
