section: Changed

- **網頁：訪客的網頁只會顯示訪客能用的東西（#1920）。**
  - **訪客看到的：** 側欄只列出他自己的 agent，附上「訪客 · <名稱>（<平台>）」標籤和他的登入狀態。沒有 Fleet、需要你處理、View、設定、新增 agent、篩選、排序，也沒有底部分頁。聊天裡沒有 View、紀錄或詳細資料分頁，也沒有 ⋯ 選單，輸入框沒有指令清單。
  - **指令：** 訪客輸入 `/` 指令時，頁面會說明訪客不能執行指令，他打的字會留在輸入框裡讓他修改。
  - **輸入框下方會有一行說明**（手機上也有）：agent 會把他的訊息視為訪客的訊息，僅供辨識。
  - **背後的改變：** 頁面不會再去要任何訪客會被拒絕的東西，例如用量、特效、owner CSS 或儲存偏好設定。主題與語言維持主機設定的樣子。
