---
section: Changed
---
- **A new bot token starts a stopped connection right away.** When a connection AgEnD started with isn't running, for example because its old token was revoked, saving a new token in Settings now starts it at once. You no longer need to restart AgEnD. A connection added or changed since AgEnD started still waits for a restart, and its note now points to the restart notice at the top of the page instead of a host command.
