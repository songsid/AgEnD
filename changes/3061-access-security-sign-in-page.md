- **Settings → Access & security → Sign-in & authorization follows the reference layout (#3061).** The page lists Owner verification first, then the sign-in session settings, then Web authorization. The "Connections from outside" card is now "Owner verification", with a status badge, badges naming the supported authenticator apps (Google Authenticator, Microsoft Authenticator, other TOTP authenticators), and the rule that set-up, re-binding and removal happen on the AgEnD computer only, with no email or backup-code recovery. On a fleet with no chat connection, the Web authorization card says the owner is verified with the authenticator instead of in Discord or Telegram. Words only: no setting or stored value changes.
