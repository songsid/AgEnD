- **在 Hub 管理頁改 Hub 名稱（#3426）。** Hub 管理員可以在「管理 → 這個 Hub」變更或移除 Hub 的名稱。以前只能改主機上的設定，而在那裡修改會讓 Hub 停下來。現在 Hub 會用自己的金鑰重新密封設定，並以新名稱重新載入。同一張卡片也會顯示 Hub ID、配對 Fleet 時比對的成員金鑰指紋、簽發金鑰和 AgEnD 版本。
- **在設定中開啟 Hub 的 HTML 預覽（#3426）。** 執行 Hub 的 Fleet 可以在「設定 → Hub → 這個 Hub 的 HTML 預覽」開關 Hub 的預覽並設定連接埠。連接埠會先檢查不能和 Hub 或 Fleet 自己的連接埠重複，而且必須沒有被占用；以前要改主機上的設定。
- **在設定中啟動或停止 Hub（#3426）。** 執行 Hub 的 Fleet 可以在「設定 → Hub → 執行這個 Hub」開啟或關閉 Hub。停止前會先詢問一次，因為所有人都會被登出；不會刪除任何資料。「Hub 管理 → 這個 Hub」也會顯示 Hub 的安裝方式。
