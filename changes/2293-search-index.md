- **A search index for the dashboard's global search (#2293).** The fleet now keeps its own index of chat messages (Discord, Telegram, web), cross-instance messages (send_to_instance, delegate_task, report_result, broadcasts) and Task Board tasks, so you can find which instance you asked about something. A worker thread owns `search.db`: no SQLite work on the fleet's loop. The first start fills it from what the fleet already has: the chat history, the delivery outbox's 30 days and every task. Secrets are masked before anything is stored. A message's forwarded verification ids, working directory and branch are never indexed. An instance whose `cross_instance_visibility` is `hidden` has no cross-instance messages in the results. A corrupt index is moved aside and rebuilt. Admin sessions only: `GET /ui/search` and `/ui/search/context` refuse guests and the public link. `web.search.enabled: false` turns it off. `web.search.retention_days` (default 90) sets how long it keeps entries. The search box arrives in the next change.
