- Web chat, HTML preview panel: a **Reply about this page** button. It starts a reply to the message the page came in and adds one line naming the page (its title, or the file's name) to the message box, for you to say what to change and send. Nothing from the page itself goes into the message, and nothing is sent until you send it. On a phone the panel closes so the message box is in view.
