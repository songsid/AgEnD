- **設定 → 帳號：Claude Code 具名帳號的登入和預設帳號一樣（#3212）。** 以前在具名帳號按 **登入**，會開啟舊的網頁終端機對話框：臨時公開連結、登入終端機頁面與一次性存取碼。現在開啟的是與預設帳號相同的對話框，標題帶帳號名稱：按 **登入**、開啟供應商的頁面、把取得的代碼貼回來。登入寫進該帳號自己的資料夾，不會動到預設帳號；關閉對話框會結束它自己開始的登入（不會結束其他 session 或分頁開始的登入），**取消登入並移除** 也會結束它。登入只會登入 **新增帳號** 做出來的帳號，不會自己建立帳號。對話框不再帶有首次安裝頁的大標與說明、**檢查登入狀態** 按鈕與 **稍後登入**；**改用主控台備援**（為同一個帳號開啟舊流程）改成底部的小字連結。登入之後只會喚醒或重啟該帳號上的 agent。Kiro 與 Codex 的具名帳號維持原有流程。
