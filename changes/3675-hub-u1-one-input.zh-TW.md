section: Changed

- **設定 → Hub：連接 Hub 只要一個輸入框。** 輸入 Hub 位址（寫 `hub.example.com` 就可以），或貼上公司連結。按下「以公司帳號登入」之前，頁面會先查詢 Hub，顯示它的名稱，以及這台 Fleet 會用什麼名稱出現。預設是這台電腦的名稱，可以按「改名」修改。「Fleet 名稱」欄位已移除。如果有問題，會用一句話說明發生什麼事、該怎麼做：位址是 http、連不上 Hub、憑證不受信任、對方不是 Hub、Hub 沒開放公司帳號連接、Hub 和這台 Fleet 用了同一個主機名稱，或 Hub 的身分變了。登入期間，Fleet 卡片會顯示倒數，並提供「重新開啟分頁」和「取消」。如果 Hub 暫時擋下這次請求，也會在卡片上說明原因：還有一個配對碼連接沒完成、已達 Fleet 上限、沒有權限，或 Hub 正忙。連接完成後，Hub 的登入分頁會自動關閉。在同一個輸入框輸入配對碼，會打開「其他方式」並帶入這組配對碼。
- **連接卡片會顯示 Hub 名稱和擁有者：** 以哪個公司帳號連接，以及這台 Fleet 的名稱。被撤銷、被拒絕、逾時或已中斷的連接，只有一個「重新連接」按鈕。它會中斷、重新開始，再用同一個位址和名稱重新登入；Hub 支援的話，會在同一步讓舊的 Fleet 失效，不會留下第二台作用中的 Fleet。「移除這個連接」會先問一次，然後移除連接。Hub 支援的話，Fleet 會先告訴 Hub 它要離開，Hub 就不會再把它列為作用中。
- **「設定 Hub」** 移到連接卡片下方，這台 Fleet 已連接時會收成一行。
