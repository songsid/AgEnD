- **Agent 可以切換 ClassicBot 房間的 AI 帳號（#3715）。** 對 ClassicBot 房間呼叫 `update_instance_config` 時，現在接受 `config.backend_options.<backend>.credential_profile`（帳號名稱，或 `null` 回到 Fleet 預設），而且只接受這一項。做法和房間的設定頁存檔（#3690）相同：`classicBot.yaml` 只改這個房間的那幾行，註解和其他房間保持原樣；房間會重新啟動，Claude Code 的對話會一起帶過去。回覆裡的 `launched_profile` 是房間實際重啟後使用的帳號。這台主機上沒有的帳號、尚未登入的帳號會被拒絕，不寫入任何東西；其他欄位也照舊拒絕，訊息和以前相同。重啟失敗時，檔案會還原。General 因此只要一次工具呼叫就能把房間換到另一個帳號，不必手動改 `classicBot.yaml`。
