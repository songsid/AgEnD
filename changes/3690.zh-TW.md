- **在設定裡選 ClassicBot 房間的 AI 帳號（#3690）。** 以前只能手動編輯 classicBot.yaml 來更換房間的帳號。現在房間的設定 →「Runtime 與模型」有和 Agent 相同的 **帳號** 選單。儲存後，該房間的 Agent 會以新帳號重新啟動，和手動改檔案一樣；尚未連接的帳號不能選。classicBot.yaml 只會改到這個房間的那幾行，註解和其他內容都保持原樣。在「設定 → AI 帳號」，**移入 Agent** 也會列出這個 CLI 的 ClassicBot 房間；移除或登出時列出的房間也有自己的 **移動…**，會打開該房間的設定。
