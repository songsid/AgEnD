- Install AgEnD as an app: on the dashboard, **Needs you → This device → Install as an app** opens Chrome or Edge's install dialog, and the Hub has the same option as a button beside the bell. It opens in its own window from the Start menu, Dock or home screen. On iPhone, the hint says to use Share → Add to Home Screen. On a Hub whose certificate the browser doesn't trust, it explains why it can't be installed instead of offering a prompt that fails. Nothing from the dashboard or the Hub is stored for offline use.
