section: Upgrade Notes
---
- **Updating from 2.1.12 on a platform where AgEnD has no bundled Node (#1488).** AgEnD 2.2 brings its own Node for
  Linux (glibc 2.28 or newer, x64/arm64) and macOS 11 or newer (x64/arm64). Anywhere else (musl Linux, 32-bit, other
  systems) it needs Node 22.14 or newer, and refuses to install on an older one. 2.1.12's `agend update` removes the
  installed AgEnD before it installs the new one, so a refusal there leaves no `agend` at all. On such a platform,
  upgrade Node to 22.14 or newer first, or update with `npm install -g @songsid/agend` instead of `agend update`.
