- **Optional, per admin: ask for my authenticator code to confirm from other devices (#3503, #3486).** Each admin can set up their own authenticator app and turn on their own switch (Settings → Access & security → Owner verification; off by default). Then off the AgEnD computer each of THEIR confirmations takes the code of their own app for that change instead of Apply now; other admins are unaffected and nobody can set up, change or switch off another admin's app. Replacing or removing your app, or turning your switch off, asks your current code off the computer (whether or not the switch is on); the first set-up asks nothing. At most 64 admins can have an authenticator. A set-up made remotely never clears the fleet-wide wrong-code pause. "Only this computer can authorize" now blocks the code too. Chat fleets can use it for these codes (not for signing in from outside).
