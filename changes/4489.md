---
section: Changed
---
- **An update no longer runs over another AgEnD on the same computer, a full disk or a running test.** Before an update, AgEnD now also checks that this home's fleet is the one being updated and that no other fleet shares this install or this home; that there is room for the new version; and that no rehearsal, test or other update is running. Another AgEnD install elsewhere on the computer means updates go on an admin's own press only. While one install is updating a home, a fleet of another install can't start on that home; the updating install's own restart still can.
