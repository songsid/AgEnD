- **`/model` 會列出 instance 實際所用帳號的模型（#2072）。** 每個 Claude 憑證設定檔現在有自己的模型清單，用該設定檔自己的登入讀取，因此 `/model`、「更多模型…」以及手動輸入模型時的檢查，看到的都是那個帳號能用的模型，而不是預設登入的清單。instance 正在用的模型一定會出現在 `/model` 的選項裡：不在 CLI 清單中的會排在最前面，並標示「不在這個 CLI 的清單裡」。（Codex 與 Kiro 的設定檔仍共用同一份清單：它們的模型清單讀自 CLI 共用的檔案，而不是設定檔自己的帳號。）
