- **`agend attach` with an isolated home (#3262).** `agend attach` now attaches to the fleet's own tmux session (`AGEND_TMUX_SESSION`, else the one for `AGEND_HOME`) instead of always looking for `agend`. With the default home nothing changes; with an isolated `AGEND_HOME` or a set `AGEND_TMUX_SESSION` it used to miss the session.
