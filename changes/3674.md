- **No more false "sign-in ended" warnings for Claude (#3674).** A Claude sign-in's stored end date isn't a real deadline: Claude Code keeps the first sign-in's date when it renews, while the sign-in itself carries on. AgEnD no longer warns from that date. Needs you no longer says a working sign-in "reached its end date" or "ends by", and Settings → AI accounts no longer shows the date. A sign-in that has really stopped (its renewal was refused) still asks you to reconnect.
