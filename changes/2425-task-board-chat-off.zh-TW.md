section: Changed
---
- **任務看板在聊天室的功能預設關閉。** 如果你的 fleet 從未設定過，以下功能現在會關閉：
  - **每日摘要。** 要重新開啟，請設定時間：`defaults: { task_board: { summary_at: "09:00" } }`。
  - **「等你處理」裡的看板卡片**（General 的即時訊息與網頁的等你處理面板）。要重新開啟，請設定 `needs_you: { task_board: true }`。

  已經設定過其中一項的 fleet 會保留原本的設定。等你處理的其他項目（提示、傳遞、登入與當機通知）不受影響（#2425）。
- 「等你處理」不再因為沒有變化的卡片而每分鐘重新發一次訊息。沒有「移到卡住」紀錄的卡片（看板之前 `task` 工具留下的都是）會以最後一次編輯的時間當作開始等待的時間，所以 agent 每次編輯都像出現新項目，訊息就被重新發到最底下（#2425）。
