---
section: Changed
---
- **The model list in Settings is shorter and grouped (#3662, part of #3636).** For Claude Code it lists the models the account itself reports, without aliases like `opus` or `sonnet`; an alias name is still accepted under "Other…", and a saved one keeps showing as the current value, unchanged. A `[1m]` variant is listed, in its own "1M context (plan-dependent)" group, only for a model that reports 1M or more input tokens and does not have 1M by default; the other `[1m]` entries are no longer listed. When no account list can be read it shows the documented `claude-*` ids under "Not checked against this account". Other CLIs that have both a quick list and a fuller one show "Common" then "More models". Antigravity's low / medium / high versions of one model are now one entry, and its effort is chosen in the Reasoning effort dropdown, which now also appears for Antigravity. Claude Code's model probe also stops adding a `[1m]` variant for models that report under 1M tokens, report no size, or already have 1M by default, so Telegram's `/model` "More models" no longer lists entries that fail.
