- **Settings → Runtime no longer tells you to type a host command to add a Claude account (#3333).** When a paired computer has none yet (or you want another), the computer card and the agent's Claude account field point to Settings → Agents → AI sign-ins and API keys → Accounts, then **Add account** on that computer — the path that already signs the account in.
