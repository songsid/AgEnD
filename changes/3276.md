- **`agend rollback <version>` (#3276).** Goes back to an older AgEnD (2.3.x) safely: it stops the fleet, closes AgEnD's own tmux server and confirms it is gone, and only then installs that version and starts it. If the close can't be confirmed it stops before installing anything and says what is still running. `agend update` also checks the new version's bundled tmux before stopping anything (once the bundled tmux is used).
