section: Added
---
- 網頁對話的 HTML 預覽面板新增「**分享頁面**」：fleet 管理員可以為某個 agent 頁面建立一個任何人都能開啟的連結，時間 15 分鐘到 24 小時（預設 1 小時），不需要登入。每次都會先跳出確認對話框，說明分享哪個頁面、頁面本身的腳本會在對方的瀏覽器執行，以及分享多久。連結只顯示一次，供你複製。
- 分享的是 agent 傳來頁面的快照，在沙箱中執行、與儀表板分開；對方只看得到這個頁面，看不到對話、agent 或 fleet。
- 分享期間，面板會顯示「**分享到 …**」與「**停止分享**」，設定 → 存取與安全 也會列出分享中的頁面，可以停止。開始與結束分享時會告知頁面所在的對話，但不會貼出連結本身。
- 連結使用辦公室分享連結專用的臨時通道，不會用到 `/web` 連結或它的網域。可用 `web.page_share: { enabled, max_hours }` 關閉或縮短。
