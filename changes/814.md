section: Fixed
---
- **`update_instance_config` now accepts `tool_set`.** The General's MCP tool previously had no `tool_set` field in its Zod schema, so the coordinator could only set the tool-permission profile through Settings or a hand-edit of `fleet.yaml`. The field is now accepted with the same allowed values as the rest of the config (`full`, `standard`, `worker`, `coordinator`, `minimal`, `general`). Also fixes `config-validator.ts` which was missing `general` from its inline allow-list (the validator now delegates to `isToolSetName` — the existing source of truth in `tool-permissions.ts`).
