- 設定 → 存取與安全 → 公開連結：自己的網域（固定 tunnel）新增「**測試連線**」按鈕。用填好的網域、port 與 token 測試（不論是否已儲存），分五步：設定值、這台主機的 port、tunnel 連上 Cloudflare、DNS、網域連到這台 AgEnD；每一步顯示 ✓ 或 ✗，每個 ✗ 都說明下一步可以怎麼做。token 不會顯示，也不會影響已開啟的連結。
- 使用自己網域的 `/web` 現在會區分「tunnel 連不上 Cloudflare」與「tunnel 已連上，但這台主機打不開自己的網址」。後者發生在這台主機所在的網路擋了這個網域或它的 DNS 時；從其他網路（例如手機行動網路）可能仍可使用。
