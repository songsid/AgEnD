- **儀表板的設定精靈也不再要求填寫工作目錄。** 在 設定 → 設定精靈 裡，新 agent 的工作目錄可以留空，和 `agend setup` 頁面一樣。這時 agent 會有自己的資料夾 `~/.agend/workspaces/<名稱>`，精靈會在欄位下方顯示這個路徑，方案也會寫出完整路徑。若自己填寫，仍必須是絕對路徑。使用繁體中文時，精靈現在也會以繁體中文顯示主機的拒絕訊息（agent 名稱已被使用、連線已存在、token 環境變數是保留名稱）、方案的警告（後端沒有安裝）以及 Discord 頻道清單的錯誤。設定主機以代碼拒絕的套用步驟，也會用兩種語言的文字說明（#2726）。
