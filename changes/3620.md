- **Web chat 「引用」 / Quote on desktop sits below the selection (#3620).** Edge draws its own selection menu (hide, …, copy, search) above where a selection ends, right where the Quote button used to appear, and a page can't turn that menu off. On desktop the button now sits below the end of the selection, and goes above it only when there is no room below in the chat. Phones are unchanged: the button stays above the message box. If you'd rather not see Edge's menu at all, its own menu (… → Hide menu) can hide it for this site.
