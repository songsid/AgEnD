- **`agend attach`, `start`, `stop` and other commands now accept the names shown by `agend ls` (#1809).** `agend ls` shows display labels — a `display_name` such as `稜鏡 Prism` or `Fable 焚穹`, or a shortened real name such as `agend-reviewer-t996543` — but `agend attach <name>` only matched against real instance names, so copying a label from the table and pasting it into attach failed. A new `resolveByLabel` helper in `topic-commands.ts` builds the same label map that `agend ls` uses and resolves any label to its real name before the existing fuzzy matching on real names runs. Real names always keep priority; the label resolution only runs when the exact real-name lookup finds nothing.
