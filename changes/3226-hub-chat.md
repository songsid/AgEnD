- **The Hub is a chat app (alpha).** The Hub's pages now look and work like AgEnD's own chat.
  - **The sidebar** lists your conversations with the agents you may ask. **New chat** opens one: it shows who each agent answers for and how long you can ask it. A question still waiting for its answer is marked, and a closed chat is listed as closed.
  - **A conversation** uses the AgEnD chat's own thread and composer: Markdown, tables and code blocks, times, and a mark for each question's stage.
  - **The panel beside it** has the same layout as the AI usage panel. It shows who the agent answers for, your access and until when, who can see the chat, and what stays with the owner (their files, terminal and tool progress). It closes with ✕, and this device remembers that. On a phone it opens as a sheet.
  - **My exposures** and **Administration** moved into the session row's menu.
