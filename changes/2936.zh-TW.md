- **將遠端 Windows Runtime 配對至同一個 Fleet（#2936）。** 設定 → Runtime 管理電腦配對、核准、撤銷與 CLI 清單，並可直接下載對應版本的可攜式 Windows Runtime ZIP；新增 Agent 可選擇電腦及其 CLI，沿用既有 Instances、聊天、模型與選填工作目錄。執行端在啟動前保存任務身分，重連後依事件序號對帳並補回結果，不會自動重跑結果不確定的工作。Runtime 使用 Windows 使用者原有的 CLI 登入；協調端的監聽與網路開放方式不變。
- **原生 Codex 與 Claude 可使用限定範圍的 AgEnD 工具（#2936）。** 每輪 MCP 權限可透過本機或已配對的 Runtime 查詢任務及執行設定允許的 Fleet 操作。CLI 子程序不會取得永久機器憑證，唯讀工具限制持續生效；建立或重新設定 Windows Agent 仍須由管理員網頁操作。
- **修復原生 Agent 的設定確認與建立流程（#2936）。** 新增精靈會在核准前驗證並顯示所選 Runtime、電腦與檔案存取模式。核准後透過伺服器持有的管理員權限繼續建立，儲存完成後正確回報成功，避免 `unsupported_sensitive_effect` 與授權失效的誤報。
- **補齊 Runtime 私有網路連線與來源說明（#2936）。** 新增 Tailscale Serve、SSH 本機轉發步驟，說明 LAN 明文 HTTP 與 Funnel 的限制，記錄設計參考及來源，並加入反向代理協定驗證。
- **已配對 Runtime 沿用明確觸發的 CLI 偵測（#2936）。** 整合 #2937 的偵測結果保存與更新抑制選項。連線、讀取模型及任務均沿用上次清單；本機與遠端電腦皆僅在管理員明確要求偵測時執行探測。
