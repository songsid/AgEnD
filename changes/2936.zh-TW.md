- **將遠端 Windows Runtime 配對至同一個 Fleet（#2936）。** 設定 → Runtime 管理電腦配對、核准、撤銷與 CLI 清單；新增 Agent 可選擇電腦及其 CLI，沿用既有 Instances、聊天、模型與選填工作目錄。執行端在啟動前保存任務身分，重連後依事件序號對帳並補回結果，不會自動重跑結果不確定的工作。可攜式 Runtime 套件使用 Windows 使用者原有的 CLI 登入；協調端的監聽與網路開放方式不變。
- **原生 Codex 與 Claude 可使用限定範圍的 AgEnD 工具（#2936）。** 每輪 MCP 權限可透過本機或已配對的 Runtime 查詢任務及執行設定允許的 Fleet 操作。CLI 子程序不會取得永久機器憑證，唯讀工具限制持續生效；建立或重新設定 Windows Agent 仍須由管理員網頁操作。
