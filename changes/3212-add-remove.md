- **Settings → Accounts: add and remove named accounts.** Each Claude Code, Codex and Kiro card has **+ Add account**. It takes a name, checks it the way the server does (Windows-safe, not a case variant of another account), creates the account's private folder on the host and opens **Sign in** right away where the dashboard can sign it in. **Remove…** on a named account deletes its folder: its sign-in and, for Claude Code, its own copies of conversations. Remove is refused while any agent, ClassicBot room or the fleet default uses the account (the dialog lists them, with **Move…** where the web can change it) and while a sign-in for it is running, and you type the account's name to confirm. It only ever deletes AgEnD's own folder for that account: a real folder of the account running AgEnD with no link at any level, never the CLI's default sign-in, and never anything a link inside it points to. The fleet log records who removed which account. Only a fleet admin on the dashboard reached directly can add or remove accounts.
