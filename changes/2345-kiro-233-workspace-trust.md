section: Fixed

- **kiro-cli 2.33.0: a V3 instance no longer sits on kiro's new "Trust this workspace?" prompt (#2345).** 2.33.0's V3 engine asks it before its screen opens, in every folder it has not trusted yet (in the home directory, at every launch). AgEnD neither answered nor held it, so a new V3 instance never became ready, and the first message delivered to it would have picked the highlighted "Trust, continue" by accident. Under `--trust-all-tools` (AgEnD's default, already the larger grant), AgEnD now confirms "Trust, continue" on the exact screen kiro paints, then answers the trust-all-tools confirmation as before. Without it, with the cursor moved to "Don't trust", or on any other layout, the prompt is held for you to answer in the instance's pane, and no message is delivered into it. The sign-in screens, the TUI trust confirmation and the rate-limit text are unchanged from 2.32.0 (re-captured live), and 2.33.0 no longer gets the "untested version" launch warning.
