- **`agend update` 會先確認新版本能在這台電腦上執行，才動手更新（#1441）。** 它會讀取新版本自己的 Node 需求，判斷實際會用哪個 Node：新版本有為這台電腦附帶 AgEnD 的 Node 時就用它，否則用 PATH 上的 `node`。如果那個 Node 不符合，更新會停下來並顯示「沒有做任何變更」，說明新版本需要哪個 Node、為什麼用不了附帶的 Node（例如 musl Linux），以及接下來怎麼做。它不會安裝任何東西，也不會動到系統的 Node。從聊天室下的 `/update` 也會回報同樣的原因。如果讀不到需求，更新照舊進行，新版本自己的安裝檢查仍會把關。
