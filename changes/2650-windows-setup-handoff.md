section: Fixed
---
- **The Windows installer no longer leaves you stuck when the setup page asks for confirmation "on the host" (#2650).** When the browser setup page asks for a host confirmation, the installer now opens a separate window that runs `agend settings confirm`. That window lists exactly what will change and asks y/N; the installer also prints the one command to paste into PowerShell if no window appears. The approval still has to come from a person at the computer: neither the page nor the installer can give it.
- **Setup expiry and the final handover can be recovered (#2650).** The installer always prints the setup page's address and says why a page closed (15-minute limit, inactivity, too many wrong codes). After a close, Enter reopens the page (backends you already signed in are not asked again), or `c` switches to setting up in the console. The setup page counts down to its 15-minute limit, warns in the last three minutes, says when it has lost contact, and says how to reopen it once it closes. The dashboard sign-in address is always printed. If the dashboard does not open at the end, the installer says how to open it later, and pasting the install command again on an installed machine offers to open the dashboard.
