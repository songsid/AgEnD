- **Web chat on a phone: the message box names the agent by its display name, on one line, and Return adds a line (#2478).** The placeholder used the agent's full id, and a long id wrapped the empty box to two lines. It now uses the display name (the id only when there is none) and ends in "…" on one line, on phones and desktops. On a touch screen the keyboard's Return key adds a new line, and only the Send button sends. On a desktop, Enter still sends and Shift+Enter adds a line.
