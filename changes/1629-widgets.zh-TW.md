- **網頁儀表板的小工具（#1629）。** 小工具是儀表板用自己的元件繪製的一小塊面板：數字、進度條、一行文字、短清單、彩色標籤或走勢線。它依一段簡短的 JSON 規格與數值繪製；不會帶入撰寫者的 HTML、腳本、連結或 CSS，而且每個小工具都有 ✦ 標籤。
  - **Agent** 用 `set_web_widget` 在自己的聊天標頭下方與自己的詳細資料頁各放一個，並在工作時更新數值（最多每 10 秒一次，與主題變更分開計算）。用 `remove_web_widget` 移除，在 shell 裡則用 `agend-agent widget`。小工具也可以顯示 agent 自己的狀態、context 與花費。
  - **人** 可以從聊天或詳細資料的 ⋯ 選單移除 agent 的小工具，**鎖定主題** 則讓 agent 無法變更。**設定 → 網頁外觀 → 你的側邊欄小工具** 會把你自己的小工具放在實例清單下方，顯示 fleet 的計數，套用到你所有的裝置。
  - 關閉 **顯示 agent 的主題、效果與小工具**，或網址加上 `?safe=1`，就會隱藏 agent 的小工具。
