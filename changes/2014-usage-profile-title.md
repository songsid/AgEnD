- **A credential profile's usage card names it on its own line (#2014).** In the usage rail and the usage dialog, a profile's card is titled with the provider (for example **Claude**) beside its plan badge, and the profile's name sits on a muted line under it, instead of "Claude (team…)" cut off next to the badge. The full name is the tooltip. The usage API's `name` is unchanged; rows also carry `profile`.
