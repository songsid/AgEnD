- **Windows agents: fixes from the real Windows acceptance (#2953).** A persistent ("terminal session") Windows agent on this PC now starts. Before, its relay quit at once on every Windows host. A persistent Codex agent's next message is no longer left unsent when the screen is still repainting. Creating a persistent Codex agent no longer fails on a startup race. A Windows agent waiting on a permission prompt now shows a notice in its topic and in General, is listed under Needs you on the web, and Stop or Cancel dismisses the prompt, all as for a Linux agent. Notices and Needs you name the agent by its display name. A Settings change that fails says why, instead of only "could not be applied" or "Authorization expired". Pressing Save again on a pending change no longer queues a second, identical request. The confirmation for a new Windows agent shows its CLI and model. With this PC's Windows CLIs switched off, New agent no longer offers Native Windows.
