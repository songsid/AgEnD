- **Confirm a held change with your authenticator code.** On a fleet without Discord or Telegram, a change that needs confirmation can now be confirmed on the dashboard with the 6-digit code from your authenticator app, from this computer or your local network. The code confirms only that change and is used once, and wrong codes count toward the same limit as signing in from outside. The computer's own browser session still confirms with Apply now, including connecting to a Hub and sharing an agent. Over a public link the card says to confirm on the AgEnD computer's browser, or in General. If no authenticator is set up, the card links to setting one up.
