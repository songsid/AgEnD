- **A named Antigravity account's model list appears after you sign it in (#4052).** #4047 left named agy accounts out because `agy models` was not run with the account's folder, so its answer would have been the default account's. It now runs the way the account's agent is launched (`--app_data_dir <account folder>`), answers as that account, and gives nothing for a folder with no sign-in, so the default account's list is never shown under another account's name. A finished sign-in, an empty-list `/model` or Settings field, and the `models` event now cover named agy accounts too. Opening a menu or field for one can start a probe worker that contacts the vendor.
