- **Codex 0.169.0 support (#3830).** In codex 0.169.0, the screen shown while a resumed conversation loads has an extra hint row, so AgEnD stopped recognising it as still loading. It was already safe, because that screen was also never treated as ready. AgEnD recognises it again, so nothing can be typed into a conversation that is still loading. Everything else AgEnD reads from codex is unchanged in 0.169.0.
