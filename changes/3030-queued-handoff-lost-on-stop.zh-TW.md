- **傳給忙碌中 Claude Code 或 Codex agent 的訊息，不再因 AgEnD 停止或重新啟動而遺失（#3030）。** 這類訊息會先排在 CLI 自己的輸入佇列裡，等目前這一輪結束才處理，而這個佇列只存在於 CLI 的程序中：若在這一輪結束前執行 `agend stop`、重新啟動或更新，訊息就會遺失，而且先前已經標成 ✅。現在 AgEnD 會記錄每則排隊中的訊息，直到 CLI 的對話紀錄顯示已被處理。重新啟動後，舊 CLI 沒處理到的訊息會重送一次（已處理的訊息絕不重送），✅ 也改成在 agent 真正處理訊息時才出現，而不是排進佇列時。若 CLI 閒置下來卻沒處理，或重新啟動後 AgEnD 無法確認，該訊息會標 ❌ 並通知你一次，方便你再傳一次。
