section: Added

- **Settings content width can be chosen on each device.** Appearance offers a maximum width for settings pages, applies it immediately and remembers it in this browser. Narrow screens and compact forms still use the space they need.
- **Filter the Agent settings list by Runtime and status.** Filters combine with the existing search and grouping, show how many agents match, and can be cleared without changing the agents.
- **View keyboard shortcuts from Preferences.** The help section opens a reference for existing shortcuts, with platform-specific modifier keys and notes on where they apply.
