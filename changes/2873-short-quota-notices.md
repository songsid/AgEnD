- Quota, usage-limit and credit notices are one short line in your language, for every backend, e.g. 「⚠️ Codex 用量用完，已暫停」 / "⚠️ Codex usage limit used up — paused" (they were a long English sentence after the instance name, ending in "(action: pause)"). They say "paused" only where the instance is paused, and give a reset time only where AgEnD reads one (Claude, Antigravity). In the instance's own topic there is no name; posted elsewhere (a ClassicBot's in General), the name stays. Webhooks get the same message as before.
