- **Hub 改成聊天 App（alpha）。** Hub 的頁面現在和 AgEnD 自己的聊天一樣好看、好用。
  - **側欄**列出你和可提問的 Agent 之間的對話。**新對話**會開一個新的對話，並寫出每個 Agent 代表誰回答、你能問到什麼時候。還在等回答的問題會標示出來，已關閉的對話會標為已關閉。
  - **對話**用的是 AgEnD 聊天本身的訊息串和輸入框：Markdown、表格、程式碼區塊、時間，每個問題也會標示目前進度。
  - **旁邊的面板**和 AI 用量面板同一個版型，寫出這個 Agent 代表誰回答、你的權限與期限、誰看得到這段對話，以及哪些內容只有擁有者看得到（檔案、終端機與工具進度）。按 ✕ 可以關閉，這台裝置會記住；在手機上會以底部面板開啟。
  - **我的公開 Agent** 和 **管理**改放在登入者那一列的選單裡。
