- **網頁訪客：管理員逐一授權每個人可以看的 agent，並可傳送登入碼（#2348）。** **設定 → 存取與安全 → 訪客** 會列出有存取權的人，並能新增 AgEnD 看過、曾傳訊息給 agent 的人。系統會依對方傳過訊息的地方預先勾選 agent，任何修改在按 **儲存** 前都不會生效。新增人員或替某人加上 agent 需 fleet 管理員在 General 同意；收回立即生效，並會結束對方的 session。**傳送登入碼** 會私訊已儲存授權的帳號（每人每分鐘一次，不會發在任何其他地方）；私訊失敗時那一列會說明原因。一旦有 `web.guests.grants`，它就是訪客的全部範圍（預設拒絕），伺服器會在訪客的每一個讀取上強制執行。**以目前的訪客為起點** 會把目前推導出的權限轉成授權。
