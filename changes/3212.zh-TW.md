- **設定 → Agents → 帳號：每個 CLI 的帳號集中在一頁，並可選擇 agent 使用哪一個。** 原本的登入清單改成每個 CLI 一張卡片。卡片列出預設登入與每個具名帳號（憑證設定檔），包括只存在磁碟上的。每個帳號都會顯示它是哪個帳號（遮蔽過的 email 與方案）、是否已登入、哪些 agent、ClassicBot 房間或 fleet 預設在使用，以及本週用量。Claude Code、Codex 與 Kiro 有三種選擇帳號的方式：帳號上的 **把 Agent 移到這裡…**、agent 對話框新的 **帳號** 欄位，以及每個 CLI 的 **Fleet 預設**。它們和其他設定一樣先暫存再儲存，要等 fleet 管理員確認，執行中的 agent 會以新帳號重新啟動。設定會拒絕尚未登入的帳號，並顯示它的登入指令。只有 fleet 管理員在直接連到的 dashboard 上能查看或變更帳號。憑證不會傳到瀏覽器。一併修正：Agent 共用設定本身有 backend 選項時，儲存 agent 的 backend 選項（例如 Codex 速度）不再失敗。
