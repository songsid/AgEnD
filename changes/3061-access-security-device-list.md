- **Devices list and an optional login QR code, on a fleet with no chat connection (#3061).** Settings → Access & security → Sign-in & authorization → Devices & sign-in now lists the signed-in devices: this one marked, how each was approved (sign-in code, device code, this computer, authenticator app), whether its owner is verified, and when it was last active. The verified owner can sign another device out there; ending another device's session — by that button or the older `DELETE /auth/sessions` routes the Session menu uses — now takes the owner on a web-only fleet (a session a code or a device approval made can still sign itself out). A fleet with a chat connection is unchanged. With the new `web.login_qr` switch (off by default) the new device's "Sign in with another device" page also draws a QR code of the approve link — only the page's own address and the code on screen, never a credential; opened on a device signed in as the owner it fills in the code in Add device, and approving is the same as typing it.
