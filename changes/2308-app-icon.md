- **Your own app icon (#2308).** Settings → Web appearance → App icon takes a square picture (PNG, JPG or WebP) for the
  browser tab and a phone's home screen, with a preview and **Restore default**; an admin's session changes it. The
  dashboard now has a web app manifest, so installing it as an app uses the same icon. Icon addresses carry a version,
  so a new icon shows at once (an iPhone home screen keeps the old one until the shortcut is added again). See
  [web dashboard](web-dashboard.md#app-icon).
