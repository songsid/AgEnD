- **網頁：每個 instance 的詳細資訊頁，以及「聊天 / View / 詳細資訊」切換（#1561）。** 每個 instance 現在都有自己的詳細資訊頁，網址是 `/ui/fleet/agent/<name>`。頁面上有它的執行環境和最近活動，以及唯讀的設定摘要：目錄、綁定在哪裡、標籤和說明。按 **到設定編輯** 會開啟那個 agent 的設定。⋯ 選單可以啟動、重新啟動、停止、暫停、喚醒或刪除它，確認步驟和聊天頁相同。在 instance 的頁面上，標題列可以切換它的 **聊天**、**View** 和 **詳細資訊**；手機上則是標題列下方的分頁。開著某個 instance 時，按 **Fleet** 會進到那個 instance 的詳細資訊，不再總是落在 Tasks。在詳細資訊或 Fleet 分頁上，點側欄的 instance 會開它的詳細資訊。
