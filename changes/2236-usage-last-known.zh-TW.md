- **用量讀取失敗時，那一列保留上次的數字（#2236）。** 以前 token 過期（「Access token 已過期——…」）、請求受限、網路不穩或其他錯誤時，整列都會被錯誤取代。現在那一列會保留上次成功讀到的數字，最多一週前的。
  - **標示：** 數字會變灰，並有一行說明原因與時間：**已過期 · 快取於 14:05**、**暫時無法更新** 或 **讀取失敗**。過期或其他錯誤時，第二行說明該怎麼做（例如「執行一次 `agy`」）。
  - **已過的重置：** 之後已經重置的時段顯示 **已於 … 重置**，不會顯示舊的百分比。
  - **出現在哪裡：** 用量面板、側欄與對話框，Telegram 與 Discord 的 `/usage` 文字，以及 `get_usage`（那一列帶有 `stale`、`cachedAt`、`staleCause`；已重置的項目帶有 `resetPassed`）。
  - **不會憑空產生：** 從未成功讀取的 provider 仍顯示錯誤；一旦讀取成功，標示就會消失。
  - **重新啟動後：** 數字來自 AGEND_HOME 裡的 `usage-last-good.json`。
