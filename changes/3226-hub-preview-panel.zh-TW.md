- **Hub（實驗功能，alpha）：在聊天室的側欄看 HTML 頁面。** 回答裡有 HTML 頁面時，卡片可以在聊天室的側欄打開它。這是和 Fleet 聊天同一個面板，有版本、頁面、「指著它」、錯誤和「針對這一頁回覆」。頁面在 Hub 自己的預覽位址（`hub.web.preview_port`）的隔離沙箱裡執行。每個瀏覽器只需要為這個 Hub 允許一次預覽，確認視窗也會這樣說明。側欄打開時會取代資訊面板的位置，按 ⓘ 可以把資訊面板叫回來。在手機上，側欄是蓋在聊天室上的面板。面板帶入的文字會放進聊天室的輸入框，送出前可以先修改。Fleet 專用的「檔案與變更」和「分享頁面」不會出現在 Hub。沒有設定預覽連接埠時，面板會說明這個 Hub 不提供預覽。
