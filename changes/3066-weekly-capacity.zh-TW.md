- **用量對話框現在會顯示每個每週額度的 100% 實際是多少（實測）。** 帳號的每週長條下方會寫例如「100% ≈ $412（$378–$455）· 約 31.0M token · 依 3 週」。這個值是供應商的每週百分比變動期間，這個帳號的 agent 用掉的量，除以百分比變動的幅度。`get_usage` 也會在每個每週指標上回傳 `capacity`。
  - **何時顯示。** 某一週的百分比至少變動 10 個百分點後才會出現數字，在那之前對話框會說明目前進度。範圍已計入供應商以整數百分比回報的誤差，以及以小時記錄用量的誤差。
  - **代表什麼。** 估算同時以牌價換算的 API 等值與 token 數表示。累積三週後，對話框會指出最穩定的那一種，很可能就是供應商計算額度的方式。依模型區分的每週上限（例如「Sonnet（每週）」）只計算該模型的用量。
  - **一律註明：** 只計算這個 fleet 的 agent，同一帳號在別處的使用會讓估算偏低；各換算方式不一致的那一週會被標示。(#3066)
