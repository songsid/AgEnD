section: Fixed
---
- **An agent created from a fleet's second chat connection now works there.** In a fleet with Telegram and Discord, an agent that the Discord General (or a template it deploys) created was saved without its connection. The fleet then treated it as a Telegram agent, and messages in its new Discord channel never arrived. New agents now record the connection they were created in. `agend ls` shows the connection the fleet actually uses for each agent, instead of guessing from the topic id. If you already have such an agent, add `channel_id: discord` to it in fleet.yaml and restart.
- **`agend ls` no longer crashes when fleet.yaml has no `instances:` section.** It shows an empty list with the same hint `agend doctor` gives.
