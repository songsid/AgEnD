- **任務卡的頁面會列出關注者和 leader，時間軸也會顯示關注者的變更。** 屬性欄在**派工**下面：**關注者**列出會收到這張卡進度通知的 instance，每個都有 ✕ 可以移除，**新增**可從 fleet 其他 instance 挑（任務板關閉的 instance 會變灰並寫出原因；一張卡最多 10 個，滿了會說明）。子任務也會顯示主任務的關注者。**Leader** 寫出這張卡由誰帶領——專案的負責人或任務板預設——並在它收不到通知時說明原因（它就是負責人、已不在 fleet、任務板已關閉，或進度通知被關掉）。關注者的變更是時間軸上的一行（「Ann 修改關注者：+ops, −dev-b」，**歷史**篩選也看得到）。被拒絕時會用頁面自己的語言說明。訪客和唯讀的公開連結看不到這些控制。卡片的讀取新增 `leader`、`inheritedWatchers`、`followsProgress`（只增不改；不改動任何儲存資料，公開連結也不會在其中點名隱藏的 instance）。
