- Web chat and Hub rooms (on a computer): in a message's table, press in a cell and drag down to select just that column, or drag diagonally to select a block, as in a spreadsheet. **Ctrl/Cmd+C** copies the selected cells so they paste into a spreadsheet as cells. Dragging inside one cell still selects its text, and **Esc** clears the selection. A copied cell that starts with `=` or `@` gets a leading `'` so it pastes as text, never as a live formula.
