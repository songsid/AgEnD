- **`/update` no longer looks finished when the package is installed (#2476).** The progress message used to say "✅ Installation complete" while the fleet was still restarting, and a late edit of that line could overwrite "Starting… N/M". Install now says the fleet is restarting (no checkmark). "✅ Update complete — v… · N/M agents ready" is posted only by the new fleet once it is READY. Discord, Telegram and web chat, both locales. Failure and already-current messages are unchanged.
