- **Web: Edit layout in the right-hand panel; search while a panel is open.** On a screen 1200 px or wider, Edit layout's controls move into the right-hand panel, like Edit offices, so the whole canvas is free for dragging. Narrower screens and fullscreen keep the bar along the canvas, and Esc now cancels it there too. While either editor is docked, the rest of the page works, Ctrl+K search included. Leaving the page with unsaved changes asks first: **Discard changes**, or stay. (#2585)
