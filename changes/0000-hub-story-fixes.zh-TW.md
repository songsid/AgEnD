- **Hub：在使用者卡住的地方把話說清楚（#0000）。** 依 Hub 使用情境走查的結果：
  - **停止分享。** Hub 上的「暫停提問」改名為 **停止分享**。確認框會寫明後果：之後沒有人能再向這個 Agent 提問；要再分享，必須回到它的 Fleet 重新分享，而且每個人都要重新允許。
  - **到哪裡確認。** 打開「分享」或開始用公司帳號連接後，只有確認卡真的送到 General 時，提示才會提 General（例如「Discord 的 General」）。沒有聊天平台的 Fleet 會改指向頁面上的確認卡。公司帳號連接的等待畫面不再說「本機確認」，而是請你確認是你本人要連接這個 Fleet，之後才會開啟 Hub 登入。
  - **「分享的 Agent」** 會說明目前只能分享 Fleet 的 Agent，ClassicBot 房間還不能分享。
  - **登入頁** 第一行同時講兩種方式：驗證器 App 的 6 位數驗證碼，或 8 字元的裝置登入碼。
  - **Hub 管理員：**
    - 核准被拒時會寫出是哪個人，例如「Carol 目前不能連接 Fleet…」，不再說「你沒有權限」。
    - 撤銷 Fleet 的確認框會寫出 Fleet 名稱，和清單一致。
    - 目錄無法列出群組時，會說明原因（需要 Active Directory 並使用 LDAPS）和能做的事：按「編輯 AD 連線」檢查，或改用個別邀請。不再叫你去找 Hub 管理員。
  - **在其他裝置設定 Hub** 會說明做法：到執行 AgEnD 的那台電腦執行 `agend web`，再用它開啟的頁面設定。
  - **提問頁** 改成說明：對方會看到是你問的；Agent 用擁有者允許的範圍回答。
