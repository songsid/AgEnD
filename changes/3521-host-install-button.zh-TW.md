- **在設定頁就能替 AgEnD 主機安裝 AI CLI（#3521）。** 設定 → Agents →「AI 帳號與 API 金鑰」裡，主機上還沒安裝的 CLI 現在有自己的一列和「安裝」按鈕（Claude Code、Codex、OpenCode、Grok、Kiro、Antigravity、Muse：登錄表在主機上能安裝的全部 CLI）。它執行的是 `/login` 在聊天裡跑的同一套無人值守安裝程式：登錄表裡的指令、沒有終端機可以詢問、低優先權、可以停止、以安裝程式的結束碼判定成敗，所以只用儀表板的 fleet 不必再登入主機開 shell。執行中那一列會顯示安裝程式最後幾行輸出，並有「取消安裝」；結束時顯示該執行檔回報的版本，或安裝程式的結束碼與最後幾行，接著像已安裝的 CLI 一樣提供「連接」。頁面只送出 CLI 的 id，指令由伺服器查表；被拒絕的 id、已經有安裝進行中、或同時有帳號正在連接，都會用文字說明。誰可以：在這台機器或其網路上登入的 fleet 管理員，與在儀表板連接 AI 帳號的規則相同；訪客、唯讀工作階段與公開連結一律不行。網頁連接 AI 帳號遇到沒安裝的 CLI 時，現在改成指向「安裝」按鈕，而不是說這個頁面無法安裝。安裝是設定閘門的一項待確認變更，與其他會作用在 AgEnD 這台電腦上的變更相同：管理員的「安裝」會立即套用（不多一道確認）；開啟「要我的驗證碼」的管理員，不在這台電腦上時，要輸入自己的驗證碼，並綁定這次變更的摘要。公開連結、訪客與唯讀工作階段都不能提出安裝，確認後的請求在安裝程式開啟前，還會再確認一次提出者的身分。
