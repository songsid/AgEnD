section: Changed
---
- **An agent's new card no longer lands in "No project" without a word (#4391).** When an agent's `task create` names no project, a main task goes to the board's only project, or else to the one project that agent leads; with several projects and none of them its own, `create` is refused with the projects listed, so the agent asks you which one. `project: "none"` still opens it in no project on purpose. The answer to `create` now says which project the card went to and why, so the agent can tell you.
