- **設定 → 帳號：新增與移除具名帳號。** Claude Code、Codex 與 Kiro 的卡片都有 **＋ 新增帳號**。它會要求輸入名稱，並用和伺服器相同的規則檢查（Windows 也安全、不能和另一個帳號只差大小寫），在主機上建立該帳號的私人資料夾，dashboard 能登入時立刻開啟 **登入**。具名帳號上的 **移除…** 會刪除它的資料夾：它的登入，以及（Claude Code）它自己的對話副本。只要還有 agent、ClassicBot 房間或 fleet 預設在使用該帳號（對話框會列出它們，網頁能更改的附上 **移動…**），或它正在登入，就會拒絕移除；確認時需要輸入帳號名稱。它只會刪除 AgEnD 自己為該帳號建立的資料夾：屬於執行 AgEnD 的使用者、任何一層都不是連結的真實資料夾，絕不會刪除 CLI 的預設登入，也不會刪除資料夾裡連結指向的東西。fleet 記錄會記下誰移除了哪個帳號。只有在直接連到的 dashboard 上的 fleet 管理員能新增或移除帳號。
