- **設定 → 帳號：登出與切換帳號。** Claude Code、Codex 或 Kiro 已登入帳號上的 **登出…** 會在主機上為該帳號執行 CLI 自己的登出指令。對話框會先列出在重新登入前無法運作的 agent、ClassicBot 房間與 fleet 預設，網頁能更改的附上 **移動…**。對話會保留。對 Claude Code，還會刪除登出後留下、仍記載帳號的備份。預設登入上的 **切換帳號…** 會先登出，再開啟 **登入** 讓你登入想用的帳號；使用它的 agent 會以新帳號重新啟動。在 macOS 上，移除或登出 Claude Code 帳號時會由 Claude Code 刪除它自己的鑰匙圈項目，若仍找得到項目 AgEnD 會告訴你。該帳號正在登入時會拒絕登出；fleet 記錄會記下誰登出了哪個帳號。只有在直接連到的 dashboard 上的 fleet 管理員能登出帳號。
