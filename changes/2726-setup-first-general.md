section: Fixed
---
- **The first agent you set up on a Telegram or Discord connection is now the fleet's General.** The setup page (`agend setup`, the page the Windows installer opens) and Settings → Setup wizard name it `general` by default. It works in its own folder and answers in the chat's own General topic: the Telegram group's built-in General, or the Discord connection's general channel. Until now it was written as an ordinary agent. The fleet then added a second agent as the General at start, and an agent you named `general` got a new forum topic while the fleet ran with no General at all. Any name works, and a typed name is kept. If you enter a working directory, the agent is a worker in that project: it is named `agent-1`, and the fleet adds its General in its own folder as before, so the General's instructions never land in your repository. Web only still starts with `agent-1`. On a fleet that already has a connection or a General, a new agent cannot be called `general`. An existing fleet with an agent named `general` (in AgEnD's own folders) and no General is fixed at the next start: that agent becomes the General, in the chat's General topic (on Discord, when the connection has a general channel). An agent named `general` in a project of yours is left as it is, and the fleet adds its General under a free name (M-2069).
