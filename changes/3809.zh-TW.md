- **網頁對話的步驟區塊現在支援 Codex agent（#3787）。** Codex agent 工作時以前只顯示「處理中…」；現在它的對話有和 Claude Code、Antigravity、Grok 一樣的區塊：它執行的指令（只讀一個檔案或搜尋會照實標示，失敗的指令顯示結束碼）、檔案變更、MCP 呼叫、網頁搜尋，以及它在這些動作之間說的話，放在它所產生的回覆上方。規則不變：只給登入的管理員在儀表板上看到、每個 agent 的 `tool_progress` 決定顯示多少、**顯示思考** 預設仍是關閉。Codex 自己的推理是加密的，不會被讀取或顯示；只有模型自己選擇寫出的摘要才可能出現。步驟從 Codex rollout 檔的尾端讀取（不會讀整個檔案，它可能有數百 MB），Codex 壓縮上下文或重啟後繼續寫同一個 rollout 時，步驟仍會掛在正確的回覆上。Codex 會把它執行的每個工具記兩次（一次是 `exec` 腳本、一次是動作本身），對話只顯示一個步驟。在 Log 分頁，以 `reply` 工具回覆的回合，不會再因為 Codex 沒有回報最後訊息而被標成失敗。現在只有一般檔案會被當成 transcript 讀取：位置上的符號連結或 FIFO 只會顯示沒有步驟，不會被跟隨或等待。
