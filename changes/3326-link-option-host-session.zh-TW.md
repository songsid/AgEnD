- **開啟命名連結或快速連結：現在可以在 AgEnD 電腦本機的瀏覽器上完成。** 開啟命名連結或快速連結的網頁授權，以前需要 General 的卡片或在主機上執行指令。現在主機操作者自己的 session，也就是在那台電腦用 `agend web` 登入、並在本機瀏覽器上使用的 session，可以像確認其他變更一樣確認它：純網頁 fleet 上按「直接套用」，有聊天連線的 fleet 在沒有 General 能接收確認卡時，於儲存時套用。其他 session 仍然不行；在純網頁 fleet 上，頁面會請你到 AgEnD 電腦本機的瀏覽器操作。驗證碼一律不能用來確認它。
