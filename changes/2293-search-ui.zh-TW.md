- **Dashboard 全域搜尋（#2293）：找回某件事當初交給哪個 agent。**
  - **打開：** 側欄的**搜尋**（在等你處理下方，標著快捷鍵）、任何地方按 **Ctrl+K** / **⌘K**，或在側欄收起時與手機上按標頭的 🔍。在 agent 的聊天裡按 **Ctrl+F**，會打開已限定為該 agent 的搜尋。
  - **結果：** Spotlight 風格的對話框（手機上全螢幕），打字時就出現結果，依 agent 分組，每筆標著聊天、訊息或任務，並標出你輸入的詞。
  - **按鍵與篩選：** ↑↓、Enter、Esc 或點外面關閉；篩選可展開，包括 agent、團隊、時間、種類與只看我的。沒輸入時列出最近的搜尋。
  - **開啟結果：** 聊天訊息會開啟該聊天並跳到那則訊息，閃一下。agent 之間的訊息、任務，或聊天已不保留的訊息，會顯示搜尋保留的副本。
  - **權限：** 只有 fleet 管理員能用，訪客與公開連結一律不行。
