- **為每個 agent 挑顏色，並決定顯示在哪裡（#1958）。**
  - **修改方式：** 在網頁儀表板按 **⋯ → 顏色…**（或 View 的 **編輯個人資料**）。可以從 12 種顏色或自訂色碼中挑選，並選擇顯示在 agent 的名稱、左側色條或圖片外框。**重設** 可以回到原本的顏色。
  - **Agent** 可以用 `set_web_theme`（`identity`）設定自己的顏色，有人挑的顏色一律優先。
  - **自動配色：** 沒人挑過的 agent 會得到幾種柔和自動配色之一。
  - **設定：** 分頁現在叫 **設定 → 網頁外觀**，也可以設定預設的顯示位置，並提供 **關閉顏色** 與 **還原預設值**。
