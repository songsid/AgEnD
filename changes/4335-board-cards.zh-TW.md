section: Changed
---
- **任務看板的卡片更寬、更清爽，也看得出誰在跑。** 看板和清單都撐滿頁面，不再停在 1240 px（清單裡多出來的寬度給標題欄）；每一欄寬 272–360 px，不管有幾個狀態（放不下的往右捲），標題不會再擠成三行。卡片高度跟著內容走，標題最多兩行、狀態最多一行（超過的以「…」截斷，滑鼠移上去看全文）。清單裡執行中的卡，「執行中」標示改放在標題前面。狀態列現在只說一件事，依序是：為什麼卡住、在等誰、什麼正在執行、下一步是什麼、子任務進度。卡片左邊的彩色線條在所有狀態都拿掉了。卡片與清單上的負責人頭像現在是按鈕：點它會開啟和卡片詳情頁相同的選擇器，選了就存（卡片被別人改過時會提示）；滑鼠移上去會顯示該 instance 的狀態、正在做什麼、手上有幾張卡、是不是專案負責人、以及這張卡是誰派的。唯讀連結下頭像只能看。卡片詳情頁的「動態」改成串流的排法：每則留言（和進度回報）是一張獨立的卡片，系統動態是卡片之間的細列（每一段，即使只有一筆，都會收成「› N 項動態」），留言框是最底下的一張卡。留言裡的作者頭像變大，並會顯示和看板相同的資訊卡（滑鼠移上去、鍵盤聚焦或點一下），卡上有前往該 instance 的 Agent 頁面的連結（唯讀連結沒有連結、人沒有連結、看不到的 instance 完全沒有卡片）；留言內容的格式和 instance 對話視窗一致（Markdown、表格、JSON 與其他程式碼區塊，附換行與複製，過長的會收合）；「進度」標籤與篩選移上去會說明它是什麼。Tasks 的外觀改成跟設定頁一致：同樣的頁首（大標題、下方一行說明、右側動作）、搜尋欄、清單容器與卡片，讓兩邊看起來是同一個產品。看板的欄位放不進視窗時，工具列最右邊會出現 **‹ ›** 按鈕可以捲動它們（只有在有欄位看不到時才會出現）。只動版面與樣式：API、儲存資料與公開連結的規則都沒有改。
