- HTML previews over a fixed public link no longer need a temporary Cloudflare address. Set **Preview address** in Settings → Access & security → Public & sharing (`web.public_link.preview_hostname`). It is a second route on the same tunnel, to the preview port, and **Check preview address** confirms it works. When Cloudflare limits temporary links (429), the preview notice now links to that setting, and Download still opens the file. Saving on that tab also no longer jumps back to Overview a moment later.
