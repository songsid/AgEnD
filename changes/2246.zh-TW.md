- **任務看板：專案、主任務和子任務，以及你的確認（#2246）。** Fleet › Tasks 現在是一個看板。打開是你的專案和各自的
  完成度，以及待你處理的事：做完等你**確認**或**退回**的工作、等你**回覆**的卡住的卡。專案頁是它的主任務依狀態分欄的
  看板，可以拖曳移動卡片（或在卡片標題上按 Alt+方向鍵；手機上用卡片裡的**位置**）、依負責人篩選，每張主任務都能展開
  子任務。卡片打開後每個欄位都能編輯，也看得到留言、進度紀錄和變更歷史；你開始編輯或移動之後 instance 才寫入的話，
  你的操作會被拒絕，不會蓋掉對方的，你打的字也會留著。在網頁上開的主任務做完會停下來等你確認，而且只有在網頁登入的人
  能確認：instance 對這種卡的 `task` `done` 會把它改成 `review`，只帶 web token 的請求也照 instance 的規則處理。公開
  連結上的看板只能看。instance 透過 `task` 工具使用看板：`task mine` 列出自己的工作（你退回的排最前面，附上你的理由），
  `task move` 移動卡片，`task get M-3` 顯示卡片和它還沒看過的留言，每次寫入也會收到看板要告訴它的事。以前的任務保留
  原本的 id，放在**未分類**；保留期限不會清掉進行中專案裡已完成的卡片（要退回沒有看板的舊版前，先調高
  `retention_days`）。詳見[功能說明](features.zh-TW.md#在網頁上fleet--tasks)。
