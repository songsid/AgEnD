section: Changed
---
- Hub (experimental): the Hub's chats now look and work like AgEnD's own chat. The list uses the same rows, with each agent's status dot and its owner, and an unread count. On a Hub with rooms, the list has two groups, **Rooms** and **Agents** (the Hub assistant last), and a room opens in the same chat thread and message box: each message says who wrote it, answers are replies to the message that asked, and a line shows how many agents have answered. Type `@` to pick **@All agents**, the room assistant, an agent or a person.
