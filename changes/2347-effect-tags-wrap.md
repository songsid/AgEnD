- **On a phone, a setting's effect tag sits under its label (#2347).** On narrow screens, a tag like "Restart this Agent" or "Needs an admin's OK" used to be squeezed beside a long label or broken mid-tag. It now takes its own line under the label's text, in one piece. In a checkbox row it lines up with the text, not the box. A desk keeps the tags beside the labels.
