- **跑 kiro TUI 的 kiro instance 現在可以在回合中插話（steer）了（#1405）。** `/steer` 與帶 `steer: true` 的 `send_to_instance`，現在能送進工作中的 kiro instance：條件是它用 `kiro_ui: tui` 啟動，且 kiro-cli 版本的 TUI 已經過 AgEnD 驗證（目前為 2.27.1，v2 engine）。訊息怎麼處理由 kiro 自己的插話模式決定。AgEnD 每次插話前都會從 kiro 的輸入列讀出這個模式，而且從不切換它：只有輸入列顯示 `Type to steer` 時才貼上，並在輸入列重新變空後才確認送達。如果顯示的是 `Type to queue`（使用者用 Ctrl+S 選了排隊模式），訊息就照舊在回合結束後送出。legacy UI、v3 與其他版本也是一樣；在這些 instance 上用 `/steer` 會說明為什麼無法使用。
