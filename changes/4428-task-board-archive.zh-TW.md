- Fleet › 任務：專案的「完成」欄現在只顯示最新完成的 20 張卡片（按「再顯示 N 張」看其餘的），標題下方會顯示本週完成了幾張、其中幾張已封存。完成或取消的主任務在完成 3 天後會封存（設定 › Agent 共用設定 › 進階設定 › 「完成的卡片封存於」，`defaults.task_board.archive_after_days`；設為 0 則一直留在看板上）：封存的卡片會離開看板欄位和專案的統計數字，按專案的「已封存 · N」可以看到清單，搜尋時會標示「已封存」，用卡片編號也仍然打得開，移回「待辦」就會重新開啟。不會刪除任何東西。
