---
section: Changed
---
- **Windows agents accept newer Codex and Claude Code versions (alpha).** A persistent Windows agent no longer refuses a CLI version AgEnD hasn't tested yet. It runs and is labelled **Not yet verified** in Settings → Runtime, in the CLI diagnostics and in the agent's chat header. Nothing is checked less strictly: AgEnD still types only into a screen it recognises, and a screen it doesn't recognise stops and waits for you in **Needs you**. On an unverified version, an administrator decides whether a conversation that was never saved starts over. A version known not to work, or a version AgEnD can't read, is refused with the reason.
