section: Added
---
- Settings → Access & security → Guests now sets how long a guest stays signed in and when an unused guest session signs out. Before, this was only in fleet.yaml (`web.guests.session`).
- The limits now go as far as an admin's own: up to 720 hours, and up to 720 hours unused. The default is unchanged (12 hours, 2 hours unused).
- A guest is never signed in longer than an admin on this computer, and the public link's own limits still apply there.
- Making a limit longer waits for a fleet admin; making it shorter applies at once.
