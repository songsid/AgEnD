- **不能安全更新的電腦，不會再嘗試更新。** 每次更新前（不論是網頁、聊天的 `/update` 或 Hub），AgEnD 會先檢查這台電腦：執行中的是 npm 會更新的那份安裝、Fleet 的 PATH 上的 `agend` 就是那個檔案、有權限寫入安裝位置、不是容器或 Windows、連得到更新來源，而且新版能在這台的 Node 上執行。任何一項不符合，更新就會停下並說明原因和解法，不做任何變更。無法在更新後自己重新啟動的設定（沒有服務、沒開 lingering），或需要管理員處理的情況（`npm link`），仍可由管理員親自按下更新，但不會自動更新。
