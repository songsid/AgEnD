- **辦公室的對話框（#2861，由 hxhsandy 設計）。** 在辦公室工具列勾選 **對話框**（每個瀏覽器各自設定，預設關閉）後，有人傳訊息給畫面中的 agent 時，場景下方會出現視覺小說風格的對話框：對方的立繪、名字與訊息（逐字打出），agent 工作時顯示它的立繪與「處理中…」，接著是它的回覆。同時有多段對話時依序排隊（「+N」）；點一下對話框開啟該 agent 的資料卡，點兩下開啟聊天。儀表板只顯示檢視者本來就能在聊天裡讀到的文字；分享連結永遠不顯示文字（「傳了一則訊息給 Atlas。」、「已回覆。」）。它會遵守隱藏暫停與停止的成員、就寢時間與減少動態效果。外觀包可以加上 `portraits`（依 instance、依人的帳號、給 NPC，可依狀態換表情）與 `dialogBox` 樣式；沒有的話 agent 顯示頭像，再沒有就是首字。和 `levels` 一樣，較舊的版本會拒絕含 `portraits` 或 `dialogBox` 的外觀包（以辦公桌顯示）。
