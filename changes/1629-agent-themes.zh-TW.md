- **網頁：Agent 的主題（#1629）。** Agent 可以用 `set_web_theme` 系列工具替自己的網頁聊天設定外觀：淺色與深色的顏色、強調色、對話泡泡、字型、背景圖片、自己的圖片與工作中顯示的文字。
  - 主題只改變該 agent 的聊天，以及它在側欄的圖片與外框顏色。主機與頁面都會檢查這些值，圖片由儀表板本身提供，並已移除中繼資料。
  - 已登入的管理者可在聊天或「詳細資料」的 **⋯** 選單 **鎖定** 或 **重設** agent 的主題；臨時公開連結上不提供這兩項。
  - **設定 → 網頁外觀 → 顯示 agent 的主題與效果** 可在你所有的裝置上關閉主題。`web.themes.agent_edit: false` 會拒絕所有 agent 的變更。
