---
section: Changed
---
- Settings → "Revoke web authority" is now "Revoke other devices' authorization": only a verified owner can use it (the server answers 403 to anyone else), the confirmation lists the devices that lose their authorization, and the owner's own session stays verified. The session menu and Settings → Devices show one of four roles (Owner ✓, Admin · not verified, Guest, Read-only), and a browser whose host sign-in lost this computer's admin authority can re-bind in place with the sign-in code from `agend web --code`. The session menu now has its own border so it no longer blends into the sidebar (#3486).
- Settings → Devices & sign-in is now the one device list for every fleet: `GET /ui/devices` returns one row per session of any tier (`tier`, `verified`, `via`, `lastSeen`, `current`, and whether you may sign it out), also on a fleet with a chat connection. There an admin can sign out their own devices and any guest's or read-only one; another admin's devices only that admin can sign out (the server answers 403 `other_admin`). The session menu no longer lists devices: it links to Settings → Devices, and "Sign out everywhere" moved there (#3486).
