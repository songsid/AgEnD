- **A kiro instance running kiro's TUI can now be steered mid-turn (#1405).** `/steer` and `send_to_instance` with
  `steer: true` now reach a working kiro instance launched with `kiro_ui: tui`, on a kiro-cli version whose TUI AgEnD
  has verified: so far 2.27.1 with the v2 engine. kiro's own interrupt mode decides what happens. AgEnD reads that mode
  from kiro's input row before every steer and never switches it: it pastes only while the row says
  `Type to steer`, and confirms only once the input row is empty again. If the row says `Type to queue` (the user
  chose queue mode, with Ctrl+S), the message is delivered after the turn as before. The same happens on the legacy
  UI, on v3 and on other versions; `/steer` there says why it is not available for that instance.
