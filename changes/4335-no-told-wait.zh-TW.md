- **agent 對卡片做的改變，和人做的改變一樣快通知。** 以前 agent 完成卡片、送去確認、退回、卡住或換人負責時，派工者、關注者和看板負責人 最多要等兩分鐘才收到通知；如果這個 agent 另外傳了訊息（寫了卡號）給他們，通知甚至完全不送（#2785、#2801）。訊息和看板通知是兩件事，所以這個規則拿掉了：不管 agent 有沒有另外傳訊息，`[Task board]` 通知都會在改變後約 10 秒送出，和人做的改變一樣。指派、退回、回覆、留言和 @mention 也一樣。agent 想告訴別人什麼，就在留言裡 @mention 對方。維持不變的：10 秒內的改變合成一則通知、還在等待的通知在卡片又變動時撤回、防迴圈上限、做這件事的人不會收到自己的通知。
