- **Web: the instance you have open stays on top while you filter the sidebar (#1936).** Typing in the sidebar filter or choosing a Status or CLI facet no longer hides the instance you're talking to. It stays at the top of the list under **Current**, marked as the open one, whether or not it matches, and isn't repeated in the results below. The `N / M` count still counts only the filter's matches. Clearing the filter puts the instance back in its usual place.
