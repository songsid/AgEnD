- **設定 → 帳號：配對 Windows 電腦上的 Claude Code 帳號。** 帳號頁現在會在每台配對電腦的名稱下，列出該電腦的 Runtime 回報的帳號與遮罩後的帳號和方案。電腦的擁有者在那裡開啟 `agend-runtime remote-setup accounts on` 後，fleet 管理員就能在 dashboard 上對該電腦 Runtime 建立的帳號 **＋ 新增帳號**、**登入**、**登出…** 與 **移除…**。登入和主機上一樣是連結加代碼的對話框，由那台電腦的 Runtime 執行。其餘情況以唯讀顯示，並附上原因和要在那台電腦上執行的指令：電腦離線或 Runtime 太舊、擁有者尚未允許，或帳號是手動建立、由舊版 Runtime 建立。Windows 使用者自己的登入永遠不會從這裡更改，Anthropic Console 帳號要在那台電腦上用 `agend-runtime login` 登入，電腦也不回報用量。有 agent 或那台電腦自己的預設在使用時會拒絕移除。伺服器不會儲存登入連結和代碼。
