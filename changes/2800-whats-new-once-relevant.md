section: Changed
---
- After an AgEnD update, agents get the "what's new" note only once per release and only about tools they actually have. It now rides in front of their next message instead of arriving as a separate message they had to spend a turn on, and it links the full notes on the website instead of pasting them. An agent with nothing relevant gets nothing. A person's message with a verified sign-in is never changed; the note waits for the next message.
