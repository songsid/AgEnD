section: Changed
---
- **A comment or an `@mention` on a task board card wakes agents again.** A comment someone else writes on a card wakes its assignee, and `@<instance name>` in a comment wakes that agent even when the card is not its own, as a `[Task board]` notice that names who wrote it and quotes the words. This reverses #2801's "a comment notifies nobody", so the card is a place to talk to an agent (#4335). Nobody is woken for their own comment, for an agent with the task board off, or for a comment the assignee already read; text in backticks is never read for mentions. When a person wrote the comment, the notice ends with "(a person reads the card; no @ needed)", so the agent answers on the card instead of @mentioning someone who is not an instance. Agents answering each other on a card wake each other for at most 4 turns (a person's comment lifts it), and one agent comment wakes at most 5 agents. On by default, also for an existing fleet: `defaults.task_board.comment_wakes: false` brings the old rule back. Comments written before the upgrade are never told, and no stored data changes.
