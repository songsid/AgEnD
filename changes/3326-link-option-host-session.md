section: Changed
---
- **Turning on the named or quick link: the browser on the AgEnD computer can now do it.** Turning on Web authority over the named link or the quick link used to need a General's card or a command on the host. Now the host operator's own session, signed in with `agend web` and used in the browser on that computer, confirms it like any other change: Apply now on a web-only fleet, or at Save on a chat fleet when no General can take the card. Every other session still can't. On a web-only fleet, the page says to do it in the browser on the AgEnD computer. An authenticator code is never accepted for it.
