- **Windows 本機 CLI 可以與 WSL Agent 使用同一套 Fleet。** 在 WSL 協調端啟用 `AGEND_WINDOWS_CLI=1` 後，可於「設定 → Windows CLI」偵測已安裝的工具。新增 Agent 分為選擇 Runtime、設定與完成三個步驟，提供 CLI 產品圖示、模型選項、選填工作目錄與 AI 協助填寫設定。Codex、Claude Code、Antigravity、Grok、OpenCode 與 Muse 提供本機任務介面；Kiro CLI 目前僅支援偵測。Windows Agent 共用既有的 Instances 清單、設定、聊天、團隊、排程與接收 Fleet 派工流程；既有本機對話會保留名稱、工作區及續接識別碼，聊天歷史可跨重啟辨識，並修復舊版重複匯入的副本。本機執行僅開放本機管理員。此預覽版一次執行一個本機任務，保留各 CLI 的核准政策，目前尚未提供向外呼叫 AgEnD 的 MCP 傳輸、終端連接或外部頻道綁定。詳見 [Windows CLI 預覽說明](../docs/windows-cli-preview.md)。
