- **The host memory notice no longer repeats every 10 minutes (#1685).**
  - A Mac on 2.2 betas got "macOS kernel memory pressure level: 2 …" about every 10 minutes, because macOS's warning level can last for hours. 2.1.12 never sent it.
  - Notices now follow the level: one when pressure rises, one "back to normal" line when it ends, and nothing in between. A level that comes back within an hour isn't announced again.
  - On macOS, the routine warning level (2) sends no chat notice. It still slows new agent starts, it is logged, and the Fleet page in the web dashboard shows it. Only critical (4), when new starts wait, is announced.
  - Linux follows the same notify-on-change rule.
