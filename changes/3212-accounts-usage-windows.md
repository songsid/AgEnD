- **Settings → Accounts: the 5-hour window beside the week.** Each account on this host shows its short usage window ("5h") next to the weekly one, with the percent, a bar that turns amber from 70% and red from 90%, and when the window resets; two columns when wide, two rows on a phone. Last-known numbers are greyed and said so once. It is the Usage panel's own meter, drawn from the same snapshot as the week. A window whose reset time has passed since the numbers were read is not shown, and a CLI that reports no window shows none.
