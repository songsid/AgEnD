- **選用、每位管理員各自：從其他裝置確認時要我的驗證碼（#3503、#3486）。** 每位管理員可以設定自己的驗證器 App，並開啟自己的開關（設定 → 存取與安全 → 擁有者驗證；預設關閉）。開啟後，在 AgEnD 電腦以外，「他自己」的每次確認都要輸入自己 App 對該項變更的驗證碼，不再按「直接套用」；其他管理員不受影響，也沒有人能設定、更換或關閉別人的 App。更換或停用你的 App、或關閉你的開關，在電腦以外都要輸入你目前的驗證碼（不論開關是否開啟）；第一次設定不需要。最多 64 位管理員可以有驗證器。從遠端設定不會清除全 fleet 共用的輸入錯誤暫停。「只有這台電腦可以授權」現在連驗證碼也擋。聊天型 fleet 也能用它做逐筆驗證碼（不能用於從外面登入）。
