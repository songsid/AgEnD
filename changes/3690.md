- **Choose a ClassicBot room's AI account in Settings (#3690).** A room's account could only be changed by editing classicBot.yaml. Now a room's settings → Runtime & model has the same **Account** picker as an agent. Saving restarts that room's agent on the new account, as a file edit does; a not-yet-connected account can't be chosen. Only that room's lines in classicBot.yaml change: comments and everything else stay as they were. On Settings → AI accounts, **Move agents here** also lists the CLI's ClassicBot rooms, and a room in a Remove or Sign out list has its own **Move…**, which opens the room's settings.
