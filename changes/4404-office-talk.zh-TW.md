- **在辦公室裡直接跟 agent 對話。** 辦公室 ⚙ 顯示選項裡的 **對話方式**（每個瀏覽器各自設定，只在儀表板）決定按 **對話** 會怎樣：和以前一樣的彈出視窗（預設）、地圖旁的側邊面板（手機上是下方拉起的面板）、疊在場景下緣、像視覺小說的對話框，或把回覆畫在 agent 頭上。四種都是和聊天同一段對話，按 Enter 送出。
- 對話框只顯示 agent 那一方：整段回覆一頁一頁逐字打出，旁邊有大立繪；點一下顯示整頁、下一頁或關閉。**歷史紀錄** 有雙方的話，也能開啟完整聊天。播放可選 **點擊**（預設）、**自動** 或 **快速**，**跳過** 關掉所有回覆；頭頂氣泡也一樣。
- 外觀包可以用 `dialogBox.bubble` 自訂頭頂回覆的樣式（顏色、九宮格框，以及 `enter`：pop、fade 或 none）。
- **「所有辦公室」成為辦公室的首頁。** 存了兩間以上辦公室時，沒在切換器選過別的之前，辦公室一打開就是全域圖；點一格就進入那間辦公室（只限這次瀏覽），工具列的 **← 返回全域** 回到全域圖。
