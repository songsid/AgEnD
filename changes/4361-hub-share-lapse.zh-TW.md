---
section: Changed
---
- **分享到 Hub 的 Agent 換了後端或資料夾後，現在會告訴你需要重新分享。** 跟以前一樣，原本的分享不會延續到新的後端或資料夾。現在：
  - 「等你處理」會出現一則提醒，重新分享後就會消失。
  - `/backend` 的回覆會提醒這個 Agent 需要重新分享。
  - 這個 Agent 的 Hub 工具會回 `share_needs_reshare`，不再只說「unavailable」。
  - 「設定 → Hub」和 Hub 的「我分享的 Agent」會標示「需要重新分享」，並提供「重新分享」。從這兩處重新分享，可以提問的人都會保留（仍有效的授權，到期日不變）；如果先停止分享再分享，這些授權仍會被移除。
