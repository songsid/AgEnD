- **Choose which dashboard features each agent may use (#2391, by @igs-willyliao).** `dashboard: { appearance, task_board, web_settings }` on an agent, or in `defaults` for every agent (an agent's own switch wins, feature by feature), takes away a whole feature on top of its tool set: its own look on the dashboard, the task board, or Settings → Web appearance for you. Unset means allowed, so nothing changes until you switch something off. A switched-off feature's tools are refused with the reason at the next call (no restart; ClassicBot rooms follow the defaults too) and leave the agent's tool list at once. An agent without the task board isn't told to use it, and switching it back on tells the agent how to start. In Settings, an agent's dialog has **Dashboard access**, and the defaults have three ticks. Switching off applies at once; switching on is confirmed first. Choosing "default" for an agent follows the default again. **A new fleet starts with the task board off**: `agend init`, `agend quickstart` and the setup page write `defaults.dashboard.task_board: false` into the new fleet.yaml. Turn it on by ticking it in the Settings defaults (or for one agent), or by setting it to `true`. An existing fleet.yaml is never rewritten, and its board stays as it was.
