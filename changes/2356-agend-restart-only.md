section: Fixed
---
- **`agend fleet restart --reload` no longer leaves a systemd fleet stopped; `agend restart` is the only full restart (#2356).** The reload made the fleet exit cleanly, which a `Restart=on-failure` unit takes as a stop, and then tried to start the next fleet inside the CLI's own process. Run from an agent's pane, that process sat in the unit's cgroup and was killed with it, so nothing came back (one host stayed down for 7 hours). Run from a shell, it ran the fleet outside systemd. `agend restart` restarts through whatever owns the fleet — the systemd unit, the launchd job, or a detached hand-off — and `agend restart <instance>` restarts one instance now. `agend fleet restart` [`--reload`] [`<instance>`] still works for this release: it prints a deprecation line and runs `agend restart`, and it is removed in 2.4. A fleet under the AgEnD systemd unit that still gets the old reload signal (from an older CLI) now exits so systemd starts it again. The chat's `/restart` is unchanged.
