# CHANGELOG fragments

One entry per file, in English and zh-TW: `<issue>.md` and `<issue>.zh-TW.md`, each with
`section: Upgrade Notes|Added|Changed|Fixed|Security` front-matter and the list item(s) below it.
`scripts/changelog-assemble.mjs` moves them into `docs/CHANGELOG*.md`. Format and rules:
[docs/development.md, "CHANGELOG fragments"](../docs/development.md#changelog-fragments).
