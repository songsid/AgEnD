- **`/login` installs a missing CLI without ever waiting on a prompt, and shows its output in the chat.** The installer now runs with no terminal to ask on (`setsid`, stdin from `/dev/null`), so a question that nobody can answer (sudo's password, kiro's "replace it?", a new codex question) fails at once with its last lines instead of holding the install window for 10 minutes. It runs at low CPU and disk priority, so the fleet and its chats keep their share while a ~0.5 GB release downloads and unpacks. Closing the window (cancel, the 10-minute timeout, a fleet stop) now stops the whole install. The installer is given your account's login shell, so its PATH line goes into the rc file your own terminals read. An installer that ended at once no longer loses its exit code. The chat that asked for the install now gets one message, edited every few seconds, with the installer's last 15 lines (ANSI removed, secrets masked), and its final state at the end: finished, failed, or stopped by the timeout. The old hint to "watch progress in the View page" pointed at a page that never showed the install and is gone. (#2980)
