- Hub: the administrator chooses how long a sign-in lasts, in Administration → Sign-in. People are signed out after a set time from signing in (1 hour to 7 days, default 8 hours), or after a set time without using the Hub (15 minutes to 24 hours, default 1 hour). An open Hub page counts as using it. A shorter time also signs out anyone already signed in longer than it. (#4397)
