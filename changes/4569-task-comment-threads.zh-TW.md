- **任務卡上的留言可以回覆、反應、編輯、解決、刪除、複製連結，也可以指定這則留言要給誰（#4335）。** 卡片頁每則留言右上有反應按鈕和 ⋯ 選單：回覆（回覆縮排顯示在討論串底下）、加反應、編輯（只有作者能改，會標「已編輯」）、解決討論串（收合成一行，可以再展開）、複製（照原樣的 Markdown）、複製連結（打開後會捲到那則留言並短暫標亮）、刪除（作者或人可以刪；原位置會留一行，底下的回覆才讀得通）。留言框底下有一個收件 chip，說明這則留言要給誰：預設是卡片的負責人，顯示「dev · 送出後開始處理」；回覆時預設是被回覆那則的作者；負責人是人、沒有負責人或卡片已完成時，顯示「不通知 agent」；列表有負責人、派工者、關注者、leader 和 fleet 裡其他的 Agent。文字裡寫 `@名稱` 的方式照樣可用，與 chip 並存。選了別人，留言就送給那一位，不再送給負責人。編輯不會叫醒任何人，除非新文字比舊文字多 `@` 了某個 agent；反應、解決、刪除都不叫醒；防迴圈的上限也會計入收件對象，所以兩個 agent 不能只靠回覆互相無限叫醒。agent 在 `agend-agent task update` 與 `task` 工具上有 `reply_to`，並用 `edit_comment` 編輯自己的留言；`task get --detail` 會顯示每則留言的編號（`c12`）。降版不會遺失資料：新欄位與新資料表都是只增不改，舊版會把編輯過的留言讀成新的文字，刪除的留言讀成空白留言。
