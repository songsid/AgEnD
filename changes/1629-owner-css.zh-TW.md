- **網頁：你自己的自訂 CSS（#1629）。** **設定 → 網頁外觀** 可以放一份樣式表，只套用在你自己的畫面，你登入的每一台裝置都會套用。
  - 它不會套用在設定頁、登入頁、臨時公開連結，或沒有登入的 `/view`。
  - **儲存並試用：** 每次儲存的版本都先試用，15 秒內按 **保留**，否則會自動還原，即使分頁被關掉也一樣。
  - 它無法從網路載入任何東西。圖片和字型放在 **資源**（會移除中繼資料），用 `url("asset:<id>")` 引用。`@import`、script 網址和較危險的 CSS 函式會在儲存時被拒絕，並說明原因。
  - 保留最近五個版本。每台裝置可以各自關閉；在任何頁面網址加上 `?safe=1`，就能不套用它地載入一次。
