- Hub 管理頁加上分頁：**總覽**（預設）、**管理項目**（原本的頁面）、**團隊**、**群組**、**這個 Hub**。總覽只用數字呈現 Hub 的使用情形，可選 **今天** 或 **7 天**，依你的時區計算，每分鐘更新：
  - **使用的人：** 今天與這週有使用、這週加入、目前登入中。
  - **提問：** 每天的提問數、一般與最慢的回答時間、沒有得到回答的提問及原因、最常被問的 Agent。
  - **Fleet：** 已連接、需要更新、版本太舊無法使用房間、版本不明。
  - **房間：** 人、Agent 與房間助理的訊息數、有活動的房間、在房間裡問 Agent 的次數、被停止的 Agent 互問。

  不會顯示任何人問了什麼或答了什麼，不按人統計，也沒有 token 或費用。還沒有人加入的 Hub 會改成顯示 **讓同仁加入**。
