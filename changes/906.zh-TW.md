- **共用工作目錄的 kiro instance 不再看到彼此（#906、#1410）。**
  - 每個 kiro instance 現在以自己的 kiro agent 執行，只包含自己的 AgEnD MCP server 和指示。
  - 它用 id 恢復自己的對話。
  - 以前同一個目錄裡的兩個 kiro instance 會啟動彼此的 AgEnD server、讀到彼此的指示；甚至可能「變成」對方：單純的 `--resume` 會拿走目錄裡最新的對話，連同它存檔時的 agent 一起帶回來。
  - 你自己的 MCP server（全域與工作目錄的 `mcp.json`）仍會載入。
  - 需要 kiro-cli 2.21 以上；較舊的版本照舊執行，並在 instance 啟動時說明。
