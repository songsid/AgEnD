- **Agent 可以檢查、上傳、取代、刪除與還原辦公室畫面的外觀包，背後有個沒人打開就關著的開關。** 替某個 agent 打開 **辦公室外觀包**（Dashboard 權限；`office_pack_access: true`，和 `office_access` 分開的獨立開關）後，它就有 `office_pack_check`（主機自己的檢查，什麼都不存：`PACK OK` 或第一個拒絕原因）、`office_pack_upload`（與網頁上傳相同的檢查與上限；fleet 已經有的 id 會直接取代——先檢查、先寫好，再一次換上，任何失敗都保留舊版——並保留上一版）、`office_pack_delete`、`office_pack_restore`（回到保留的上一版）、`office_pack_list` 與 `office_set_style`。外觀包是 agent 工作目錄或 fleet 共享資料夾裡的資料夾，由 agent 這一端讀取（realpath，只讀 manifest 指名的檔案）。會讓已存辦公室的版面調整失效的上傳會被拒絕，並說出是哪個辦公室、哪條規則，除非 `drop_invalid_overrides: true` 只移除那幾項（座位保留一次只移除一個座位的，絕不會移除整個辦公室的版面）。每次變更都會連同 manifest 與每張圖的 sha256 記錄下來，並在 General 通知管理者；管理者在辦公室頁面（編輯辦公室 → 會改外觀包的 agent）選擇 **要我核准**（預設：變更會等到在那裡或從通知按鈕核准）或 **直接套用**。每個 agent 每小時最多 20 批、200 MiB（#2692）。
