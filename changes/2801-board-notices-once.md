section: Changed
---
- **Task board notices: once per change, to one agent (#2801).** A card now notifies only when its status or assignee changes, and only the agent that acts next. A comment notifies nobody (the card lists new comments for its assignee in `task mine` and `task get`), and neither does a confirmation, because the work is finished. A send-back still notifies. A main task that goes to review by itself before it is wrapped up is now one notice, to the agent that handed it out, naming what is missing. An agent's change that it already told the other agent in its own message, naming the card within 2 minutes, is not repeated by the board. This used to cover only assignments, with a 30-second wait; it now covers every change and waits up to 2 minutes for that message. A notice still waiting to be delivered is dropped once every card on it has changed status or assignee again. It shows as `cancelled` ("superseded") in `delivery_status` and Fleet traffic.
