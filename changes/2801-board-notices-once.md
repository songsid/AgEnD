section: Changed
---
- **Task board notices: once per change, to one agent (#2801).** A card now notifies only when its status or assignee changes, and only the agent that acts next. A comment notifies nobody (the card lists new comments for its assignee in `task mine` and `task get`), and neither does a confirmation, because the work is finished. The one exception is an answer to an agent's blocked question while it is busy with another card: the answer waits on the card, and the agent is told so. A send-back still notifies. A main task that goes to review by itself before it is wrapped up is now one notice, to the agent that handed it out, naming what is missing. If an agent already told the other agent about a change in its own message naming the card, the board doesn't repeat it. For an assignment, a message up to 2 minutes before or after counts. For any other change, only a message sent after it, within 2 minutes, counts. This used to cover only assignments, with a 30-second wait; it now covers every change and waits up to 2 minutes for that message. A cancel is told at once. A notice still waiting to be delivered is dropped once every card on it has changed status or assignee again. It shows as `cancelled` ("superseded") in `delivery_status` and Fleet traffic.
