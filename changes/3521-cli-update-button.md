- **Update an installed AI CLI from Settings, to the version AgEnD has audited (#3521).** On Settings → Agents → **AI accounts and API keys**, an installed CLI now shows its version beside the newest version AgEnD has audited. When it is older, the row has **Update to \<version\>**: it runs the CLI's own official installer pinned to that exact version (Claude Code, Codex, OpenCode, Grok, Kiro) in the same install window `/login` and the Install button use — one at a time, cancellable, with the version before and after, or the installer's exit code and last lines. It never goes to "latest". A CLI that updates itself in the background (Antigravity, Muse) shows both versions and no button; one that is newer than anything audited says "not verified by AgEnD yet". On Settings → Runtime, a Windows computer's Claude Code or Codex that is older gets **Update to \<version\>**, which is the same pinned install with every check of the Windows install (exact version, hashes, registry signatures, publisher signature); the pins moved to the newest audited releases (Claude Code 2.1.318, Codex 0.166.0). The page sends only the CLI's id, and who may update is the same as who may install.
