- **Settings → Accounts: a paired Windows computer's Claude Code accounts.** Under each paired computer's name the Accounts view now lists that computer's accounts as its Runtime reports them, with the masked account and plan. Where the computer's owner has turned `agend-runtime remote-setup accounts on` there, a fleet admin can **+ Add account**, **Sign in**, **Sign out…** and **Remove…** an account that computer's Runtime created, from the dashboard. Sign-in is the same link-and-code dialog as on the host, run by that computer's Runtime. Anything else is shown read-only with its reason and the command to run on that computer: it is offline or its Runtime is too old, the owner has not allowed it, or the account was made by hand or by an older Runtime. The Windows user's own sign-in is never changed from here, an Anthropic Console account is signed in on that computer with `agend-runtime login`, and a computer reports no usage. Remove is refused while an agent or the computer's own default uses the account. The sign-in link and code are never stored by the server. **Upgrade the server and its Runtimes together:** the Runtime now also reports whether it created each account (`created`), and a server from before this change rejects an inventory that carries it.
