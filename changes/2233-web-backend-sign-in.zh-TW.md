- **不需要聊天連線，也能從網頁 dashboard 讓後端 CLI 登入（#2233）。** 在這台機器或它的網路上登入 dashboard 的 fleet 管理員，不必透過 Discord 或 Telegram 就能讓 Claude Code、Codex、Kiro CLI 或 Grok 登入：
  - **設定 → Agent → 登入** 列出每個 backend 的登入，以及代理使用的每個憑證設定檔，附 **登入**；
  - 網頁的 `/backend` 選單在未登入的 backend 旁提供 **登入 <backend>**；
  - **需要你** 在因登入而暫停的代理上提供 **登入**。

  流程和 `/login` 相同，檢查與 10 分鐘的時限也一樣。裝置碼顯示在對話框裡；瀏覽器終端機登入的連結和一次性存取碼只顯示給這個瀏覽器工作階段，取代私訊。進行中時每個管理員頁面都會顯示，只有啟動它的瀏覽器看得到代碼。訪客和公開連結永遠不會看到這個功能；啟動它的瀏覽器工作階段結束時，登入會被取消。
