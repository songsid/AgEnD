- **kiro V3 instance 提出的問題現在會送到聊天，也能直接在聊天裡回答（#2675）。** 當 agent 提問，或 MCP server 要求輸入時，kiro V3 會用一張卡片取代輸入框。以前只有在終端機前的人看得到、答得了，訊息也全卡在後面。現在 AgEnD 會把卡片貼到該 instance 的頻道與網頁聊天。問題的每個選項各有一個按鈕，另有子選項與「略過」。想用自己的話回答，就回覆那則貼文，或使用網頁聊天的回答框。MCP 的輸入要求可在聊天裡拒絕或取消；欄位與登入連結仍留在終端機。AgEnD 每輸入一步都先確認：卡片若已改變或按鍵沒有生效，就停下並告知。卡片關閉後，訊息遞送會繼續。這類卡片只存在於 kiro V3：legacy 與 tui（V2）不會出現。
