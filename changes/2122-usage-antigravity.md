- The usage report (Fleet → Usage, `get_usage_report`, the CSV) now measures Antigravity: each generation's tokens from agy's conversation databases (input, cache reads, output and its thinking as reasoning), by the conversation's workspace. Claude models are priced at list price; Gemini models read "not priced". The databases have no published format, so they are read only for agy 1.4.x (the versions checked); another version is listed as not measured. With this, every backend AgEnD runs is in the report.
