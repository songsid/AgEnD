- When a Hub recommends a newer AgEnD version, a Fleet admin sees "{Hub} recommends AgEnD v…" on the update line and in Settings → Advanced → Version and update. Update now installs exactly that version. General gets one notice with an Update now button, and a reminder every 7 days while the Fleet is still behind. On a web-only Fleet, the update notice now points to the web Update instead of saying it is unavailable.
