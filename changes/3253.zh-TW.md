- **Grok 週限重設後會按 Try Again（#3253）。** AgEnD 記下 grok 週限的重設時間、且該時間已過之後，三選項視窗（升級／買額度／Try Again）會選 Try Again——往下兩次再 Enter；清單不會循環，所以從任何起點都會停在 Try Again——排隊的工作接著跑。同一個暫停週期只會按一次 Try Again；Shift+x 被忽略時不會對仍額度用盡的同一畫面再按 Enter。重設前是 Shift+x 關掉並額度暫停，視窗不會自己再出現。重設後的 Try Again 涵蓋啟動／卡住還在畫面上的視窗，以及仍開著的視窗。同一台主機若有多個 grok 帳號，記下的時間是車隊額度歷史裡最後一筆 grok 週限 `resetsAt`，可能屬於另一個帳號；提早按 Try Again 會再秀出視窗，接著 Shift+x 暫停。
