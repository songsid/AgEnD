section: Fixed

- **更新不會再讓主機變成沒有 `agend`，而且再執行一次安裝程式一定能修好（#2264）。**
  - 更新現在由新版本自己的安裝程式執行：`agend update` 透過 `npm exec` 執行它，安裝的一行指令也一樣。安裝、更新、修復是同一個程式。
  - 安裝程式會先修好中斷的安裝留下的東西：
    - npm 移到旁邊的那份 AgEnD 會被放回去或移除；
    - 沒有人持有、或讀不懂的安裝鎖會被移除。
  - 接著安裝新版，並確認 `agend --version` 能執行。新版沒通過這項檢查時，會重新裝回前一版。
  - 手動 `npm install -g` 不會再因為鎖而被拒絕。
  - 艦隊的使用者服務現在會開啟 systemd linger，並自己找到執行期目錄，所以 `agend start`／`restart` 從任何 shell 都能用（包括 WSL 上的 root）。啟動更新的那次登入結束時，更新也不會再被中斷。
  - 聊天裡的更新訊息一定會有最終結果。艦隊重新啟動後的版本和更新的目標不同時，會直接說出來，並給出完成更新的一行指令。
