- **辦公室等級：徽章與名片（#2661，第 2 部分）。**
  - 每個名牌左上角都有等級徽章，顏色依階級，使用 dashboard 的狀態色。超過 999 的等級寫成 1.1k。升級時，那個人頭上會短暫出現光圈，同一區的人會轉頭看過來。
  - 點擊某個人，或在桌子清單的項目上按 Enter，現在會打開他的名片，而不是聊天。雙擊仍會直接打開聊天。
  - 名片是寬 320 px 的浮出卡片，在那個人旁邊，他走動時會跟著。再點同一個人、按 Esc，或點其他地方就會關閉；在手機上是畫面底部的面板，往下滑即可關閉。
  - 名片顯示名稱、instance 名稱、狀態與頭銜、等級與 XP 條、辦公室與區域、模型與 backend、今天的工作量與請求數、首次出現至今的天數、動態，以及 **在辦公室找他** 與 **聊天**。
  - token 列只在用量報告有提供的地方顯示。分享連結的名片只顯示名稱、頭銜、狀態、辦公室與等級。
  - 外觀包的 `levels` 可以自訂頭銜（`titles`），也可以把頭銜固定給某個 instance 或 NPC（`fixed`，可加 `hideLevel`）。
  - **設定 → 網頁儀表板 → 辦公室等級** 可以關閉或開啟等級。
