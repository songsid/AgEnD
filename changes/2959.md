- **Two bots no longer drop the same picture (#2959, reported by hxhsandy).** When two bots on one host received the same Discord or Telegram attachment in the same millisecond, they saved it under the same temporary name in the shared inbox. One ClassicBot then copied and removed the file before the other could, so the second logged "Attachment copy failed — skipping" and the picture never reached its agent. Each download now gets its own name.
