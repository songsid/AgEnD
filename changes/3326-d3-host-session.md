section: Changed
---
- **First run with no General: the host's own session confirms in the dashboard.** On a fleet with a chat connection, a held Settings change that no General can take used to wait for a command on the AgEnD computer. Now, if you signed in with `agend web` on that same computer and are using the dashboard there, the change is confirmed when you press Save. Nothing else to click, and no command. A change that a General can take still goes to General. A session that signed in another way, a request that came through a proxy or from another computer, or one over the public link still waits. Changes that open the named or quick link are not included.
