- **設定頁不再要求填寫工作目錄，並提供繁體中文。** 在 `agend setup` 的頁面（Windows 安裝程式開啟的那一頁），「只用網頁」和接 bot 兩種設定都可以不填工作目錄。這時 agent 會有自己的資料夾 `~/.agend/workspaces/<名稱>`，也就是 AgEnD 建立沒有指定目錄的 agent 時使用的資料夾。頁面會在欄位下方顯示這個路徑，主機確認後建立資料夾，fleet.yaml 也會寫入完整路徑。若自己填寫，仍必須是絕對路徑；既有的 agent 保留它自己的目錄。設定頁和輸入代碼的頁面現在有英文和繁體中文：預設跟隨瀏覽器的語言，頁面上方的按鈕可以切換，選擇也會沿用到同一個網址的儀表板。主機可能回覆的每個錯誤都有翻譯，後端登入卡片也會跟著頁面的語言，在儀表板裡也是（#2726）。
