- **任務看板會在接手者停下來時通知派工者（#3647）。** 接了卡的 Agent 當掉沒恢復、暫停（登入到期、用量上限、錯誤）、看起來卡住、卡在沒人回覆的提示上超過 10 分鐘，或接了卡 60 分鐘都沒有動靜時，派出這張卡的 Agent 會收到一則「[Task board]」通知；恢復後再收到一句「已恢復工作」。長時間的背景工作（子 Agent、背景任務）和在等別人回覆不算沒有動靜；預定的重新啟動和更新期間不會發通知。派工的是人時，沒有動靜的接手者會出現在「等你處理」。`task list` 加上 `stale: true` 會列出這些卡。門檻在「設定 → Agent 預設 → 接手者停下來時」（`defaults.task_board.liveness`）。AgEnD 只會通知，不會自動重啟或改派。
