- **Web：每個文字欄位都能用 Ctrl/⌘+Z 復原、Ctrl+Shift+Z / Ctrl+Y / ⌘⇧Z 重做，且每個欄位各自一份紀錄（#2342）。** 瀏覽器原生的復原是整頁共用一個堆疊：在一個框裡復原可能改到另一個框，而頁面填進框裡的文字也會把紀錄清掉。現在每個框都有自己的紀錄：打字以一個詞為單位復原，輸入法組字算一步，頁面填入的內容也能復原（Tab 補完的 `/指令`、放回、改為文字、最近搜尋、用 Esc 清掉的篩選、選定的 emoji、還原的 CSS），瀏覽器自己的編輯選單復原也走同一份紀錄。已送出的訊息不會被復原回輸入框。原本會修剪輸入內容的欄位（bot token、Discord ID、設定精靈、工作階段時數）現在會保留你打的空格，含空格的路徑也能輸入了。
