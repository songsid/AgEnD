- **只用網頁的 fleet 可以從外面使用，用驗證器 App 登入。** 在 AgEnD 電腦上，到「設定 → 存取與安全 → **從外面連線**」：設定 Authy、Google Authenticator 或 Microsoft Authenticator（掃描 QR 碼或輸入金鑰，再輸入 App 的 6 位數代碼），然後開啟 **允許從外面連線**。公開連結會開啟，從連結登入時會要求輸入 App 的代碼。這樣登入後就是這台電腦的管理者：可以在「需要你」核准 agent 的請求，也能套用自己的設定變更。
  - 設定、重新設定、移除，以及開關本身，都只能在 AgEnD 電腦上變更。關閉時連結會關上，所有從外面登入的人都會被登出；設定新的 App 也一樣。
  - 代碼錯誤：連錯 5 次後，從外面登入會暫停 15 分鐘，再錯則依序 30 分鐘、1 小時……最長一天；輸入正確代碼即重新計算。每次暫停與每次從外面登入都會記在「通知」。
  - 快速連結每次開啟網址都不同，時間到會自動關閉開關；請在 AgEnD 電腦上重新開啟。手機遺失？請在 AgEnD 電腦上選「重新設定」。(#3008)
- **只用網頁的 fleet 也可以有 General。** 在設定裡把一個 agent 勾選為 **General**；不會有第二個（設定會說明哪個 agent 已經是 General）。它會固定在聊天清單最上方。設定頁的 **只用網頁** 現在會把第一個 agent 命名為 `general` 並設為 General，與聊天平台相同；若自己填了工作目錄，它就是一般 agent（`agent-1`）。之後加上 Telegram 或 Discord 時，它會成為該聊天的 General。(#3008)
