- **A rate-limited or monthly-capped kiro instance is reported (#1636).** When kiro is throttled it prints `⚠️  Kiro rate limit reached:` and `Request quota exceeded. Please wait a moment and try again.`, and at its monthly cap `Monthly request limit reached` with the date the limits reset. Neither comes with the "Kiro is having trouble responding right now" header or an exception name, so neither matched any of AgEnD's kiro patterns: the instance was never flagged and nobody was told. Both are now a rate limit that notifies, as kiro's other throttling messages do. An expired login on the same screen still pauses first, and a message that merely quotes these lines does not trigger anything. The upstream-release precheck also no longer reports a CLI's strings merely being stored in a new order as a new prompt.
