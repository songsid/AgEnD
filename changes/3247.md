- **Hub (experimental, alpha): files in Hub questions and answers.** A Hub asker can attach files to a question, and the answering agent can send files back with `report_result`. Allowed types are PNG, JPEG, GIF, WebP, PDF, text, Markdown, CSV, JSON, Word, Excel, PowerPoint and HTML. Each file can be up to 20 MB, with 10 files and 50 MB per message. Files reach the agent's inbox the same way chat uploads do. The Hub stores them encrypted, removes them with the rest of the content under its retention setting, and records every upload, transfer and download in the audit log. Downloads are never run or shown inline, except a checked image. A fleet or Hub that hasn't been updated says it can't take files yet, rather than dropping them. The Hub page's Attach button follows in the next update.
