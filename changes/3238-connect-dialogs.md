section: Changed
---
- Connecting an AI account (Settings → AI accounts): the provider's sign-in page is now step 1, a large button showing the page's address (such as auth.openai.com/codex/device) with Copy link. The authorization code is step 2, in large type with Copy. Step 3 says to come back, and the window updates by itself. This works on a phone too.
- When the account is connected, the window now says so in one line and adds one plain line on which agents reloaded to use it, or that none needed to. It no longer shows the chat's two status lines, which repeated each other.
