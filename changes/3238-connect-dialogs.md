- Connecting an AI account (Settings → AI accounts): the steps are numbered. Step 1 is Open sign-in page, with Copy link beside it and the page's address (such as auth.openai.com/codex/device) under it. Step 2 is the authorization code in one box with Copy. A note says the window updates by itself when you come back, and Cancel connecting sits at the bottom left. The connect window for the default account now looks the same, without a second box inside it. This works on a phone too.
- When the account is connected, the window shows a green banner with a check mark, then the agents that reloaded to use it, as tags, or one plain line when none needed to. It no longer shows the chat's two status lines, which repeated each other.
