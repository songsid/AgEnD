- Connecting an AI account from chat (/login): after "Your … account is connected", the next message is now one plain line. It names the agents that reloaded to use the account (by their display names), or says that no agent uses it yet, that some are still reloading, or that they could not be reloaded automatically. It no longer says "instance", splits agents into woken and restarted, or repeats the ✅.
