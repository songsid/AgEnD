- **A Windows Codex agent stopped before its first turn now starts a new conversation on its own again (alpha).** Codex keeps an unsaved database log after it exits, and AgEnD read that as "can't tell". So every such agent waited in **Needs you** for an administrator, even though its conversation had never been saved. AgEnD now reads that log from a private copy, never changing Codex's own files. A conversation that was never saved gets one new conversation, with the usual notice. Anything AgEnD still can't confirm keeps waiting for an administrator.
