- **kiro-cli 2.34.0：訊息不再被送進 kiro 新的「Input requested」卡片（#2587）。** 在 2.34.0 的 V3 引擎裡，當某個 MCP server 的工具請你輸入資料（表單或登入連結）時，kiro 會用一張卡片取代輸入框。AgEnD 先前把這個畫面當成空閒的輸入框，下一則訊息就被貼進卡片：文字遺失，送出的 Enter 還會接受或改動當時選取的欄位。現在這張卡片會被擋住：在你於 instance 畫面裡回答或取消之前，不會送出任何訊息、也不會按任何鍵，因為答案可能是憑證或登入。kiro 2.34.0 的其他啟動畫面都和 2.33.1 相同（已實機重新擷取），2.34.0 啟動時也不再出現「未測試版本」警告。
