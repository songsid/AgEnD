- **設定 → 網頁 → 網頁授權（#1939，第 2a 步）。** 網頁授權的設定現在可以在儀表板上調整。
  - **開關：** 網頁訊息是否帶有已登入帳號的授權，以及「只有這台電腦可以授權」。後者關閉時，若 `web.allowed_hosts` 裡有從其他地方連到 dashboard 的主機，會特別提醒。
  - **有效期：** 一次 session 授權維持幾小時（1–48，預設 48）。
  - **已授權的 session：** 列出每個 session 的裝置、帳號與到期時間。
  - **撤銷網頁授權：** 讓到目前為止給出的所有授權視為無，並結束所有授權，不會登出任何人。
  - 開關預設開啟：session 要等它的帳號在 Discord 或 Telegram 上確認後才帶有授權。這裡的每項變更都立即生效。
