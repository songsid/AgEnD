- **貼上一行指令，就安裝並連線 Windows Runtime：不限電腦、免配對碼、免核准。** **設定 → Runtime → 連接電腦**現在會產生一個短效、只能用一次的安裝指令。在任何連得到這台 AgEnD 的 Windows 電腦的 PowerShell 貼上，或交給在那台電腦上執行的 AI agent 或 CI 工作，它就會安裝 Runtime，並在同一個視窗接著連線，不論視窗是不是互動式（`powershell -NonInteractive` 也可以），連上後讓它在背景持續執行（見下）。指令帶著一個一次性 token：256 位元隨機、15 分鐘內有效且只能用一次，AgEnD 只存它的 SHA-256，按**撤銷並關閉**或重新產生指令會立刻讓它失效，每次發出、使用、撤銷與被拒絕都有紀錄。它由和配對碼相同的人、經過相同的儀表板 session 檢查發出，所以不會多給任何本來就不能配對電腦的人權限。指令也帶著 AgEnD 的伺服器指紋：Runtime 先確認連到的伺服器提出了 Ed25519 證明，才送出 token；token 走 Runtime 的標準輸入（不放在命令列參數、環境變數或檔案），並用 X25519 協商出的金鑰以 AES-256-GCM 加密，所以只把身分檢查轉給真 AgEnD 的中繼伺服器，讀不到 token，也讀不到帶回的憑證。電腦以這種方式加入時，AgEnD 會透過一般的通知管道**主動通知擁有者**（電腦、主機、token id 與撤銷方法），Runtime 頁面也會顯示（**有新電腦透過安裝指令加入**，附**撤銷**）。已經連到這台 AgEnD 的電腦只會重連，不消耗 token；連到另一台 AgEnD 的電腦會另開獨立的 profile。token 過期、已使用、已撤銷、格式錯誤、伺服器不符時，各自以清楚的訊息和非零 exit code 停止。
- **配對碼放在手動選項裡。** 沒有 token 的指令在互動式主控台執行時，做法與 ZIP 的 `connect-agend.bat` 相同：新的 profile 會要求輸入頁面上的一次性配對碼、顯示指紋，再等你在 AgEnD 核准；已配對到這台 AgEnD 的 profile 直接重連，不要求配對碼。其他情況（AI agent、CI、被管線串接，或設定了 `CI`、`GITHUB_ACTIONS` 等常見 CI 環境變數的偽終端機）或設定了 `$agendNoConnect = 1` 時，只安裝，印出下一步要執行的確切 `agend-runtime connect --server "…"` 指令，並以 0 結束。配對碼仍然只在互動式終端機輸入。
- **安裝程式會留下重連入口。** `agend-server.json`（只含公開位址）和 `connect-agend.bat` 會放在 `%LOCALAPPDATA%\agend-runtime\connect\<server>`，下次雙擊即可；`agend-runtime` 接受 `--connection-dir DIRECTORY` 來使用這種資料夾，`agend-runtime connect` 也新增 `--enroll-stdin` 與 `--server-fingerprint`。`install.ps1` 是被頁面雜湊固定的同一份位元組。在指令有效且未使用時拿到它的人，可以把自己的電腦註冊成你的 Runtime，所以請把它當成密碼；`docs/SECURITY.md` 直接說明了這個風險，細節見 `docs/remote-runtime.md`。擁有者的「有電腦加入」通知在當下沒有聊天目的地時，會先保存，直到確認送達（平台收下，或儀表板通知已寫進磁碟；被平台拒絕會重試；超過 100 則未送達時，最舊的會合併成一則摘要）。這取代了先前「安裝指令不會連線」的說法。
- **有電腦要求配對時會跳出核准對話框，等待核准的電腦排在最前面，同名的電腦也分得出來。** 在**設定 → Runtime** 裡，等待核准的電腦不再把它的**核准**按鈕擠到很長的清單底下：頁面會自己跳出對話框，顯示電腦名稱、主機名稱、平台、要求時間，以及**大字的配對指紋**，請和那台電腦終端機上的指紋比對。**核准**仍然帶著指紋送出，對話框出現後的前一秒保持停用，也不會把焦點放在按鈕上；**拒絕**會直接丟掉要求、不再多問一次，而且對在另一個分頁剛被核准的電腦會被拒絕（409，不撤銷任何東西）；**稍後**、Esc、點背景和 × 都只是關掉，按過稍後的電腦不會再自動跳出。同時有好幾台在等時一次顯示一台，等待核准的電腦排在清單最前面，上方有提示條（「有 N 台電腦等待核准」，按「檢視並核准」）；已過期的要求不會跳出，按「拒絕」可以清掉；同名的電腦會標示 **#1**、**#2**、配對時間，並提示可以重新命名。用安裝指令加入的電腦不會經過等待，會改成顯示它自己的通知。
