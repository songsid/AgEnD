- Web chat: a Markdown file (`.md`, `.markdown`) in a message can now open in the side preview panel, beside the conversation (on a phone, a full-screen sheet). It shows the file formatted or as its source, with full screen and Download. It is drawn by the chat's own safe Markdown renderer, so nothing in the file runs; files over 1 MiB are offered as a download, as in the chat's own card. The card in the chat works as before.
