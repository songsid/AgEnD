- **nvm-route update no longer fails when the old root copy can't be sudo-removed (#1660).** Retiring the old system copy is cleanup: once the new version is installed, verified and running, a refused `sudo -n npm uninstall` becomes a warning instead of exit 1. Chat `/update` reports success plus one line naming the manual removal (`sudo <npm> uninstall -g @songsid/agend`, with the leftover path when resolvable). `sudo -n` stays non-interactive — it never prompts for a password. Real install or verification failures still fail exactly as before.
