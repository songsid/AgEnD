- **Export an agent's settings, and load a template from a file.** In Details & settings › Basic info, next to Agent instructions, **Export** writes this agent's saved portable settings — description, tags, the Agent instructions (written text only — a `file:` reference is left out), model, tool set, lightweight mode and the behaviour tuning — as `<role>.agend-agent.yaml` (`agend_export: 1`), with a live preview and Copy / Download. Only an allow-list is ever written: accounts, API keys, channel and topic ids, the working folder, machine ids, permissions (`dashboard`, `skipPermissions`), `pre_task_command`, status emojis and the display name never are, and a Description or Agent instructions text that looks like a secret blocks the download until it is removed. **Load template** reads such a file (choose it or paste it), shows what will be filled in and what is skipped and why, then fills the form — you still press Save and confirm as usual. The file reserves a `library:` section for skills and tools later.  A loaded file never fills a `file:` reference into the Agent instructions (it would name a path on another computer), and the text may be at most 24,000 characters, as in the editor. An Agent instructions text over that limit is left out of an export (the dialog says so), so a file never holds what it cannot load back. `deploy_template` and `create_instance` have no `instructions` argument or template key (the Agent instructions are `systemPrompt`); one that is given is ignored.
