- **Windows 安裝程式在設定 WSL 前會先檢查這台電腦，啟用之後也會確認真的啟用了（#2650）。** 它會先看 Windows 組建、架構、WSL 需要的兩個 Windows 功能（Windows 子系統 Linux 版、虛擬機器平台），以及虛擬化有沒有開。Windows 舊於 Windows 10 2004（組建 19041），或是 32 位元的 Windows，現在一開始就停下來並說明怎麼做，不會到後面才只說「Ubuntu 安裝失敗」。BIOS/UEFI 的虛擬化明顯沒開時，會給明確的提示。安裝程式只啟用缺少的功能；以前只要 WSL 功能已經開著，就不會去開虛擬機器平台。它也會檢查每一次 DISM 的結果，再讀一次兩個功能的狀態，不再不管結果都說「已啟用」。ARM64 的電腦，WSL 的備用下載現在會拿 ARM64 版而不是 x64 版，下載也有時間上限。新安裝時，如果 `wsl --install` 沒有裝出 Ubuntu（例如較舊、不支援 `--location` 的 WSL），會和另外安裝的流程一樣，改用官方 Ubuntu 映像檔匯入。
