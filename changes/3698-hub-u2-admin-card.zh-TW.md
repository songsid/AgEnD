- **Hub 管理頁：用三個步驟「讓同仁加入」（#3698）。** 管理頁的第一張卡片分成三步，每一步都依 Hub 已儲存的設定標示是否完成：
  1. 開啟公司帳號連接。
  2. 決定誰可以加入。用群組名稱的開頭找到 AD 群組，設定每人最多能連幾台 Fleet，按一次「儲存」；這也會同時開啟群組權限。有效的加入碼也算完成。搜尋找不到的群組，仍可以用辨別名稱新增。
  3. 複製一句說明給同仁：「在 AgEnD 的「設定 → Hub」輸入 {host}，再用公司帳號登入。」完成前兩步後才能複製。
- **長的公司連結**移到「含金鑰指紋的連結（進階）」，給需要自己核對金鑰指紋的同仁。個別邀請收在卡片下方。
- **歡迎頁：** Hub 還沒有任何 Fleet 連接時，管理員會看到同一張卡片，不再顯示「你的 Hub 管理員會幫你配對 Fleet」。還沒有 Fleet 的人會看到第三步那句說明；用配對碼連接移到「其他方式」裡。
- **Fleet 清單**以每台 Fleet 的名稱為標題，下方是擁有者；已撤銷的 Fleet 收在「已撤銷（n）」裡。
