- **設定頁的模型清單變短並分組（#3662，屬於 #3636）。** Claude Code 列出帳號自己回報的模型，不列 `opus`、`sonnet` 這類別名；別名仍可在「其他…」輸入，已儲存的值照舊顯示為目前使用中、不會被改寫。`[1m]` 變體只在模型回報 1M 以上輸入、且本來不是 1M 的情況下列出，放在獨立的「1M context（需訂閱／方案支援）」群組；其他 `[1m]` 不再列出。讀不到帳號清單時，會把文件列出的 `claude-*` 模型放在「尚未確認此帳號可用」底下。其他同時有快速清單與完整清單的 CLI 改成先「常用」、再「更多模型」。Antigravity 同一模型的 low／medium／high 版本合併成一項，強度改在「推理強度」下拉選擇，該下拉現在也會出現在 Antigravity。另外，Claude Code 的模型探測不再為回報小於 1M、沒有回報大小、或本來就是 1M 的模型加上 `[1m]` 變體，所以 Telegram `/model` 的「更多模型」不再列出會失敗的項目。
