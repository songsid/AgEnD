- **設定頁連接某個 AI 帳號，不再被另一個帳號擋住。** 先前整個 fleet 只有一個登入視窗，所以沒完成的 Claude Code 登入會讓 Grok 的「連接」顯示「正在連接 claude-code 帳號，請先 /login cancel」。現在每個 backend 各有自己的視窗：不同 backend 可以同時連接（同一個 backend 的登入、安裝、保持登入更新與登出仍然輪流進行）。關閉「連接」彈窗會結束它啟動的登入，而不是讓它再跑十分鐘。若因為該 backend 正在連接而被拒絕，彈窗會用白話說明，並提供「取消那個連接並繼續」按鈕——不必再輸入聊天指令。
