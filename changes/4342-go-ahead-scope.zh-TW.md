- Agent 的指示裡直接寫清楚哪些動作需要確認：只有發佈、超出 Agent 自己工作範圍的破壞性或無法復原的動作、超出正常工作的花費或額度、憑證或金鑰、授權或轉交權限給別人。讀取、查詢、分析、看狀態和記錄，以及 Agent 自己負責範圍內的日常操作，都不需要收據、按鈕或驗證。這五類的確認方式不變。Codex Agent 要改動自己範圍以外、別人在用的東西時，仍會先問（#4342）。
- **擁有者與日常操作**（設定 → Agent → 基本資訊；fleet.yaml 的 `operations`）：選填，寫這個 Agent 負責的系統是誰的、哪些操作在那裡是日常工作。Agent 會在角色說明之後讀到，當成背景資訊；它不會核准那五類需要確認的動作。匯出範本時預設不帶，要勾選才會帶（#4342）。
- **詳細資料 → 每次對話都會讀**：列出 Agent 的 CLI 每次開始對話時讀的檔案、各自的大小和合計；檔案超過 50 KB，或 Codex 的 `AGENTS.md` 超過 Codex 會讀的 32 KB 時會提醒（#4342）。
