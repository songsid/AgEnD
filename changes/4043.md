section: Fixed
---
- **Antigravity can be connected from Settings → Accounts where its version cannot be read (#4043).** On a host that cannot make a network namespace (Docker with the default seccomp profile, some WSL, macOS), AgEnD could not read agy's version, so the Antigravity card had no **Connect** and named accounts could not be signed in. AgEnD now checks agy's own file for the `acp --login` command, reading it without starting agy, and offers **Connect** for the default connection and named accounts when it is there. An agy known to be older than 1.5.0 is still told to update.
