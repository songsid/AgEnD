section: Changed
---
- **Settings → "Agent defaults" is now "Shared agent settings", and says what each setting does (#3065).** The page was named for new agents, but a change here reaches every agent that has no setting of its own, new or existing. It is now two cards: **Shared agent settings** (an individual agent can override these: default backend and model, auto-pause, tool progress, and under Advanced bot-to-bot messages, the reply guard, native replies, tool set, agent mode, log level and dashboard access) and **System & channels** (one value for the whole fleet: language, daily tips, project folders, and under Advanced the hang detector and startup settings).
  - **Who uses a value.** Each shared field shows "6/7 in use · artist custom"; hovering lists the agents that set the field themselves under Agents, so a change here does not reach them.
  - **What a change costs, only once you make it.** The permanent "Immediately / Restart this Agent" labels are gone. After you edit a field, a note under it says what saving does, from the settings schema: how many agents take the new value and how many of them are running (those restart), which ones are left alone, that AgEnD restarts, or that a fleet admin must confirm. Putting the field back removes the note, and the Save bar adds the notes up.
  - **Plain choices.** Tool progress, bot-to-bot messages and agent mode are segmented buttons; daily tips, the reply guard and native replies are switches; tool set and log level describe each option. Each field has an ⓘ explaining what it is for and when it matters. "Default backend" is marked **this host** with a grey line saying that only this host's CLIs are checked and that a Windows PC's CLI is chosen in that agent's own settings (Change runtime / CLI), with a link to the Runtime page. A Windows agent that runs one command at a time has no process to restart, so a change never counts it among the agents that restart.
  - Nothing was removed: every setting is still there and writes the same `fleet.yaml` key, and the field anchors, the Settings search and the "change in Shared agent settings" links are unchanged.
