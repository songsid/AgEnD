- **訪客可以執行聊天裡「任何人」可用的指令，並打開用量面板（#2855）。** 網頁儀表板上訪客的指令選單現在只列出聊天指令表允許任何人在該 agent 頻道執行的指令：`/ctx`、`/steer`、`/btw` 和 `/cancel`，只限訪客看得到的 agent，且只在允許訪客聊天時。其他指令會被拒絕並說明原因。訪客的 `/steer` 或 `/btw` 送到 agent 時會標示為訪客（`via web (guest)`）。每位訪客每分鐘最多 10 個指令，一次一個。訪客也看得到用量面板（◔），也就是主機上每個訂閱的剩餘額度，和聊天裡任何人用 `/usage` 看到的一樣；訪客不能強制重新整理，每個 agent 的費用報表仍只給管理員。
