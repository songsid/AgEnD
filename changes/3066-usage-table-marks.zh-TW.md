- **每個 agent 的用量表更清爽了。** 「Fleet → 用量」不再為每個註記在列下方加一個標籤。只有會改變數字解讀方式的資訊會保留，以小記號呈現、原因放在提示文字中；表格下方的圖例只列出實際出現的記號：
  - **◐** 部分定價、**†** 金額由 CLI 回報、**≈** 估算值（Kiro）。
  - 缺少的數字顯示為「—」，提示文字會說明原因（「未定價：…」、「Codex／Muse 不回報快取寫入」、「這個 CLI 不回報」）。
  - 在 AgEnD 記錄 backend 與 profile 之前讀取的時段，改為在表格下方顯示一則說明，而不是每列一個標籤。
  - 「推理」與「訊息數」欄在每一列都會是「—」時不顯示。
  - 未記錄憑證 profile 的 Codex 時段會顯示「未記錄 profile」。
  - 計價依據那一行更短了；訂閱方案的說明移到它的提示文字中。

  CSV 與 `get_usage_report` 的各個標記維持不變。(#3066)
