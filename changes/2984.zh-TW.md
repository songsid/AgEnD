---
section: Fixed
---
- Windows Claude 終端代理不再反覆續接尚未儲存的對話。執行端確認對話檔不存在時，只自動開一次新對話並通知；無法確認時會出現在「等你處理」，由管理員按「開始新對話」。原本的對話識別碼及輸入收據都會保留。主機暫時不可用時保留一般重試；過期的管理員決定不會替換已可讀取的原對話。
- Windows 終端忙碌時，只有執行端明確確認尚未送出的 Enter 才會重新觀察並在限制內重試；不明結果不會重送輸入，達到限制的傳送會保留為未確認並出現在「等你處理」。
- Windows 原生投遞採用一般終端的規則，只因後端自身認得的執行期對話框阻擋 Enter，不再只因輸入框讀取器無法辨認忙碌或續接後的 Codex 畫面而阻擋；僅限輸入框的操作與人類選項回答仍保留獨立檢查。
- Windows 終端忙碌時可在首次貼上前重讀畫面；貼上只送一次，回覆遺失時保留未確認狀態，不重送輸入。
