section: Changed
---
- **Agent 的「Details」頁籤改成「詳細資料與設定」。** Agent 的設定和唯讀資訊放在同一頁，依功能分類：概覽、基本資料、Runtime 與模型、工作目錄與執行、頻道與 Status emojis、進階；寬螢幕在左側、中寬變成頁籤、手機是分類清單。每個設定旁有 ⓘ 說明用途與生效時機，Status emojis 也用白話說明它是什麼。側欄 Agent 列的 ⚙ 一步直達「基本資料」；點 Agent 本身仍然是進入對話。變更先暫存，用與「設定」相同的儲存列與確認流程寫入，`fleet.yaml` 的寫法與以前完全相同。原本頁面沒有的三個設定也補上了：同時處理的看板卡片數、中斷後自動接續工作、MCP 代為回覆。Agent、Windows 原生 Agent、ClassicBot 房間的設定對話框也採用同樣的分組。
- **「設定」與 Agent 頁的選單，現在一眼分得出選單與內容。** 標題列下有分隔線、群組標題明確是標籤而不是連結、寬螢幕的分類欄有底色、中寬變成真正的頁籤並以淡出提示可捲動、手機的「‹ 設定」是整列色塊。
