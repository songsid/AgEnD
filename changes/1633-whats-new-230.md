section: Changed
---
- **What agents are told after updating to 2.3.0 (#1633).** An agent that was running before the update hears, once, what is new for it since 2.2.6: the task board's `task` actions and `[Task board]` notices, replying to a specific web message and reacting to web messages, the per-agent dashboard switches, and (General and coordinators) the CLI changes — `agend restart`, the removed commands, `create_instance` reconciling by itself. Canvas Worker effects are named as experimental and off unless turned on. The bundled `web-dashboard` skill no longer describes 2.2-era features as "2.3 beta", and names `/dashboard` as deprecated.
