section: Security
---
- **配對 Windows 電腦需要透過儀表板頁面。** 產生配對碼和核准電腦，現在都需要在儀表板上登入的管理員，使用頁面上原本的「連接電腦」和「核准電腦」按鈕。只帶 `X-Agend-Token` 標頭的 API 呼叫會被拒絕，無法自行配對電腦。你要按的按鈕和以前一樣，沒有增加任何步驟。
- **登入碼只在 AgEnD 電腦本身發出。** 主機的登入碼請求（`agend web`）現在只回應來自這台電腦的直接請求。只憑 web token，遠端或在 proxy 後面的程式都拿不到管理員 session。印出來的登入碼仍可在任何地方的瀏覽器輸入。
- **威脅模型已寫進文件。** AgEnD 防範的是遠端的人、這台電腦的其他使用者、透過公開連結進來的訪客、網頁訪客與跨站請求。和 fleet 同一個作業系統使用者執行的程式，視為擁有者本人。詳見 [SECURITY](docs/SECURITY.zh-TW.md#威脅模型)。
- **驗證器變更會發出通知。** 在純網頁 fleet 上，驗證器 App 被重新設定或移除時，會發出一則通知，讓你察覺不是自己做的變更。
