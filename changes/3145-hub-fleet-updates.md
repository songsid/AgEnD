- Hub: a Fleet owner can let the Hub's administrator update their Fleet (Settings → Hub, under Shared agents: **Let this Hub's administrator update this Fleet**, off by default; not offered on a Fleet started by hand). On **Administration → Connected fleets**, a Fleet that is behind and allows it has **Update**, and **Update *n* Fleets that allow it** sits above the list; each asks first, always installs the recommended version, waits until the Fleet's agents are idle, and the row shows how it went (waiting, updating, updated, rolled back, cancelled, did not start).
