- **Quote the parts of a message you're answering (#3554).** In the web chat, select text in a message and press 「引用」 / Quote: the passage goes into your message as a quote where your cursor is, with room to answer under it. Do it again for the next passage. On a phone the button sits above the message box and the keyboard stays down, so you can pick several passages first.
