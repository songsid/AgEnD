- **在 AgEnD 電腦上重新登入、連接 AI 帳號、各種「碼」都有名字（#3517）。**
  - 還沒連上聊天時，登入頁不再叫你傳 /web。
  - 在 AgEnD 電腦本機打開登入頁時，會告訴你怎麼在這台電腦重新登入：Windows 點桌面的「AgEnD 儀表板」捷徑，其他系統在終端機執行 `agend web`。自動登入連結已用過或過期時也會這樣說。
  - AI 供應商帳號一律稱為「連接」。設定 → Agents →「AI 帳號與 API 金鑰」→「帳號」顯示「已連接／未連接」與「連接／重新連接／撤銷連接」。要前往供應商官方網站完成授權，供應商給的碼叫「授權碼」。「等你回應」、`/backend` 選單、設定頁、已配對電腦的帳號與 `/login` 用詞一致。
  - 介面裡不再出現單獨的「代碼」：
    - 儀表板的一次性碼與其他裝置的碼是「裝置登入碼」；
    - 驗證器的是「6 位數驗證碼（驗證器 App）」；
    - Hub 的配對碼是「手動配對碼」；
    - 供應商的是「授權碼」。
