- Hub Administration has tabs: **Overview** (the default), **Manage** (the page as it was), **Teams**, **Groups** and **This Hub**. Overview shows how the Hub is used, in counts only, for **Today** or **7 days** in your time zone, refreshed every minute:
  - **People:** active today and this week, joined this week, signed in now.
  - **Questions:** per day, typical and slowest answer times, questions not answered by reason, and the most-asked agents.
  - **Fleets:** connected, needing an update, too old for rooms, version unknown.
  - **Rooms:** messages by people, agents and the assistant; active rooms; agent questions; stopped agent chains.

  It never shows what anyone asked or answered, never counts by person, and has no token or cost figures. A Hub nobody has joined yet shows **Let colleagues join** instead.
