- **Install an AI CLI on the AgEnD host from Settings (#3521).** In Settings → Agents → **AI sign-ins and API keys**, a CLI that is not installed on the host now has its own row with an **Install** button (Claude Code, Codex, OpenCode, Grok, Kiro, Antigravity and Muse: every CLI the registry installs on the host). It runs the same unattended installer `/login` runs in chat — the registry's command, no terminal to ask on, low priority, stoppable, judged by the installer's exit code — so a fleet that is only used from the dashboard no longer needs a shell on the host. The row shows the installer's last lines while it runs, with **Cancel install**; it ends with the version the binary reported, or the installer's exit code and last lines, and then offers **Sign in** like any installed CLI. The page sends only the CLI's id: the command is looked up on the server, and a refused id, a second install while one runs, or a sign-in running at the same moment is answered in words. Who may: a fleet admin signed in on this machine or its network, the same as signing a CLI in from the dashboard; never a guest, a read-only session or the public link. A web sign-in for a CLI that is not installed now points to the Install button instead of saying the page cannot install it.
