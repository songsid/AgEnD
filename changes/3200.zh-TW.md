- **從 fleet 第二個聊天連線建立的 agent 現在能在那裡正常運作。** 在同時有 Telegram 與 Discord 的 fleet 中，由 Discord 的 General（或它部署的範本）建立的 agent，存檔時沒有記下所屬連線，fleet 就把它當成 Telegram 的 agent，它新 Discord 頻道裡的訊息都收不到。現在新建的 agent 會記下建立時所在的連線；`agend ls` 也會顯示 fleet 實際替每個 agent 使用的連線，不再從 topic id 猜測。已經有這種 agent 的話，在 fleet.yaml 替它加上 `channel_id: discord` 再重新啟動即可。
- **fleet.yaml 沒有 `instances:` 區段時，`agend ls` 不再當掉。** 它會顯示空清單，並給出與 `agend doctor` 相同的提示。
