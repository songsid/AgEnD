- 在 npm 12 上安裝和更新 AgEnD：npm 12 預設會略過套件的安裝腳本。安裝程式、`agend update`、Hub 的更新和 install.sh 現在會允許 AgEnD 自己的腳本，讓自帶的 Node 通過檢查、AgEnD 能啟動。如果直接 `npm install -g` 略過了它們，AgEnD 會說明原因，並列出可用的指令：`npm install -g --allow-scripts=@songsid/agend @songsid/agend`。npm 設成略過所有安裝腳本（`ignore-scripts`）時，更新會在改動任何東西之前停下。
