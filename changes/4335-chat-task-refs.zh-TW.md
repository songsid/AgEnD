- **在 instance 的網頁聊天裡引用任務卡。**在輸入框輸入 `#` 就能從看板挑卡（用編號或標題裡的字找），輸入框裡就是它的編號，例如 `#M-3`；手打的 `#M-3` 也有效（沒有 `#` 的 `M-3` 只是文字）。對話裡凡是真的有這張卡的編號，會顯示成帶有編號、標題和狀態的標籤，點了就開啟那張卡；訊息送出時，agent 會在你的文字下面收到卡片的編號、狀態、標題和負責人，以及這個 instance 實際能用的讀整張卡的方式（有 MCP 工具的是 `task get M-3` 加 `detail: true`，CLI 模式是 `agend-agent task get M-3 --detail`；工具組沒有 `task` 工具的 instance 會被告知它沒有）。不是任務卡的編號就只是文字。關掉任務板的 instance 只會收到你寫的文字，聊天會說明是哪個 instance、去哪裡打開。沒有多存任何東西，所以舊的對話照舊顯示；Telegram 和 Discord 的訊息不變。
