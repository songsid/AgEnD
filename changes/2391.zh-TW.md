- **可以決定每個 agent 能在 dashboard 上用哪些功能（#2391，作者 @igs-willyliao）。** 在 agent 上，或在 `defaults` 為所有 agent 設定 `dashboard: { appearance, task_board, web_settings }`（agent 自己的設定逐項優先），就能在工具組之外拿掉整個功能：它在 dashboard 上的外觀、任務看板，或替你改「設定 → 網頁外觀」。未設定代表允許，所以在你關掉任何功能之前一切照舊。關掉的功能，其工具會在下一次呼叫時被拒絕並說明原因（不必重新啟動；ClassicBot 房間也遵循預設值），並立即從 agent 的工具清單移除。沒有任務看板的 agent 不會被要求使用它，重新打開時會告訴 agent 如何開始。設定頁：agent 對話框裡的 **Dashboard 權限**，以及預設值的三個勾選。關閉立即生效；打開要先確認。agent 選「預設」就會重新遵循預設值。**新的 fleet 一開始任務看板是關閉的**：`agend init`、`agend quickstart` 與設定頁會在新的 fleet.yaml 寫入 `defaults.dashboard.task_board: false`。在設定頁的預設值（或單一 agent）勾選，或把它設為 `true`，即可打開。既有的 fleet.yaml 不會被改寫，看板維持原樣。
