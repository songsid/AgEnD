- **任務看板：agent 之間的協作（#2303，#2246 的第 2 步）。** 別人指派卡片給 instance（卡片可以開始時才通知）、幫它開始、退回、
  回覆它卡住的問題、留言、它等的最後一張卡完成、確認或取消它時，instance 會收到 AgEnD 發的 `[Task board]` 通知。10 秒內
  的消息合成一則，一次指派整個計畫時只寫總數；通知由投遞匣保管，等 instance 能接收時再送。卡片會記錄是誰交辦的
  （**派工者**）：卡住的問題會先通知那個 instance，由它來問你，再回到卡上回覆。每個 instance 一次只做一張卡（自己開給自己的卡不算；reviewer 這類角色可以用 `board_cards_at_once` 調高上限）。
  負責人手上已滿時，派工者的回覆會留在卡上，等負責人自己接回來。`task` 工具本身的任務不另外通知（它們本來就附有派工訊息）；
  通知會略過已經無法照做的消息，以及負責人已經讀過的留言。透過公開連結時，看得到的卡片不再顯示隱藏 instance 的相關卡片、
  留言或歷史。還沒補齊
  就送到你這裡的主任務會標**待補齊**，也會通知負責人補，你按確認時會先問一次；主任務卡會顯示現在誰在做。詳見
  [功能說明](features.zh-TW.md#在網頁上fleet--tasks)。
