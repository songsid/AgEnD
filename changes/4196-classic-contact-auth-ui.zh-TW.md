- 網頁：ClassicBot 受限模式與聯絡申請。
  - Agent 頁面新增「**權限**」分頁：房間的模式、工具與命令列防護的涵蓋範圍；Agent 的核准人與常用轉交；以及紀錄。
  - 「**Fleet → 授權**」列出等待核准的申請，可「**核准這一次**」或「**拒絕**」。
  - 「**等你處理**」會顯示等待中的申請，以及建議將舊房間切換為受限模式。
  - 聊天中會標示被攔下的申請（「**聯絡申請 #R…**」）與已轉交的申請（「**已准轉交 #R…**」）。
  - 若防護不涵蓋房間的 AI 工具或版本，頁面會說明該工具以原本的權限執行，只有聯絡申請需要核准。
