section: Added

- **Pair remote Windows runtimes with the shared Fleet (#2936).** Settings → Runtime manages computer pairing, approval, revocation and CLI inventories, with a matching portable Windows Runtime ZIP available directly on that page. New Agents select a computer and its CLI while retaining the existing Instances, chat, models and optional workspaces. The outbound runtime journals execution before launch and reconciles sequenced results after reconnects without automatically replaying uncertain work. The runtime uses the Windows user's existing CLI sign-ins; the coordinator listener and network exposure remain unchanged.
- **Scoped AgEnD tools for native Codex and Claude (#2936).** Per-turn MCP capabilities permit task queries and configured Fleet actions through local or paired-runtime transports. Machine credentials stay outside CLI children, read-only tool scopes remain enforced, and Windows Agent creation or reconfiguration still requires an administrator dashboard action.
- **Complete native Agent creation through settings confirmation (#2936).** The wizard validates and displays the selected Runtime, machine and file-access policy before approval. Approved creation retains its server-owned administrator capability and returns a success receipt after committing the Agent, avoiding `unsupported_sensitive_effect` and false authorization errors.
