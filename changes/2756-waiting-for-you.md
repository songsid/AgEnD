- Task board: **Waiting for you** and its count now list only the cards a person handed out, waiting for their confirmation or blocked on a question to them. This is the same rule as Needs you, so agents' own cards in review no longer pile up there. A card in review says whom it waits for: **Waiting for you**, or **Waiting for** the agent that confirms it. The review column is now **To confirm**. An agent that moves its own card to review, with nobody else to confirm it, finishes it instead. A main task that goes to review by itself tells its agent that it's theirs to confirm.
