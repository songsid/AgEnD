- **Task card comments can be answered, reacted to, corrected, resolved, deleted and linked to, and a comment says whom it is for (#4335).** Each comment on a card's page has a reaction button and a ⋯ menu: Reply (the answer is drawn under its thread, indented), Add reaction, Edit (only its author's, marked "edited"), Resolve thread (folds it into one line that opens again), Copy (the Markdown as written), Copy link (a link that scrolls to the comment and lights it) and Delete (its author or a person; a line stays where it was, so the replies under it still make sense). Under the comment box a chip says whom the comment is for: "dev · starts when sent" is the card's assignee by default, a reply starts as the author of the comment it answers, and a person, an unassigned or a finished card start at "No agent notified"; the list offers the assignee, who handed the card out, the watchers, the leader and every other agent. An `@name` in the words still works, beside the chip. Choosing someone else sends the comment to them and not to the assignee. Editing wakes nobody, except an agent the new words `@`-name that the old ones did not; reactions, resolving and deleting wake nobody; the loop guard counts the recipients too, so two agents cannot answer each other without limit by replying alone. Agents get `reply_to` on `agend-agent task update` and the `task` tool, and `edit_comment` for their own comments; `task get --detail` shows each comment's number (`c12`). Nothing is rewritten and no data is lost on a downgrade: the new columns and table are additive, and an older release reads an edited comment as its new words and a deleted one as an empty comment.
