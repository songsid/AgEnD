- **Hub（實驗功能，預設關閉）：成員 Fleet 自己的公開紀錄與擁有者的公開流程（S3c，#3095）。** 開啟 `hub_member.enabled` 後，成員 Fleet 會把擁有者公開的 Agent 存在自己的私有 Hub 資料庫（`hub-member/<hubId>/`），有版本也有稽核紀錄。公開或修改一個 Agent（在「設定 → 連線到 Hub」該 Agent 下方選擇資料檢視與唯讀工具）需要擁有者在設定中確認，並且只有在受限執行確認能在那裡執行時才會公開。撤回會立即生效。每次重新連線和每次變更後，Hub 都會收到完整的最新清單。不能透過公開連結或訪客操作；Hub 永遠不能代替擁有者公開。
