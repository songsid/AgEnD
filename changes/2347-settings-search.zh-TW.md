- **網頁設定：可以搜尋所有設定（#2347）。**
  - **搜尋設定** 在各區上方，按 **/** 可聚焦。
  - 可用名稱、`fleet.yaml` 的鍵或常用說法找到設定，中英文皆可：「token」找得到 Cloudflare token、bot token 與供應商 API 金鑰；「語言」找得到儀表板與 bot 回覆的語言；「port」找得到固定網址。
  - 結果依區分組，按 **Enter** 或點選就會前往、聚焦該欄位並閃一下。
  - 同樣的設定也會出現在 **Ctrl K** 的 **設定** 群組。
  - 要修正的欄位在其他區時，下方的列會指出是哪一區並帶你過去。
