section: Changed
---
- **Settings: one card style on every page.** Every Settings section now draws its cards with the same border, corners and spacing (24 px inside on a computer, 16 px on a phone). Shared agent settings → General location is now a regular card like the one below it: a labelled field and the Refresh and Save buttons together, instead of a large heading, a bare inline menu and a full-width bar. A long paired-PC or model name no longer runs the card off the right edge. Notifications → Quota notices is now a card too, with its fields side by side, and the page shows its description instead of a raw text key.
