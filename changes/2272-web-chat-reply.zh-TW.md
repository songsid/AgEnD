- **在 web chat 裡回覆某則訊息（#2272）。**
  - **怎麼回覆：** 滑鼠移到訊息上按 **↩**，或按右鍵（回覆／複製文字／複製連結）。手機上在訊息上往左滑（和 Telegram 一樣）或長按；用鍵盤時，在聚焦的訊息上按 **R**。
  - **輸入框** 上方會出現一列，顯示你在回覆誰、回覆什麼（**✕** 或 **Esc** 取消）。送出的訊息會顯示引用，點一下就跳到原訊息。
  - **agent 收到的：** 和 Discord、Telegram 回覆完全一樣的 `(reply_to: "…")`，agent 不需要任何改變。引用由伺服器從原訊息讀出：只有一行，最多 500 字。聊天已不再保存的訊息，或訪客看不到的訊息，都不能回覆。
  - **Discord／Telegram 上的副本** 只有在原訊息本來就在那個頻道時才會引用；只在網頁上的原訊息只會被提到。
  - **不會多給** 訪客或公開連結任何權限。
