- **`agend web` 會替這台電腦的瀏覽器直接登入，第一組登入碼可用一天（#3270）。** `agend web` 開啟的瀏覽器由一個私有的 `0600` 啟動檔導向 `/signin#code=…`，登入碼不會出現在其他使用者讀得到的命令列上（WSL 上改開乾淨的網址，由你輸入登入碼）。頁面在發出任何請求前先把網址列上的片段移除，再兌換登入碼並直接進入儀表板——只在 `localhost`、`127.0.0.1`、`[::1]` 上、只在全新導覽、且瀏覽器還沒有 session 時；失敗時表單會說明，不會顯示登入碼。放進網址的登入碼仍是 5 分鐘。這個 fleet 從未授權過任何主機 session 之前（新安裝；登出或過期不會讓它回來），`agend web --code`（或 WSL 上的 `agend web`）印出、由你輸入的第一組登入碼有效期 24 小時：只能從這台電腦兌換（公開連結、LAN 主機名稱、經過代理一律不行），第一個主機 session 一建立就失效，從這台電腦輸錯五次仍會讓它作廢。登入斷路器不變。
