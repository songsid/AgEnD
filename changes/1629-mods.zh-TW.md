- **Mod：帶著一套外觀的單一檔案（#1629）。** 在 **設定 → 網頁外觀 → Mod** 分兩步匯入 `.agendmod.json` 檔案。
  - 會先檢查整個檔案並列出全部內容：主題與圖片、身分卡文字、小工具的樣子、效果（Canvas Worker 效果仍是 2.3 beta），以及完整的自訂 CSS。
  - 只有勾選的部分會一次套用；任何一部分失敗就什麼都不變。檔案裡的自訂 CSS 永遠不會預先勾選，套用後會先進入試用，由你保留或還原。
  - 已安裝的 mod 可以重新下載、在確認後換成新版本，或解除安裝。**匯出 mod** 會用目前生效的外觀做成檔案。
  - Mod 是已登入的人才能做的事，透過臨時公開連結無法使用。
