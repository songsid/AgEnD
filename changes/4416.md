- Web guests: a guest who signs in with the `/web` code sent privately to their own Discord or Telegram account is now verified as that account. Their session menu says **Guest · Verified until …**, and the same private message says so, with **Not me** to sign that browser out. This is identity only: a guest still has a guest's access, and agents never take a guest's message as approval for anything that needs one. Revoke web authority, the web authority switch, "Only this computer can authorize" and the link options end it, as they do for an admin's browser.
