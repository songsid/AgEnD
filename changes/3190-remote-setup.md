- **A Windows computer's local administrator can now let AgEnD manage Claude accounts on it (Runtime side; no dashboard screens yet).** `agend-runtime remote-setup accounts on [--for 2h]` (and `install`, reserved for CLI installs) are two switches that are off by default, set only on that computer, and can turn themselves off. With `accounts` on, a fleet admin's request can add, sign in, sign out and remove Claude Code profiles that this Runtime created. The requests carry names only, travel in their own frames that AgEnD does not store, and the sign-in screen is rebuilt from a closed set of lines so only the link and the one-time code leave the computer. Sign-out also deletes the profile's `backups\.claude.json.backup*`; remove is refused while the pairing's default, a running task or terminal, or a sign-in uses the profile, and never follows a link or junction. Every request is recorded in `audit.jsonl` on that computer. Codex profiles are not offered yet.
