- **Type-checking and `npm run build` now use TypeScript 7.0.2 (#2445).** The native `tsc` is installed as `@typescript/native` (`npm:typescript@7.0.2`, the official side-by-side alias). Programmatic `import "typescript"` (tests and the CLI upstream-precheck manifest) keeps the TypeScript 6 compiler API via `@typescript/typescript6@6.0.2`. Emitted `dist/*.js` and `*.d.ts` match 5.9. The published package still does not ship `tsc`.
