- **網頁：只有一個 Fleet 入口，手機只有四個分頁（#2183）。** 側欄以前同時有 **Fleet 概覽**、**Fleet** 和**檢視**。現在：
  - 側欄的 **Fleet**（會打開目前 agent 的詳細資訊）和**檢視**兩列拿掉了。Agent 的 View、紀錄與詳細資訊是它標頭下方的分頁；
  - **Fleet 概覽**在英文介面改叫 **Fleet**（中文仍是「Fleet 概覽」）。它會打開你在這台裝置上次用的 Fleet 分頁，第一次是組織圖；
  - 手機下方的分頁是**聊天 · 待處理 · Fleet · 設定**。在 agent 的任何一頁上，目前的分頁都是**聊天**，點它會回到那個 agent 的聊天；
  - 未登入看 `/view` 的人，側欄和分頁都跟以前一樣。
