section: Changed
---
- **A signed-in admin confirms Settings changes from any device (#3486).** Pressing Apply now (or just saving) now works for every kind of change — secrets, access lists, connections, Hub changes, opening a link — from this computer, a LAN or tailnet connection, or a public link, on a chat fleet and a web-only fleet alike. It no longer needs a Discord/Telegram DM confirmation of the browser, a General card, or the AgEnD computer. Agents, guests, header tokens and paired Windows PCs still never confirm. Pages that are not the AgEnD computer no longer show the host command.
