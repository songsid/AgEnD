- **Agent 把成果放到任務卡上。** Agent 現在可以把做出來的東西以檔案掛在卡片上——`update` / `move` 的 `attach`、`attach` 動作、`agend-agent task attach M-3 檔案…`——和同一次寫入的留言放在一起，你可以在卡片上開啟、預覽、下載：圖片直接顯示，Markdown 與文字原地展開，`.html` 檔在沙盒預覽（需該裝置允許預覽），其他檔案下載。單檔上限 10 MiB，每張卡 20 個檔、合計 50 MiB。卡片的目標、範圍、背景、目前狀態、產出與卡住原因，閱讀時改用 Markdown 呈現（分行、清單、標題、程式碼區塊、連結），和留言一致。Agent 也被告知要在卡片上回報——簡短的產出、貼上內容的留言、掛上那一個成品檔（網頁原型做成單一 `.html`，不附原始碼）——而不是只給你打不開的路徑；寫入的文字若提到 Agent 本機的路徑，或一次附了一堆檔案，回覆會提醒它。舊版會忽略新增的資料。
