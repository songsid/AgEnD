- **`agend web` signs this computer's browser in on its own, and the first code lasts an hour (#3270).** The browser `agend web` opens is sent to `/signin#code=…` by a private launch file (`0600`, created with `wx` in a `0700` directory and deleted two minutes later), so the code is never on a command line another user could read (on WSL the clean address is opened and you type the code). The terminal always prints the clean address and the code, with one line for a browser that does not open the page — a Snap or Flatpak browser may not be able to read the launch file: open the address above and type the code. The page clears the fragment from the address bar before it makes any request, exchanges the code and goes straight into the dashboard — only on `localhost`, `127.0.0.1` and `[::1]`, only on a fresh navigation, and only when the browser has no session yet; if it fails, the form says so and never shows the code. A code that goes into a URL keeps its 5 minutes. The first code `agend web --code` prints to an interactive terminal before a host session has ever been authorized on this fleet (a new install; signing out or expiry does not bring it back) lasts 60 minutes from the first one: it can be redeemed from this computer only (never over the public link, from a LAN host name or through a proxy), stops working as soon as the first host session exists, and five wrong tries from this computer still spend it. After the hour every code is the ordinary 5 minutes again — run `agend web` once more. It is never given to output that is not a terminal (a pipe, a redirect, an install log, a service's journal), and never on WSL, where a Windows process counts as loopback and can read the distro's files: both keep 5 minutes. The fleet never logs a code. The sign-in breaker is unchanged.
