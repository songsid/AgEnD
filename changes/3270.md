- **`agend web` signs this computer's browser in on its own, and the first code lasts a day (#3270).** The browser `agend web` opens is sent to `/signin#code=…` by a private `0600` launch file, so the code is never on a command line another user could read (on WSL the clean address is opened and you type the code). The page clears the fragment from the address bar before it makes any request, exchanges the code and goes straight into the dashboard — only on `localhost`, `127.0.0.1` and `[::1]`, only on a fresh navigation, and only when the browser has no session yet; if it fails, the form says so and never shows the code. A code that goes into a URL keeps its 5 minutes. The first code `agend web --code` prints before a host session has ever been authorized on this fleet (a new install; signing out or expiry does not bring it back) lasts 24 hours: it can be redeemed from this computer only (never over the public link, from a LAN host name or through a proxy), stops working as soon as the first host session exists, and five wrong tries from this computer still spend it. The sign-in breaker is unchanged.
