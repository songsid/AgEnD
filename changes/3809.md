- **The web chat's activity block now works for Codex agents (#3787).** A Codex agent used to show only "Working…" while it worked; its chat now has the same block as Claude Code, Antigravity and Grok: the commands it ran (a read of one file or a search is shown as such, a failed command with its exit code), file changes, MCP calls, web searches and what it said between them, above the reply they produced. The rules are unchanged: a signed-in admin on the dashboard only, each agent's `tool_progress` decides how much, **Show thinking** stays off by default. Codex's own reasoning is encrypted and is never read or shown; only a summary the model chose to write can appear. The steps are read from the end of Codex's rollout file (never the whole file, which can be hundreds of MB), and they stay on the right reply after Codex compacts its context or restarts and keeps writing the same rollout. Codex records each tool it runs twice (as an `exec` script and as the action itself); the chat shows one step for it. In the Log tab, a turn that answered through the `reply` tool is no longer marked failed because Codex reported no final message. A transcript is now read only if it is a regular file: a symbolic link or a FIFO in its place shows no steps instead of being followed or waited on. The fixture-redaction helper for real Codex captures now also refuses one-time and authorization codes, and never prints what it refused.
