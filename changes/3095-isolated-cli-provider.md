- **Hub members can explicitly select a restricted CLI provider (#3095).** Each external question uses a disposable, unnetworked Claude Code or Codex container with a fresh home and only approved document tools. The member enforces tool and model-response gates, exact operation leases, local action proposals and teardown before releasing an answer. This experimental provider requires a reviewed local image and owner configuration; Hub features remain off by default.
