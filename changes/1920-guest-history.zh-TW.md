section: Security
---
- **網頁：訪客的聊天只顯示頻道本來就看得到的內容（#1920）。** 目前還沒有人能以訪客登入。
  - **會顯示：**
    - 在 agent 的主題或房間裡說的話；
    - agent 發到那裡的回覆；
    - 副本已送到頻道的網頁訊息；
    - 訪客自己的訊息；
    - 訪客自己的 Telegram 私人房間，則顯示全部。
  - **不會顯示：** 別人只在網頁上說的話、agent 之間的通知或 fleet 狀態訊息，以及這次更新之前留下的訊息。
  - **串流、輪詢與歷史紀錄**都依同一規則。送達勾勾只出現在訪客自己的訊息上，也不會送出任何人的帳號 id。
  - **管理者：** 每則訊息現在也會記錄它是否送到頻道、由哪個帳號所寫，其他不變。
