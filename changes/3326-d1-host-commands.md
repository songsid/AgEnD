section: Changed
---

- **The dashboard and notices no longer tell people to type a host command (#3326).** Where a same-surface path exists, the copy points there: Restart now or `/restart` in General, Settings → Accounts or `/login`, Fleet, `/update`, `/web revoke`, Sign out everywhere, or the agent's View panel. A web-only fleet never names General, and does not ask the computer's owner when the reader is that owner. Last-resort CLI stays in docs and `--help`.
