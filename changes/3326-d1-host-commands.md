section: Changed
---

- **The dashboard and notices no longer tell people to type a host command (#3326).** Where a same-surface path exists, the copy points there: Restart now when a Settings job offers it, `/restart` in General (or Restart AgEnD on a web-only hand-edit banner), Settings → Agents → AI sign-ins and API keys → Accounts or `/login`, the agent's chat menu → Start instance, `/update`, `/web revoke`, Sign out everywhere, or the buttons in General's dashboard chat. A web-only fleet never names General, and does not ask the computer's owner when the reader is that owner. An unsaved `/web revoke` warns that a restart may restore those sessions. When General itself is blocked, View shows the prompt; the dashboard cannot type the answer. Last-resort CLI stays in docs and `--help`.
