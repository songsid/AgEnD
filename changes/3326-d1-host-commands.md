section: Changed
---

- **The dashboard and notices no longer tell people to type a host command (#3326).** Where a same-surface path exists, the copy points there: Restart now or `/restart` in General, Settings → Accounts or `/login`, Fleet, `/update`, `/web revoke`, Sign out everywhere, or the agent's View panel. On a web-only fleet with no in-page path, it says to ask the computer's owner. Last-resort CLI stays in docs and `--help`.
