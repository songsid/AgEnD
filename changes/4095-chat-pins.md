- Web chat: pin messages. Right-click a message (or press and hold it on a phone) and choose Pin; the chat header shows how many are pinned (on a phone, in the ⋯ sheet) and opens the list, where a message is one click away. Pins are kept on the host for each agent (up to 50), sync across your devices, and keep a copy of the message, so a pin still opens after the message has left the chat's last 500. Admins only.
