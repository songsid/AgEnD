---
section: Changed
---
- An agent kept busy by other agents no longer looks idle. Its activity time now counts the last turn another agent started (a message, task, report or broadcast) as well as its last reply to a person. The sidebar shows one time, whichever response is newer, and its tooltip says which kind it was. Only a reply to a person highlights the row or moves it up when the list is sorted by recent replies. `agend ls`, `list_instances` and `describe_instance` show the agent side separately. A busy agent no longer reads "33 days ago".
