section: Changed
---
- An agent's activity time now shows its two sides apart: its last reply to a person, and the last turn another agent started (a message, task, report or broadcast). The sidebar shows "Person 33d · Agent 2m", with which is which in its tooltip. `agend ls`, `list_instances` and `describe_instance` add the agent side too. A busy agent no longer reads "33 days ago".
