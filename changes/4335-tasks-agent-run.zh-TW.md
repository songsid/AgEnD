- **任務卡會顯示 agent 正在做什麼，也有到它對話的入口。** 進行中的卡，只要負責 instance 正在工作，看板和清單就會標**執行中**（主任務則看它自己的某張子任務；**等你回應**和**似乎卡住**有各自的字樣）。卡片頁標題下方有一塊 **Agent 活動**：誰負責、牠的狀態，以及**開啟對話**，直接到那個 instance 的聊天頁；管理員在該 agent 的工具進度開啟時，還會即時看到牠自這張卡進行中以來正在做什麼。這個對應是推論，負責人手上只有一張進行中的卡時是準確的（預設）；有好幾張時，每張都標**忙碌中 · N 張卡**，不標執行中。時間軸會用 **Agent** 標籤標出 agent 做的事——認領、移動、紀錄、留言。這些都不另外儲存，資料庫和 API 沒有任何改動；舊版看板、看不到的 instance、關閉的步驟來源都照舊顯示。
