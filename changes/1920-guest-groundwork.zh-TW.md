section: Security
---
- **網頁：為讓非管理員以訪客身分登入打好基礎（#1920），管理員這邊完全不變。** 目前還無法發出訪客登入碼，下一步才會加入。
  - **預設拒絕：** 有訪客之後，他們只能存取一份固定的路徑清單，在 dashboard 與公開連結上都會在任何 handler 之前檢查。其他路徑一律回 403，超出訪客範圍的 instance 回 404。
  - **登出其他裝置：** 非管理員的 session 現在只會列出並登出自己的裝置；管理員的 session 仍會登出所有人。
  - **文件清楚說明誰能讀取匿名的 `/view`：** 本機的每個使用者與程式、反向代理／tailnet 分享／port 轉送所放行的對象，以及在 WSL2 上的 Windows 那一側。他們看得到每個 agent，包括即時終端。`web.view_access: session` 可以關閉它，預設值不變。
