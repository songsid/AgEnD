section: Changed
---
- **Windows runtimes are switched on in Settings → Runtime (#2953).** **Use this PC's Windows CLIs** and **Allow other Windows PCs to pair** replace setting `AGEND_WINDOWS_CLI=1` / `AGEND_REMOTE_RUNTIME=1` and restarting. Both are off by default and saved in fleet.yaml (`runtimes.windows_cli`, `runtimes.remote_runtime`). Turning one on asks a fleet admin to confirm, like other access settings; turning one off applies at once (paired PCs disconnect and keep their approvals). Neither needs a restart, and neither can be changed over the public link or by a guest. The environment variables still override them (`1` on, `0` off), and Settings shows when they do. The page explains that this machine stays the fleet and the other PC runs only a small runner, with a connection guide (Tailscale Serve recommended, an SSH tunnel as the alternative, never Funnel, no plain HTTP on a LAN). **Agents at once on each Windows PC** (`runtimes.max_agents_per_machine`, 1–16, default 4) sets the per-PC limit that long-lived Windows agents use.
