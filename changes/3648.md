- **See what an agent is doing in the chat itself (#3648).** With the Log tab on, each agent reply in the web chat has a "N steps" block above it holding what the agent did to produce it — its thinking, the text it said on the way and its tool calls (open a row for the arguments and output) — and the turn in progress grows live at the end of the thread. It is built for Claude Code and Codex instances; a step is attached to its reply by the ids the transcript already holds, and a block that had to be matched by text or time says so. Paths inside the agent's working directory are shown relative. The thinking (`web.log_thinking`, on unless you turn it off, Settings → Web dashboard) is sent only to a signed-in admin on this dashboard — never over the public link or to a guest — and, for Claude Code, needs the agent's next start (AgEnD then asks Claude Code to write thinking summaries). The chat's ⋯ menu has Show activity and Show thinking for this browser.
