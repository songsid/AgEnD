- **See what an agent is doing in the chat itself (#3648).** For a signed-in admin, each agent reply in the web chat has one block above it holding what the agent did to produce it — what it did, the text it said on the way and its tool calls (thinking too, if you turn it on) — and the turn in progress shows as one live line (current step · N tools · time so far) that opens to the steps; when the reply arrives it shrinks to "Tool history · used N tools". Each agent's own `tool_progress` decides: `off` shows nothing, `standard` each step's summary (never a command's arguments or output), `verbose` adds the command, arguments and output. Guests, the public link and read-only sessions never receive it — the server refuses the read. It is built for Claude Code instances (Codex stays as it is until a real, redacted Codex capture proves it); a step is attached to its reply by the ids the transcript already holds, and a block matched by text or time says so. Paths inside the agent's working directory are shown relative. Thinking (`web.log_thinking`, Settings → Web dashboard) is a separate switch and **off by default**; while it is off AgEnD does not touch Claude's settings, and turning it on asks Claude Code for thinking summaries at the agent's next start (which can change what a turn costs). The chat's ⋯ menu has Show activity and Show thinking for this browser.
