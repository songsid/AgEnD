- Edit and test a Hub’s AD connection from Administration → This Hub, or from this computer’s own Settings → Hub even when AD or the Hub is offline. Passwords are write-only; a changed server or CA requires fingerprint confirmation. Save uses the sealed writer, preserves the administrator’s immutable identity, refreshes the browser session after a successful change, and leaves a stopped Hub off. A stopped or uncertain Save must be checked with Reload before trying again.
