- **Level titles for every office (#3679).** A fleet admin can set the Office's level titles once for the whole fleet in Settings → Web dashboard → **Level titles for every office**: the same `{ "titles", "fixed" }` JSON as a skin pack's `levels`, checked by the same rules. Every office uses them. An office drawn in a pack with its own `levels` uses the pack's titles instead, and the pack's pinned titles win name by name. They're kept in `web-offices.json` beside the offices.
