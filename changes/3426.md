- **Rename the Hub from Hub Administration (#3426).** The Hub's administrator can change or remove the Hub's name on Administration → This Hub. Before, the name could only be changed in the host's configuration, and editing it there stopped the Hub. The Hub reseals its own settings and reloads with the new name. The same card shows the Hub ID, the member key fingerprint people compare when they pair a fleet, the issuer key and the AgEnD version.
