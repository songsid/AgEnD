- **Native Windows CLIs can run agents in the same Fleet as WSL agents.** Enable `AGEND_WINDOWS_CLI=1` on the WSL coordinator, then use Settings → Windows CLI to discover installed tools. New agent separates runtime selection, configuration and completion, with CLI product icons, model choices, an optional working directory and optional AI-assisted configuration. Codex, Claude Code, Antigravity, Grok, OpenCode and Muse have native task adapters; Kiro CLI remains detection-only. Windows agents share the ordinary Instances list, settings, chat, teams, schedules and incoming Fleet delivery. Existing native conversations migrate with their names, workspaces and resume IDs intact; chat history stays identified across restarts and reconciles earlier duplicate imports. Only local administrators can use native execution. The preview has one native execution slot, preserves each CLI's approval policy, and does not yet provide an outbound AgEnD MCP transport, terminal attachment or external channel binding. See [Windows CLI preview](../docs/windows-cli-preview.md).
