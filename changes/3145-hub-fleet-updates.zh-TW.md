- Hub：Fleet 擁有者可以允許 Hub 管理員更新自己的 Fleet（設定 → Hub，「分享的 Agent」下方：**允許這個 Hub 的管理員更新這個 Fleet**，預設關閉；手動啟動的 Fleet 不提供）。在 **管理 → 已連接的 Fleet**，落後且已允許的 Fleet 會有 **更新** 按鈕，清單上方有 **更新 *n* 個已允許的 Fleet**；每次都會先確認，一律安裝建議版本，等那個 Fleet 的 Agent 都閒置才開始，並在那一列顯示進度（等待中、更新中、已更新、已復原、已取消、沒有開始）。擁有者會在 Fleet 的 **通知** 頁看到：誰要求的、更新到哪個版本、結果如何。
