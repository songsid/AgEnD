- **「檢視」終端可以往上捲動（#2969，beta.5 撤回後重新加入）。** 用滑鼠滾輪、手指拖曳、PageUp 或「較早的輸出」往上捲，就能看到已經捲出代理終端畫面的內容（最多 2,000 行，只在你要求時讀取一次）。閱讀時，新的輸出不會把你拉回下方，而是顯示「下方有新的輸出 · 跳到最新」；捲到最下面就會再次跟著最新內容。捲動完全在你的瀏覽器中進行，用的是終端內容的唯讀副本，因此不會影響訊息傳遞。Codex、Kiro 與 Muse 會保留這些內容；會重繪整個畫面的 CLI（Claude Code、OpenCode、Grok）沒有，「檢視」會說明這一點；Claude Code 則會連到它的「紀錄」分頁（那裡有較早的輸出），或告訴你在哪裡開啟「紀錄」分頁。升級時仍開著的儀表板分頁，現在會自動重新讀取「檢視」的樣式與文字。在 beta.4，這種分頁會讓「檢視」的文字每秒縮小一點、讓 Codex 的「檢視」卡在歷史最上方，並把標籤顯示成原始鍵名（`view.earlierInLog`）。
