section: Changed

- **CLI product icons are clean vector marks with stated sources (#2934).** Grok, OpenCode and Muse use the MIT-licensed @lobehub/icons marks (Grok no longer uses an app-store image), and Antigravity uses its press-kit icon; Claude, OpenAI and Kiro keep their published marks. Single-colour marks follow the text colour in light and dark themes. Every icon is bundled — the dashboard requests no remote image — and each has a generic two-letter tile fallback behind one switch. THIRD_PARTY_NOTICES lists each mark's source and terms; the marks belong to their owners and are used only to identify the supported CLIs.
