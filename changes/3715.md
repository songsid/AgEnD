- **An agent can switch a ClassicBot room's AI account (#3715).** `update_instance_config` on a ClassicBot room now takes `config.backend_options.<backend>.credential_profile` (a name, or `null` for the fleet default), and only that. It is the room's Settings save (#3690): only that room's lines in `classicBot.yaml` change, comments and other rooms stay as they were, and the room restarts with Claude Code's conversation carried over. The answer's `launched_profile` is the account the room actually restarted on. An account that does not exist on this host or is not signed in is refused with nothing written, and so is any other key, with the same message as before. If the restart fails, the file is put back. So General can move a room to another account with one tool call instead of editing `classicBot.yaml`.
