- **側欄會把 agent 列在它的團隊底下（#2172）。** 沒有篩選時，屬於 fleet.yaml 某個團隊的 agent，以前會列在它的第一個標籤底下：例如 agend-dev 的成員因為標籤是 `wiki`，就出現在「wiki」底下。現在屬於團隊的 agent 會列在那個團隊底下（屬於好幾個團隊時列在第一個）。不屬於任何團隊的 agent 仍列在它的第一個標籤底下，ClassicBot 房間列在 **Classic**，其他列在 **其他**。團隊排在前面，每個分組標題會標出它是什麼：團隊有團隊圖示，標籤前面有 **#**。**設定 → Agents** 也這樣分組。訪客看不到團隊名稱。
