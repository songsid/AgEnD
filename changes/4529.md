section: Fixed
---
- Install and update AgEnD when npm's global folder has a UUID in its path (for example `~/.npm-<uuid>`). npm hides such a path, so the installer looked in a folder that doesn't exist, and the one-line installer fell back to `/usr/local` with sudo. They now find the real folder.
- `agend update` and the one-line installer no longer run code from the folder they were started in. Inside a project with its own `node_modules/.bin/node`, the installer used to run on that project's `node`, and the one-liner then ended with nothing installed. Both now start the installer from the filesystem root.
