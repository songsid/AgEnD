section: Fixed
---
- Claude Code 2.1.326 renamed the last option of its "resume from a summary" menu, and AgEnD stopped recognising the menu. An agent restarting an old, large session could then sit on that menu and take messages into it. AgEnD now answers it again with "Resume full session as-is", keeping the whole conversation. If the menu's wording changes again, AgEnD holds it for a person instead of answering.
- Claude Code 2.1.326 also writes its API-retry line in lower case. While Claude was retrying, an agent could look idle; it now shows as busy again.
