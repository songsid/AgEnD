- **A CLI's model list appears after you sign in, with no Refresh (#4047).** A CLI that was signed out at startup (agy: `agy models` needs the vendor) kept an empty list, so `/model` and Settings → Runtime & model showed nothing until Refresh was pressed. A finished sign-in (Settings → Accounts, chat `/login`, a paired Windows computer) now reads the account's list again, and opening `/model`, the model field or the `/backend` model step on an empty list waits for one bounded read and shows it as loading. A menu or field that is still open when a slow read ends updates in place, a read that starts before a sign-in ends is followed by one more as the signed-in account, and a profile chosen in a field is read as that profile. Opening a menu or field on the host can now start a probe worker that contacts the vendor. A named Antigravity account is still not read.
