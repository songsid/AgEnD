- **即使 Codex 自己的清單遺失了，Codex instance 也會接回之前的對話（#2963）。** 當 Codex 的 session 資料庫裡沒有這個 instance 資料夾的對話，但 Codex 的對話紀錄還在（該資料夾最新、由 Codex CLI 開始、至少有一輪對話的那段）時，AgEnD 現在會直接接回，而不是開新對話再告訴你怎麼接回。topic 會說明這件事；對話很長、Codex 可能先壓縮時也會註明。若 Codex 無法開啟它，下一次啟動會開一次新對話並說明，之後不會再自動挑這段對話。
- **`restart_instance` 可以接回指定的 Codex 對話（#2963）。** `restart_instance { name, resume_session_id }` 會讓 Codex instance 在這次重啟時接回那段對話，只限這一次。這個 id 必須是該 instance 自己、工作資料夾相同、由 Codex CLI 開始的對話；不符合就不會重啟，並在回覆中說明原因。
