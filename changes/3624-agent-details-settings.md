section: Changed
---
- **An agent's Details tab is now its "Settings" tab.** The agent's settings sit beside its read-only facts (the tab is named "Settings", like its neighbours; the ⋯ menu no longer has a second "Edit in Settings"), in categories — Overview, Basic info, Runtime & model, Workspace, Channels, Advanced — as a column on the left (tabs on a mid-width screen, a list on a phone). Each setting has an ⓘ that says what it does and when a change takes effect, and Status emojis says in plain words what they are. The ⚙ on an agent in the sidebar opens Basic info in one step; clicking the agent still opens its chat. Changes are staged and saved with the same Save bar and confirmations as Settings, and `fleet.yaml` is written exactly as before. Three agent settings the page never showed are now there: board cards at once, resume interrupted work, and the MCP proxy reply (turning the MCP proxy reply on asks you to confirm first, since it can post raw screen text to a channel). The Settings dialogs for an agent, a Windows native agent and a ClassicBot room use the same grouping.
- **The menus of Settings and of the agent page tell menu from content.** A line under the header, group titles that are plainly labels and not links, a tinted column on a wide screen, real tabs with a fade that says they scroll on a mid-width screen, and a full-width tinted "‹ Settings" bar on a phone.
