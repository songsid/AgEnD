- **登入後 CLI 的模型清單會自己出現，不用按重新整理（#4047）。** 啟動時還沒登入的 CLI（agy：`agy models` 要連廠商）會一直留著空清單，`/model` 和設定 → Runtime 與模型什麼都沒有，要手動按重新整理。現在登入完成（設定 → Accounts、聊天 `/login`、已配對的 Windows 電腦）就會重新讀該帳號的清單；在清單是空的時候打開 `/model`、模型欄位或 `/backend` 的模型步驟，會等一次有時限的讀取，並顯示「讀取中」。還開著的選單或欄位會在較慢的讀取結束時就地更新；登入前就開始的讀取，結束後會再以已登入的帳號讀一次；欄位裡選的帳號就讀那個帳號。在主機上打開選單或欄位，現在可能啟動探測 worker 並連到廠商。具名 Antigravity 帳號仍不會自動讀取。
