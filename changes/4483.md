---
section: Changed
---
- **An update is no longer tried on a machine that can't take it safely.** Before every update, from the web, chat `/update` or the Hub, AgEnD now checks this machine: it is the install npm updates, the `agend` on the fleet's PATH is that same file, it may write the install, it isn't a container or Windows, the update source answers, and the new version runs on this Node. If one of those fails, the update stops with the reason and the fix, and nothing is changed. A setup that can't bring itself back after an update (no service, lingering off) or needs an admin's hand (an `npm link`) still updates on an admin's own press, but never on its own.
