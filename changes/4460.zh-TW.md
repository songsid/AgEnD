- **建立者可以把新 agent 的工具組設到自己的等級（#4460）。** `create_instance` 與 `deploy_template` 接受不高於呼叫者自己 profile 的 `tool_set`。不能用這種方式給出 `full` 或 `general`。超過上限會被拒絕，訊息會寫明上限。沒有確認卡。新 agent 一起動就是那個 profile。經 `update_instance_config` 改既有 agent 的 `tool_set` 仍只有 General 能做。`skipPermissions` 仍然一律拒絕。General 仍可設定可寫入的 profile，也仍然不能改自己的。
