- **A failed chat `/update` now shows a short cause and logs the full output (#1818).** Before, a failing updater only reported `updater exited 1` with no other information. Now: (1) the updater's stdout and stderr are written to `$AGEND_HOME/update.log` (capped at ~400 KB across runs, masked for secrets); (2) the failure message includes a short cause extracted from the updater output — the last `npm ERR!`/`npm error` line if present, then the last `✗` line, then the last non-blank line — truncated to ~300 characters and masked; (3) the message ends with "Full log: `<path>`" so the operator knows where to look. The success, pending (exit 75) and interrupted paths are unchanged.
