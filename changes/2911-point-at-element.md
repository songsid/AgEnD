- Web chat, HTML preview panel: **Point at it** — click it, then click an element in the running page (it is outlined as you hover; Cancel pointing stops). The message box gets a reply about the page and a line naming that element (where it is and its words, marked as the page's text), for you to write what to change and send. The click, and the presses around it, are not passed to the page, and nothing is sent until you send it.
