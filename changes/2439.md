- **On macOS, a finished launchd update no longer leaves `~/.agend/service-plan.json` behind (#2439).** Once launchd already runs the planned job, the record is compare-and-deleted (same bytes as the snapshot taken before `launchctl print`). Publish, revoke and consume share one exclusive lock (holder file named by pid, so a stale reclaim cannot drop a live successor). A crash after mkdir is recovered; a missing AGEND_HOME is created through the private-home policy so `install --no-activate` still proceeds. The #2376 race stays gone.
