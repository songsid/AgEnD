section: Added
---
- **Agents put their work on the task card.** An agent can now put what it made on the card as files — `attach` on `update` and `move`, the `attach` action, `agend-agent task attach M-3 FILE…` — under the comment of the same write, and you open, preview and download them on the card: a picture is shown, Markdown and text open in place, an `.html` file previews in the sandbox (where previews are allowed), anything else downloads. Up to 10 MiB a file, 20 files and 50 MiB a card. A card's goal, scope, context, state, result and blocked reason are now read as Markdown (lines, lists, headings, code blocks, links), as comments already were. Agents are told to report on the card — a short result, the content as a comment, the one finished file attached (a web prototype as a single `.html`, not its source files) — instead of a path you cannot open, and an answer to a write that names a path on the agent's machine, or attaches a pile of files, says so. Older releases ignore the new data.
