section: Security
---
- **Web: a guest's chat now shows only what its channel already showed (#1920).** No guest can sign in yet.
  - **What it shows:**
    - messages said in the agent's topic or room;
    - the agent's replies that were posted there;
    - web messages whose copy reached the channel;
    - the guest's own messages;
    - for a guest's own Telegram private room, everything.
  - **What it never shows:** someone else's web-only messages, cross-agent notices or fleet status lines, and messages kept from before this change.
  - **Stream, poll and history** all follow the same rule. Delivery ticks appear only on the guest's own messages, and no one's account id is sent.
  - **For admins:** each message now also records whether it reached the channel and which account wrote it. Nothing else changes.
