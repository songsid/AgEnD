- **Settings → Agents → Accounts: every CLI's accounts on one page, and choosing which one an agent uses.** The old sign-in list is now one card per CLI. A card shows the default sign-in and every named account (credential profile), including one that only exists on disk. Each one shows which account it is (a masked email and the plan), whether it is signed in, which agents, ClassicBot rooms or fleet default use it, and its weekly usage. For Claude Code, Codex and Kiro there are three ways to choose an account: **Move agents here…** on an account, the new **Account** field in an agent's dialog, and each CLI's **Fleet default**. They are staged and saved like other settings, wait for a fleet admin's confirmation, and restart a running agent on its new account. Settings refuses an account that isn't signed in and shows its login command. Only a fleet admin on the dashboard reached directly sees or changes accounts. No credential reaches the browser. Fixed with it: saving an agent's backend option (such as Codex speed) no longer fails when the shared agent settings have backend options of their own.
