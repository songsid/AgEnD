- **Adding a second chat platform also offers that platform's General.** `agend quickstart` → **Add another platform** now asks whether to create a General for the new platform, such as `general-discord`. Press Enter for yes. Without one, messages there outside an agent's topic reach no one: AgEnD creates a General by itself only for the first platform. The question says what it costs, a second agent that is always running. It isn't asked for a Discord persona bot that shares an existing server, or when a General already answers on that platform. `agend doctor` now names any connection that has its own group but no General.
