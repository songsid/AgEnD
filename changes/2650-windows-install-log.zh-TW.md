- **Windows 安裝程式會留下安裝紀錄，並說明停在哪裡（#2650）。** 安裝程式畫面上說的話、長步驟裡每一行輸出，現在也會寫進 `%LOCALAPPDATA%\AgEnD\install-logs` 的紀錄檔（只留最近 10 個，每個最多 5 MB），寫之前會先遮掉設定碼、登入碼、token 和網址裡的驗證參數。第一次出錯時會說紀錄檔在哪裡。安裝停下、失敗或視窗被關掉時，你貼上指令的那個視窗會說出停在哪一步、紀錄檔在哪裡。它也會分清楚幾種情況：系統管理員確認被拒絕、被公司的安全性原則（AppLocker、WDAC）擋下、被防毒軟體攔下，或下載失敗。下載的安裝程式如果在檢查之後被換掉或刪掉，絕不會執行。沒有預料到的錯誤也會被接住並說明，不會只丟出一段 PowerShell 錯誤就結束。
