---
section: Upgrade Notes
---
- **現在需要 Node.js ^22.14.0 || ^23.6.0 || >=24。** `better-sqlite3` v13 使用 Node-API 10，此功能從 Node 22.14.0 與 23.6.0 起才提供。22.x 或 23.x 的較舊版本（以及所有 Node 20/21 版本）會在原生 DB 建構子時發生崩潰。安裝腳本與 `agend update` 現在會在嘗試安裝前拒絕不相容的 runtime。升級 AgEnD 前，請先更新至 Node.js 22.14.0 LTS（或 23.6.0+、24+）。快速安裝一行指令已透過 nvm 自動安裝目前的 LTS 版本。
- **`better-sqlite3` 升級至 v13（N-API，`^13.0.3`）。** 原生 SQLite 綁定現在直接在 npm 套件中附帶各平台的預建 N-API 二進位檔案；安裝時不再需要另外從 GitHub 下載，也不需要編譯器。預建檔案在各 Node 版本之間保持 ABI 穩定，因此在 macOS 上安裝時不再需要 Xcode Command Line Tools。
