[網頁儀表板](/AgEnD/zh-tw/docs/web-guide/)的 **Fleet → 組織圖 → 辦公室** 把你的 fleet 畫成一間小小的像素辦公室：每個 agent 是一個小人，姿勢就是它的狀態；agent 之間的訊息、委派與回報會在房間裡飛來飛去。這頁是精簡版；完整指南（含外觀包格式與所有上限）在儲存庫的[辦公室畫面](https://github.com/songsid/AgEnD/blob/main/docs/office.zh-TW.md)。

辦公室畫面在 2.3.0 推出，含辦公桌與工作室兩種風格。外觀包、溫馨、編輯配置、所有辦公室、分享連結與等級是在 2.3.2 加入的。

## 看一看

| 狀態 | 姿勢 |
|---|---|
| working | 在桌前打字 |
| idle | 喝茶休息（在工作室、溫馨或區域外觀包裡會走到休息區） |
| paused、stopped | 睡著 |
| 需要你、crashed、看起來卡住 | 舉手 |

- **移動畫面：** 拖曳平移，用滾輪或雙指縮放。「顯示整個辦公室」按鈕顯示整個場景，**填滿** 填滿面板並裁掉多出的部分。辦公室有焦點時可用 `+`、`-`、`0` 與 `f`（全螢幕）。
- **人：** 滑過會顯示名稱、狀態與 backend。點一下某個人，或在桌子清單的項目上按 Enter，會打開它的名片；雙擊會打開它的聊天。
- **辦公室工具列：** 要顯示哪間（**整個 fleet**、某間已存的辦公室，或存了兩間以上時的 **所有辦公室**）、只顯示某個 team 或大廳、釘選成員、風格，以及 **隱藏暫停與停止的成員**。
- **手機上**，場景會用上方各列下面剩下的高度，縮放按鈕排成一列放在場景上方。

## 風格與外觀包

- **辦公桌：** 每個 team 一間房，每個 agent 一張桌子。
- **工作室：** 一個有四個區域的場景（工作區、休息區、求救區、午睡角）；每個 agent 會走到符合狀態的區域。
- **溫馨：** 同類型的場景，畫在 AgEnD 內建的一張溫暖像素風房間裡。新的辦公室，以及還沒選過風格的瀏覽器，預設都用它。
- **外觀包** 是畫師的圖：一個 `manifest.json` 加上 PNG 檔。fleet 管理者在 **編輯辦公室 → 外觀包** 上傳；主機會檢查並原封不動地保存。保存的外觀包會出現在每個風格選單裡。怎麼製作請見[製作外觀包](https://github.com/songsid/AgEnD/blob/main/docs/office.zh-TW.md#製作外觀包)。

fleet 管理者為 **整個 fleet** 選的風格，就是每台裝置與每個分享連結看到的風格。其他人可以為自己的瀏覽器另選一種。

## 設定辦公室

fleet 管理者在直接連線的 dashboard 上，使用辦公室工具列的 **編輯辦公室**：

1. **新增辦公室**，取個名稱。
2. **成員：** **全部**、**指定**（整個 team 或個別 agent），或 **沒有人（只有 NPC）**：只有風格裡角色的房間。
3. **風格：** 辦公桌、工作室、溫馨或已保存的外觀包。
4. **儲存。**

fleet 上的每個人看到的是同一組辦公室。主機把它們存在 AgEnD 家目錄的 `web-offices.json`，不在 fleet.yaml 裡，所以修改不會讓任何東西重啟。

**編輯配置**（工作室、溫馨或區域外觀包）可以為一間辦公室移動座位、家具、門、信件落點與走道，把座位保留給特定 agent，並為家具設定夜間位置。外觀包本身維持上傳時的樣子。請見[安排配置](https://github.com/songsid/AgEnD/blob/main/docs/office.zh-TW.md#安排配置)。

## 分享畫面

辦公室工具列的 **分享…** 會建立一個任何人都能開啟、不需登入的連結，期限 15 分鐘到 24 小時（預設 1 小時）：可以分享 **整個 fleet**、某間辦公室或 **所有辦公室**，外觀可選淺色、深色或跟著觀看者的裝置。觀看者看到場景、名稱、身分色與狀態，每 5 秒更新——沒有聊天、設定、模型或費用。同時最多 10 個連結；在 **設定 → 存取與安全 → 辦公室分享連結** 撤銷。請見[分享畫面](https://github.com/songsid/AgEnD/blob/main/docs/office.zh-TW.md#分享畫面)。

## 等級

每個 agent 依它一生的工作量（未快取的輸入、快取寫入與輸出；快取讀取不算）有一個等級，顯示在名牌的徽章與名片上。數字來自用量報告，不會另外收集任何資料。**設定 → 網頁儀表板 → 辦公室等級** 可以關閉。請見[等級](https://github.com/songsid/AgEnD/blob/main/docs/office.zh-TW.md#等級)。

## 辦公室裡的 agent

為某個 agent 開啟 **辦公室** 儀表板功能後（`office_access: true`，沒有人設定就是關閉），它能看到自己所在的辦公室，並暫時走動、說一句短句或擺個姿勢（`office_view`、`office_set`）。另一個開關 **辦公室外觀包**（`office_pack_access: true`）讓 agent 檢查、上傳、取代、刪除與還原外觀包；預設每次變更都要等 fleet 管理者核准。請見[辦公室裡的 agent](https://github.com/songsid/AgEnD/blob/main/docs/office.zh-TW.md#辦公室裡的-agent)。

## 降版

升級後辦公室、配置與外觀包都會保留。降回 2.3.1 時每間辦公室仍會顯示，只是沒有編輯配置的修改；若配置很重要，請先備份 `web-offices.json`。請見[升級與降版](https://github.com/songsid/AgEnD/blob/main/docs/office.zh-TW.md#升級與降版)。
