# Contributing to AgEnD

[繁體中文](CONTRIBUTING.zh-TW.md)

Thank you for helping. A few pointers before you open a pull request:

- **Setup and workflow:** [docs/development.md](docs/development.md), including how to add a changelog entry under
  `changes/`.
- **Before asking for review:** [docs/dev/review-checklist.md](docs/dev/review-checklist.md).
- **Web UI changes:** follow the [web UI style guide](docs/design/ui-style-guide.md). Reviewers check UI pull requests
  against it. Attach screenshots before and after (desktop and phone, light and dark, English and Traditional Chinese)
  and name the shared component or existing section your change follows.
- **Every user-visible string** has English and Traditional Chinese (`zh-TW`) text.

The pull request template has a short checklist for these.
