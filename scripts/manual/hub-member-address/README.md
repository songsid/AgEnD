## Option B leg (#3429, M-2901)

`SCRIPT=accept-b.mts OUT=<dir> scripts/manual/hub-member-address/run.sh` replaces `accept.mts`'s option-A expectations (every Fleet revoked). It covers:
- **The Settings card** (**Settings → Hub → Fleet connection address**): show, edit and confirm in EN/zh-TW × desktop/phone × light/dark, and Check then Back changing nothing.
- **The affected surface, before/after** (Settings → Hub on the Hub's computer, EN/zh-TW × desktop/phone × light/dark): `surface-before.*` serves the base's own section, connection and strings modules (`BASE_REF`, default the merge base with `release/2.3.5-alpha`), so no card; `surface-after.*` is this tree, the card folded. **SKEW**: an old tab holds one module this change alters while the rest is new — `skew-old-section.*` (the base's `settings-hub-section.js`: no card, no error) and `skew-old-strings.*` (the base's `hub-join-one-strings.js`: the card renders, no raw key, no error). The card's own imports (`settings-confirm.js`, `settings-hub-web-address.js`, `ui-states.js`, `app.css`) are byte-identical to the base's; `receipt.skewFiles` records that.
- **Leg 1, member online** (the change confirmed through the card, in EN): it follows the issuer-signed relocation. Its credential and pairing.json are byte-identical, its relocation is confirmed, the Hub keeps the Fleet, no notice names it, and the old endpoint is refused.
- **Leg 2, member paused** (through the card, in zh-TW): it doesn't follow. The card names it, the Hub revokes it and its owner's notice names it, and the new endpoint refuses its old credential. It then re-joins as a new Fleet by the **manual pairing → explicit Disconnect / Start over → company sign-in (one-box join)** path and comes back online. This is not the existing-company **one-button Reconnect**; that path (descriptor repair, trust CAS) is covered by `tests/hub-company-join-local.test.ts` and `tests/hub-company-join-http.test.ts`.

The PNGs and `receipt.json` are in `docs/screenshots/hub-member-address-3429-b/`.

**Binding.** `run.sh` refuses a modified or untracked file (the executed source is exactly `git archive HEAD`; `ALLOW_DIRTY=1` is for a local try and lists every overlaid file) and a non-empty evidence folder. It writes `inputs` into `receipt.json`: `sourceHead`, `sourceTree`, `baseRef`, the script's and `run.sh`'s digests, `package-lock.json`, the mounted dependency tree's `node_modules/.package-lock.json`, the base modules' digests and the image ID; and `artifacts`: every PNG with its SHA-256.
