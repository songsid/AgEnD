# #1629 — personal region reference geometry

This is the host target primitive for the **already-proven actual stock shell** (Chat, Fleet, Needs, Settings, View, Log and Details). It supplies no personal selection, resource authorization, frame registry, code, event, profile or cursor renderer, and is now served for the reviewed product adapter. That adapter uses the one combined owner/Chat frame pool; these empty references consume no frame slot themselves.

- Header resolves the one direct protected `.panel-head` of the current closed stock panel; sidebar resolves the actual visible stock sidebar. Missing/duplicate/hidden/offscreen/foreign/transformed elements refuse.
- Page covers the current integer viewport. Box uses a closed manifest anchor/width/height/offset: corner offset is edge padding, center ignores offset, and an oversized box shrinks inside the available padding. No space inside the padding means no target. Viewport axes are bounded to 4096 px / 8 Mi pixels.
- Page/box have at most two empty, aria-hidden host DIV references, never mod HTML. Existing same-origin-link CSSOM geometry binds them hidden before control yields. A synchronous checked placement followed by hide provides their real bounding rectangle; they stay hidden before returning. Current actual geometry/visibility are rechecked. Stronger CSS that wins hidden/position proof physically removes that reference.
- Construction may precede the first committed panel; it creates only an empty host root. Every resolve requires one current closed panel (Chat, or the fixed marker/class pairs), a current page predicate and fresh closed stock evidence. Unknown route/proof/viewport returns null and hides synthetic references. Null means the caller must remove its descriptor before yielding; this primitive cannot remove a caller-owned effect frame. The future registry must independently enforce placement/provenance/stock proof/caps on the actual effect frame. Human front exemption does not bypass those gates.
- Disposal removes only the helper's references, root and CSS rules. Actual stock controls are never hidden or removed. No selectors, positions, URLs or HTML come from effect code.

Native controls use actual Shell/ChatPanel/CSS with inert fixture data in Chromium, Firefox and Linux WebKit at desktop/phone widths. They cover all five anchors, shrinking, actual header/sidebar, invisible reference paint, stronger visibility refusal, stale lease and cleanup without Worker/iframe/canvas. This is not a Safari or personal playback claim. The first native run reached refusal correctly but its numeric CSS-rule cleanup index moved when reference rules were removed; the recipe now removes its own host control rule by object identity.
