# AgEnD 2.3 — development preview

This page tracks the 2.3 feature branch; it does not describe 2.2 stable.

- Settings → Web appearance manages Canvas Worker effect files and saves chat or personal choices. Signed-in Chat, including authorized public/guest viewers, plays current placed effects without HTML-preview consent or its separate listener/port, with local Pause/Resume in More → Effects for dashboard sessions; public/guest Chat headers have their own browser-local show/off switch and recovery. Personal page/header/sidebar/box choices play across supported stock pages in that same pool, with slot Pause/Resume in Appearance. The host cursor uses a static image and keeps stock pointer/text/resize fallbacks, without running Worker code. Widgets are drawn by the host, never supplied HTML.
- Agents can offer Try cards. Only a signed-in admin click outside the public link (not limited to localhost) starts a clipped temporary sample; nothing is applied or saved. The click consents only to that sample; no global HTML-preview opt-in is required. Trial controls and stage are isolated from custom CSS in a closed Shadow DOM; custom CSS remains active elsewhere. Closing, navigating, blurring or opening another menu/dialog stops it.
- A chat can show a static poster behind content when Worker/transport support or the chosen motion preference prevents playback. Public viewers may read only current in-scope Chat metadata/code, never the library, personal slots, Trial or profiles; their show switch stays browser-local. Safe mode and Show off hide posters; no poster means no image. Playback starts without an FPS calibration. Reduced motion blocks only when this device chooses to follow it (off by default, shared with ambient effects); data saver is informational. A shared one-time note, local motion recovery and safe-mode exit name the active setting.
- Personal choices stay separate for each platform sign-in. Web-only host-operator sign-ins explicitly share host-wide choices. An unshared personal effect remains saved but unavailable until Clear; future resource reads are refused, while its reference is retained. Chat placements keep their separate retained-runtime policy.
- Before playback, the host must prove stock UI ordering and protected paint. Agent foreground effects stay paused while custom CSS is active, loading or unknown; their status links to Appearance. Human placements retain that agent-rule exemption. Focused inputs still withhold pointer data and stay clipped, without stopping unrelated drawing. Behind effects still need proven ordering; menus/dialogs, safe mode, caps and performance restrictions still apply.
- ClassicBot rooms now echo web chat by default (`🌐 web · <name>: …`), group channels included, following the fleet-wide `web.echo_to_channel`. **After upgrading, existing rooms that never set `web_echo` start echoing**; set `web_echo: false` in `classicBot.yaml` (or untick Web echo in the room's Settings) to keep a room quiet (#2054).

A trusted foreground/paint-containment plane is a later 2.3.x follow-up (#1940). See the [stock paint design](design/1629-stock-effect-trust.md) and [owner choices](design/1629-owner-effect-client.md) for current limits.
