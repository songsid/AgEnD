# AgEnD 2.4 新功能

[English](whats-new-2.4.md)

2.4 目前在 alpha 版本線上預覽（`2.4.0-alpha.N`）。這一頁寫給從 2.3.5 升上來的人：2.4 加了什麼、升級後有什麼不一樣。比較大的三塊是新的使用方式：在 Windows 電腦上跑 Agent（Windows Runtime）、只用瀏覽器的 Fleet（純網頁），以及 AgEnD Hub。Hub 是實驗功能，沒有打開就不會有任何變化。

## 升級前

- **從 2.3.5 改用 alpha。** 第一次請在 AgEnD 電腦上執行：

  ```bash
  agend update --alpha
  ```

  從 2.3.5 升上來是正常的升級。之後留在 alpha 版本線上，用網頁的「更新」或在 General 傳 `/update` 就好。
- **AgEnD 改用自己的 tmux。** 從 2.4 起，AgEnD 用自帶的 tmux 3.8、自己的 socket 跑 Agent，不再用電腦上安裝的 `tmux`。升級後第一次啟動時，每個 Agent 會重新啟動一次，接續原本的對話。`tmux attach` 看不到 Agent 了：請用 `agend attach <名稱>`，其他 tmux 指令用 `agend tmux <指令>`。你的 `~/.tmux.conf` 不會套用到 AgEnD 的 tmux。系統的 `tmux` 請保留：退回 2.3.5 時會用到。詳見 [AgEnD 自帶的 tmux](bundled-tmux.zh-TW.md)。
- **退回 2.3.5。** 請執行：

  ```bash
  agend rollback 2.3.5
  ```

  它會先停下 Fleet、關掉 AgEnD 自己的 tmux、確認真的關了，才安裝並啟動 2.3.5。不要用 `agend update --stable` 或直接 `npm install` 退回：AgEnD 的 tmux 可能還在跑，2.3.5 就會拒絕啟動 Agent。
- **開著的網頁分頁。** 升級前就開著的分頁，請重新整理一次。

## 聊天

### 兩個 Agent 並排（分割對話）

電腦的視窗夠寬（1200 px 以上）時，可以同時和兩個 Agent 對話。

- 在 Agent 的聊天按 **⋯ →「分割對話」**，再選第二個 Agent。或在開著某個 Agent 時，按側邊欄另一個 Agent 旁的 **⋯**，選「在旁邊開啟」。快捷鍵是 Ctrl+\（Mac 是 ⌘\）。
- 每一格都是完整的對話：有自己的輸入框，也有自己的「聊天」「檢視」「紀錄」「設定」分頁。你正在用的那一格標著「目前」，側邊欄、字級和用量按鈕都跟著它。Ctrl+Alt+\（Mac 是 Ctrl+⌘\）切到另一格。
- 每一格的 **⋯** 選單有「左右排列」或「上下排列」、「交換位置」、「切換到另一窗格」和「收起此格」。
- **引用到另一窗格。** 在一格裡選取文字，選「引用到另一窗格：*名稱*」（在「引用」旁邊）。文字會以引用的形式放進另一個 Agent 的輸入框，要你按送出才會送。
- 視窗較窄時只顯示一格，用上方的 Agent 分頁切換。上次開著的兩個 Agent 會被記住。

### 推理強度

- **強度標籤一律顯示。** CLI 有強度設定的 Agent，就算沒設定，聊天標題上也會顯示強度（**auto**，也就是 CLI 自己的預設），一點就能改。
- **選項跟著模型。** 每個模型只列它接受的等級，從 CLI 自己的模型清單讀取。例如有些 Claude 模型最高只到 `high`，有些完全沒有強度設定。
- **手機上**，`/model` 的清單會在每個模型旁顯示強度。點 **›** 打開該模型的等級；選了之後，需要的話會順便換模型。
- **在設定裡。** Agent 的「設定 → Runtime 與模型」在模型下方有「推理強度」。「模型預設」代表沒有設定。執行中的 Agent 會立刻改用新的等級（Codex 會重啟 Agent 才生效）。
- **模型清單變短。** Claude Code 只列你的帳號能用的模型；1M context 的版本只在模型支援時列出。其他 CLI 先列「常用」，再列「更多模型」。

### 聊天的其他改變

- Agent 開始或停止工作時，輸入框寬度不再跳動；「停止」移到輸入框上方的工作狀態列。
- **檔案與變更**（Agent 的 **⋯**）以唯讀方式顯示 Agent 的工作資料夾，以及它改過的檔案。本機的 Claude Code 或 Codex Agent 可以按「跟隨 Agent」，看它正在讀或改哪個檔案。

## Agent 與設定

- **Agent 頁改叫「設定」**（原本是「詳細資料」），**System prompt** 改叫「Agent 指示」，放在「基本資料」。**Agent 預設值**改叫「Agent 共用設定」。
- **導出 Agent，或從檔案建立。** 在 Agent 的「設定 → 基本資料」、「Agent 指示」旁邊：「導出」把這個 Agent 的設定（描述、標籤、指示、模型、工具組、行為）寫成一個可以分享的檔案。「載入範本」讀這種檔案，先列出會填入什麼、略過什麼，再填進表單；你仍要按「儲存」。帳號、資料夾、頻道 ID、API key 和權限一律不會寫進檔案。詳見 [導出 Agent 設定與載入範本](features.zh-TW.md#導出-agent-設定與載入範本)。
- **新增 Agent 時選帳號。** 在這台電腦上建立 Agent 時，「帳號」欄位決定它從第一次啟動起用哪個已登入的帳號。

## AI 帳號

「設定 → Agent → AI 帳號與金鑰」每個 CLI 一張卡，列出這台電腦上的所有帳號。

- **新增、移除、登出。** 「＋ 新增帳號」建立具名帳號並開始登入。「撤銷連接」用 CLI 自己的登出指令登出。「移除」刪除帳號。每個帳號都會顯示哪些 Agent 和 ClassicBot 房間在用它。
- **選帳號：** 在 Agent 的「帳號」欄位選；或在帳號上按「移入 Agent」，一次移好幾個。「Fleet 預設」是沒有指定帳號的 Agent 用的帳號。
- **ClassicBot 房間的帳號。** 房間的設定 →「Runtime 與模型」現在也有同樣的「帳號」欄位。儲存後，該房間會用新帳號重新啟動。`classicBot.yaml` 只改這個房間的那幾行，你的註解和其他房間都不變。「移入 Agent」也會列出房間。
- **保持連接。** 沒有 Agent 在用的帳號會慢慢失效，因為 CLI 只在執行時才會續期登入。勾選「保持連接」後，AgEnD 大約每天檢查一次，用 CLI 自己的工具續期。需要重新登入時，「等你回應」會告訴你。
- **在頁面上安裝或更新 CLI。** 沒安裝的 CLI 有「安裝」。已安裝、但比 AgEnD 檢查過的版本舊的，有「更新到 *版本*」。兩者都執行 CLI 官方的安裝程式，並固定在那個版本。**Antigravity 是例外：**它沒有固定的版本，按鈕是「更新到最新版（未經盤點）」，會安裝 Google 提供的最新版，AgEnD 沒有檢查過。會自己更新的 CLI（Muse）只顯示版本，沒有按鈕。
- **不再誤報「登入已到期」。** Claude 登入檔裡的到期日不是真正的期限，AgEnD 不再依它提醒，只有登入真的無法續期時才提醒。

## 任務看板

- **接手者停下來時，通知派工者。** 拿著卡的 Agent 如果當掉沒恢復、被暫停（登入到期、用量上限、錯誤）、看起來卡住、卡在提示上 10 分鐘，或 60 分鐘都沒有動靜，派出這張卡的 Agent 會收到一則訊息；接手者恢復工作時會再收到一則。你自己派出的卡會出現在「等你回應」。AgEnD 只通知，不會自動重啟或改派。時間可以在「設定 → Agent 共用設定 → 進階設定 → 接手者停下來時」調整。詳見 [接手者停下來時](features.zh-TW.md#接手者停下來時)。
- **清單、篩選、統計和卡片選單。** 「顯示」可以把專案切成看板或清單。「統計」依負責人、狀態、優先度或大小計算卡片數。在卡片上按右鍵會出現它的選單。
- **Agent 可以建立專案**，也能把主任務移到別的專案。

## 純網頁 Fleet 與登入

沒有連接 Discord 或 Telegram 的 Fleet，現在所有事都能在瀏覽器裡完成。

- **從外面使用。** 在 AgEnD 電腦上打開「設定 → 存取與安全 → 擁有者驗證」，設定一個驗證器 App（Google Authenticator、Microsoft Authenticator，或其他會顯示 6 位數驗證碼的 App），再打開「允許從外面連線」。公開連結就會開啟，從那裡登入時要輸入 App 上的驗證碼。
- **純網頁 Fleet 也可以有 General。** 在某個 Agent 的設定裡勾選 **General**。
- **只輸入驗證碼就能登入。** 在新的瀏覽器上，輸入你自己驗證器 App 的 6 位數驗證碼，不用輸入名稱。有聊天連接的 Fleet 也可以用，每個設定了 App 的管理員都能用。
- **用其他裝置登入。** 新裝置的登入頁可以顯示一組 8 個字元的碼，在已登入的裝置上到「裝置與登入 →新增裝置」核准。登入頁只有一個輸入框，兩種碼都能輸入。
- **在任何裝置上確認變更。** 已登入的管理員按「立即套用」，就能從任何裝置確認需要確認的設定變更，包括公開連結。每個管理員都可以打開自己的開關：不在 AgEnD 電腦上確認時，要輸入自己的驗證碼。
- **「存取與安全」一打開是總覽：** 誰登入了（可以把某台裝置登出）、從外面進來的方式（可以立刻關掉公開連結）、你的擁有者驗證，以及 Hub、Windows 電腦和 AI 帳號的連結。

## Windows 電腦（Windows Runtime）

Agent 現在可以直接在 Windows 上跑，不論是 AgEnD 這台電腦，還是其他 Windows 電腦，都和其他 Agent 在同一個 Fleet。詳見 [遠端 Windows Runtime](remote-runtime.zh-TW.md) 和 [Windows CLI 預覽](windows-cli-preview.md)。

- **在「設定 → Runtime」打開：**「使用這台電腦 Windows 上的 CLI」和「允許其他 Windows 電腦配對」。兩個預設都關閉。
- **一行指令連接電腦。** 「設定 → Runtime →連接電腦」會給一行 PowerShell 指令，只能用一次，15 分鐘內有效。貼到另一台電腦上執行（或交給那台電腦上的 AI Agent），它就會安裝 Runtime 並連接那台電腦，不需要配對碼。指令有效期間請把它當密碼保管。Runtime 連上後會在背景執行，登入 Windows 時自動重新連線。配對碼還在「手動選項」裡。
- **Windows 上的 Agent** 和其他 Agent 共用聊天、設定、團隊和排程。Claude Code 和 Codex 的 Agent 可以保有自己的 Windows 終端機和對話。General 也可以在配對的 Windows 電腦上執行。
- **那台電腦上的帳號與安裝。** 那台電腦的擁有者在電腦上允許之後，設定頁可以列出它的 Claude Code 帳號，並在那裡安裝或更新 Claude Code、Codex、OpenCode 或 Antigravity。更新會固定在 AgEnD 檢查過的版本；Antigravity 例外，會更新到最新版（未經 AgEnD 盤點）。
- **Runtime 自動更新。** 配對的 Runtime 可以從你的 AgEnD 取得更新，等閒置時才切換。

## AgEnD Hub（實驗功能，預設關閉）

Hub 讓公司裡的同仁用公司帳號（Active Directory）登入後，向彼此的 Agent 提問。沒有人用 `agend hub init` 或「設定 → Hub」建立 Hub，就不會有任何變化。Fleet 要連接 Hub，只要一個輸入框：輸入 Hub 位址，按「以公司帳號登入」。2.4.0-alpha.1 之後，Hub 管理員在一張「讓同仁加入」卡片上就能讓同仁加入：開放加入、選擇 AD 群組，再複製一句說明傳出去。加入碼之後推出。完整步驟見 [把 Fleet 連接到 Hub](hub-join.zh-TW.md)；群組權限見 [Hub 群組權限](hub-group-permissions.zh-TW.md)。

## 辦公室

- 管理員可以在「設定 → 網頁儀表板」一次設定所有辦公室的等級頭銜。
- 造型包可以讓每個角色有自己的對話泡泡台詞，也能讓閒置的人偶爾去別的區域走走。
- 辦公室工具列的「對話框」會用視覺小說風格的對話框顯示訊息（預設關閉，只限這個瀏覽器）。

## 安裝與指令

- **`agend tmux <指令>`** 在 AgEnD 自己的 tmux 上執行 tmux 指令，例如 `agend tmux ls`。
- **`agend web`** 會自動讓這台電腦的瀏覽器登入（碼和以前一樣 5 分鐘內有效）。在 WSL 上它會打開登入頁，由你輸入它印出的碼。新安裝時，在終端機（不是 WSL）用 `agend web --code` 印出的第一組碼一小時內有效，而且只能在這台電腦上使用。
- **`agend build-info`** 顯示安裝的是哪個 build。
- **桌面捷徑。** `agend shortcuts` 在 Linux 桌面上也會加上儀表板和重新啟動的捷徑。Windows 的捷徑改用 AgEnD 圖示。
- `agend rollback` 會找到管理這份安裝的 npm。安裝程式不會再被系統套件的問答卡住。

## 已知問題

- **ClassicBot 房間的帳號。** 如果你在 `classicBot.yaml` 裡把房間寫成單行（`{…}`），從設定頁存帳號時，那幾行會改寫成一般的多行格式。值和註解都會保留。
- **舊分頁。** 升級前開著的網頁分頁，可能混著新舊頁面，請重新整理一次。
