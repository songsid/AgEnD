# 把 Fleet 連接到 Hub

[English](hub-join.md)

> AgEnD Hub 是預覽版，預設關閉。公司還沒建立 Hub 之前，這一頁的內容都用不到。

Hub 讓同仁可以向彼此的 Agent 提問。每個人的 AgEnD（他的 **Fleet**）連接到公司的 Hub，大家在 Hub 上用**公司帳號**（上班用的 Active Directory 帳號）登入。

這一頁分兩部分：

- [每個人：連接你的 Fleet](#每個人連接你的-fleet)
- [Hub 管理員：讓同仁加入](#hub-管理員讓同仁加入)

## 每個人：連接你的 Fleet

你需要 Hub 管理員給你的 **Hub 位址**，例如 `hub.example.com`。管理員也可能給你一組**加入碼**，例如 `K7QF-3M9P`。

1. 在你的 AgEnD 儀表板打開「設定 → Hub」。
2. 在「Hub 位址」輸入位址。輸入 `hub.example.com` 就可以，不用加 `https://`。不需要先打開任何開關：連接時會自動打開這個 Fleet 的 Hub 成員功能。
   - **有加入碼時：**輸入位址，空一格，再輸入加入碼：`hub.example.com K7QF-3M9P`。也可以把管理員複製給你的整段訊息（「在 AgEnD「設定 → Hub」輸入 hub.example.com 和這組碼。」，下面一行是加入碼）直接貼進來，頁面會找出位址和加入碼，並顯示「已帶入加入碼。」
   - 只輸入加入碼時，會提示：「這是加入碼。請在前面加上 Hub 位址，中間空一格。」
3. 稍等一下，頁面會查詢 Hub，顯示「找到「*Hub 名稱*」。這台 Fleet 會顯示為「*名稱*」」。名稱是這台電腦的名稱，想換的話按「改名」。
4. 按「以公司帳號登入」。會開一個 Hub 的新分頁，在那裡用公司帳號登入。如果頁面先請你確認是你本人要連接這個 Fleet，按「前往確認卡」完成確認，之後才會開啟 Hub 登入。
5. 完成後，Hub 的分頁會顯示已連接，並自己關掉。你的 Fleet 頁面會自動更新，顯示 Hub 的名稱，以及「以 *你的名字* 的公司帳號連接 · 這台 Fleet 叫「*名稱*」」。

管理員給你的連結（`https://…/join-info#…`，例如「含金鑰指紋的連結」）貼進同一個輸入框也能用。

### 連不上時

頁面會說明發生什麼事、該怎麼做。最常見的訊息：

| 訊息 | 怎麼做 |
|---|---|
| 這不是 Hub 位址。 | 只輸入位址，例如 `hub.example.com`。 |
| Hub 位址必須是 https。 | 輸入位址時不要加 `http://`。 |
| 連不上 *主機*。 | 確認位址，以及這台電腦連得到公司網路。 |
| *主機* 的憑證不受這台電腦信任。 | 沒有連接任何東西。請向 Hub 管理員確認位址或憑證。 |
| *主機* 不是 AgEnD Hub。 | 請向 Hub 管理員確認位址。 |
| 「*Hub*」還沒開放用公司帳號連接。 | 請 Hub 管理員開啟。 |
| Hub 和這台 Fleet 的網址要用不同的主機名稱。 | Hub 和你的 AgEnD 要用不同的主機名稱，只換連接埠不行。 |
| 「*Hub*」的身分和上次不同。 | 沒有連接任何東西。先向 Hub 管理員確認，再選「更換已儲存的 Hub 身分」。 |
| 你的公司帳號沒有連接 Fleet 的權限。 | 請 Hub 管理員把你（或你所在的群組）加進來。 |
| 你連接的 Fleet 已達上限。 | 先在 Hub 撤銷你的一台 Fleet。 |
| Hub 正在處理其他連接，稍後會自動再試。 | 不用做什麼，它會自己再試。 |
| 這次連接逾時了，沒有建立任何東西。 | 再按一次「以公司帳號登入」。 |
| 你有另一個用配對碼的連接還沒完成。 | 先在 Hub 完成或停止它。 |
| 無法確認結果。 | 按「檢查這次連接」，不要重新開始。 |
| Hub 沒有接受這組加入碼… | 可能已停用或打錯，也可能你的帳號不能連接 Fleet。請向 Hub 管理員要一組有效的加入碼，再重新開始。 |
| 加入碼已失效或已用完。 | 請 Hub 管理員給你一組新的加入碼。 |
| 還有一個連接嘗試沒有結束（顯示在上方）。 | 請先按「恢復這次連接」或「取消連接」，再重新開始。 |
| 你不在這組加入碼允許的範圍。 | 這組碼只給某一個群組，而你不在裡面。請找 Hub 管理員。 |
| 目前很多人同時加入，正在排隊…（或「正在排隊…第 *n* 次重試，共 8 次。」） | 不用做什麼，Hub 分頁會自己繼續嘗試。 |

### 重新連接或移除連接

- 連接中斷時（Hub 撤銷了、過期了，或被拒絕），卡片會出現「重新連接」。按一次就會結束舊的連接，重新打開 Hub 的登入。如果 Hub 的身分變了，它會停下來告訴你，和上面一樣。
- 「移除這個連接」從你這邊結束連接。你分享的 Agent 會停止在 Hub 上回答。

### 其他方式

「其他方式」裡是舊的**配對碼**做法，給不能用公司登入的 Hub 使用。如果你把配對碼貼進 Hub 位址的輸入框，頁面會幫你打開「其他方式」並填好。那裡的開關「允許這個 Fleet 連接 Hub」一改就生效（沒有「儲存」）。

## Hub 管理員：讓同仁加入

在 Hub 上，「管理」一打開就是「讓同仁加入」卡片。還沒有任何 Fleet 連接時，你的首頁也會出現同一張卡。卡片有三個步驟，步驟 1 和 2 依 Hub 已儲存的設定標示「已完成」。

1. **允許同仁用公司帳號連接 Fleet。** 打開「允許以公司帳號連接 Fleet」。
2. **誰可以加入。** 搜尋可以連接 Fleet 的 AD 群組（輸入群組名稱的開頭），把它們加進來。每個群組可以設定「每人最多 *N* 台」，以及成員是否也能「和 Agent 對話」「分享 Agent」。按「儲存」之前，卡片會先列出這次變更的影響（誰會失去權限、哪些項目會暫停）。搜尋找不到的群組，可以用「用辨別名稱新增」加入。群組搜尋需要 Active Directory 並使用 LDAPS；如果你的目錄無法列出群組，卡片會告訴你，請在「管理」按「編輯 AD 連線」檢查，或改用個別邀請或加入碼。有效的加入碼也算完成這一步。群組的詳細說明見 [Hub 群組權限](hub-group-permissions.zh-TW.md)。
3. **告訴同仁怎麼加入。** 完成步驟 1 和 2 後，卡片會顯示一句帶有你的 Hub 位址的說明：「在 AgEnD 的「設定 → Hub」輸入 *hub.example.com*，再用公司帳號登入。」按「複製這段說明」，傳給同仁。他們照[上面的步驟](#每個人連接你的-fleet)做。[加入碼](#加入碼)也是在步驟 3 建立。

卡片下方：

- 「個別邀請」讓某一個人不在允許的群組裡也能連接。
- 「含金鑰指紋的連結（進階）」是一個也帶有 Hub 身分的連結，給需要自己核對指紋的同仁。他們把它貼進同一個 Hub 位址輸入框。

「已連接的 Fleet」清單以名稱列出每台 Fleet，下面是它的擁有者。已撤銷的收在「已撤銷（*n*）」底下。要從 Hub 這邊結束一台 Fleet 的連接，打開那一列的選單，選「撤銷…」。

### 加入碼

加入碼讓一群人一次加入，例如工作坊的所有人，不必先加群組。

1. 在卡片的步驟 3 按「建立加入碼」，選擇：
   - **有效到：**1 小時後、今天結束（預設）或 7 天後。加入碼不能延長，需要時再建立一組新的。
   - **最多幾台：**最多能用它連接幾台 Fleet，1–200（預設 30）。
   - **誰可以用：**公司目錄中的任何人，或一個公司群組（「查找群組」）。
   - 在「更多」裡設定**每人最多幾台**（預設 1，最多 8）。
2. 卡片會用大字顯示加入碼（8 個字元，`XXXX-XXXX`），以及一句說明：「在 AgEnD「設定 → Hub」輸入 *hub.example.com* 和這組碼。」按「複製」傳給同仁。他們在同一個輸入框輸入位址和加入碼：`hub.example.com K7QF-3M9P`，或直接貼上整段訊息。
3. 加入碼有效期間，卡片會顯示「已加入 *n* / *上限*」、正在連接的台數，以及「最近的連接」。如果 Hub 剩下可連接的 Fleet 數比這組碼允許的少，卡片會提醒你。
4. 「立即停用這組碼」會先問你（「停用這組加入碼？」）：這組碼將無法再使用，對話框會列出用這組碼正在連接、將會中斷的 Fleet。已經連接的 Fleet 保持連接（需要的話再一台一台撤銷）。

一個 Hub 同時最多 8 組有效的加入碼，一小時內最多建立 10 組；超過時卡片會告訴你。

- 加入碼只代替你的核准。每個人仍要在自己的 Fleet 上按「以公司帳號登入」，並在 Hub 上用自己的公司帳號登入。沒有公司帳號，加入碼就沒有用；它也不會讓任何人向 Agent 提問或分享 Agent。
- 有效的加入碼請當成會議室的鑰匙：公司裡拿到它的任何人，在它結束或用完之前，都能用自己的名義連接 Fleet。有效時間設短一點，用完就停用。
