# Hub 房間與一對一對話

> 房間是 Hub 預覽版的一部分，細節可能還會變動。

Hub 有兩種聊天：**對話**是一對一——你和一個 Agent；**房間**是幾個人加幾個
Agent。左側清單有**房間**分組（一列一個房間：
名稱第一個字、名稱、「3 人 · 12 個 Agent」）和 **Agent** 分組（一列一個
一對一對話：Agent 名稱、擁有者、狀態圓點）。**Hub 助理**排在 Agent
分組最後。**＋ 新對話**和**＋ 新房間**開始任一種；沒有開房間權限的
人看不到**＋ 新房間**。

**＋ 新房間**會問名稱（必填，最多 60 個字）、成員（搜尋人、團隊或
AD 群組）、Agent（自己的直接加入；別人的用邀請）、房間助理的開關。
**建立**後直接進入房間，第一則是「王經理 建立了這個房間。」

## @ Agent 與 @ 所有 Agent

打 `@` 請 Agent 回答。選單列出**@所有 Agent**（「12 個都會回答」；
房間可以關成只有房間管理能用）、**@房間助理**（「Hub 提供」）、
每個 Agent（名稱加上擁有者姓名與狀態圓點），以及房間裡的人（@ 人只是
提醒對方，Agent 不會因此回答）。

選了**@所有 Agent**會先預覽誰會回答：「12 個 Agent 中 9 個在線上，
3 個上線後回答」。輸入框下方固定寫著：沒有 @ 任何 Agent 的訊息只有
房間裡的人看得到，Agent 不會回答。行首的 `/` 只是一般文字，斜線指令
在這裡不適用。

有 @ Agent 的訊息下方有一行進度，會即時更新。一個 Agent 沿用熟悉的
等待 → 已送達 → 已回答。幾個 Agent 顯示「已回答 7 · 處理中 2 ·
稍後回覆 3」，全部答完變成「12 個都回答了」。回答以回覆接在這一則
底下；超過 3 則先收合，顯示「展開其餘 7 則」。沒上線的 Agent 列在
最後：「report-bot（吳小安）· 上線後回答」，它回答時補在同一串裡。
24 小時沒有回答：「沒有回答」。房間助理的回答用淡綠底色的泡泡，
底下小字「根據這個房間最近的對話」。Agent 處理時工作列顯示
「project-helper 正在處理」，不顯示工具步驟。送不出去時原因顯示在
原地，例如「這個房間只有房間管理可以 @所有 Agent。」
「你已經不在這個房間裡。」「這個房間已封存，不能再發言。」

## 誰看得到

每則訊息都顯示作者；自己的靠右，不顯示姓名。Agent 顯示
「project-helper · 林小華的 Agent」；房間助理顯示「房間助理 · Hub
提供」。成員面板的「誰看得到」寫得很白：房間裡的每個人都看得到所有
訊息與回答，Agent 被 @ 時會讀到最近的對話。

一對一對話只有你看得到——但 Agent 的擁有者看得到你問了什麼
（「這個對話只有你看得到。Agent 的擁有者看得到你問了什麼。」）。
Hub 管理員看得到房間清單，但不能直接看房間內容；加入自己成為這個房間的房間管理是唯一的辦法（房間裡會出現系統訊息）：
「這裡看不到任何房間的內容。」

## 邀請 Agent（要擁有者同意）

加別人的 Agent 會送出**邀請**：擁有者同意後才會加入。擁有者在
「邀請 · 2」那一列和「我分享的 Agent」頁面看到：「王經理 邀請你的
Agent「project-helper」加入房間「研一主管週會」——房間裡的 3 個人
可以在那裡 @ 它；它的回答房間裡的人都看得到。」按鈕是**同意**和
**不要**。同意後房間出現加入的系統訊息，Agent 頁面多一段
「在這些房間裡」，附「退出這個房間」。

邀請放 7 天沒回應就失效，房間管理看到「邀請已過期」，可以再邀一次。
擁有者暫停分享時，Agent 在所有房間顯示「暫停」，恢復後自動回來，
不用重新邀請。

## 房間助理

**房間助理**只屬於一個房間，名稱固定「房間助理」（「待命 · Hub
提供」）。被 @ 才回答，讀得到這個房間最近 30 則訊息。**@所有
Agent** 那一則底下有人回答後，進度行右邊出現「請房間助理整理」，
按了等於送出「@房間助理 整理上面的回答」。

它無法回答時圓點變黃（「暫時無法回答」），訊息下方顯示
「房間助理暫時無法回答，稍後再試。」；在別的房間忙時顯示
「房間助理正在別的房間忙，稍後回答。」一對一裡同一個助理叫
**Hub 助理**，在 Agent 分組最後：私人對話，「它讀不到你的電腦，
也讀不到其他房間。」要不要開房間助理，由你的 Hub 管理員決定。

## 誰在線上

成員面板會數人頭：「成員 · 3（線上 2）」「Agent · 12（線上 9）」，
再來是有開才有的房間助理。圓點和 Fleet 側欄同色：人是綠「線上」
／灰「離線」；Agent 是綠「待命」／藍「處理中」／黃「暫停」加原因
（「額度用完」「等待登入」「等待核准」）／灰「離線」／灰「需要更新
AgEnD」；助理是綠「待命」／藍「處理中」／黃「暫時無法回答」。
上線才回答的人顯示灰「上線時回答」，排在最後；超過 8 個 Agent
收合成「… 其餘 7 個」。點一個 Agent 顯示擁有者與狀態，動作有
「在這裡 @ 它」、「和它一對一對話」（只有被允許提問時才出現），
房間管理另有「從房間移除」。
