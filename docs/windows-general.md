# General on a paired Windows PC (alpha)

AgEnD keeps running on its coordinator host. In Settings → Shared agent settings → **Run General on**, choose an approved, online Windows PC, its detected Claude Code or Codex, and model. Save creates the existing administrator confirmation card. General must be idle. The switch stops its previous process and requires positive exit evidence before starting the selected location. The chat and administrator authority stay on the coordinator.

Host and Windows conversations stay separate. Switching does not copy or merge their history. Each Windows binding keeps its own managed workspace and saved session. **This AgEnD host** switches back through the same confirmation, resuming the saved host conversation when available. The old Windows conversation stays saved.

When the PC is offline, AgEnD answers locally with the offline explanation and lists it in Needs you. It does not send that request later or select another computer. Reconnect the PC, or use the confirmed switch-back action. Unconfirmed old input remains failed or uncertain in Needs you; it never becomes the other conversation's input.

An uncertain previous exit holds the switch. Use the existing stopped-process recovery where offered, then retry the location change. If the location was saved but startup failed, Needs you offers the same location's Start or switch-back flow. An interrupted selected switch retains its exact target, including across a coordinator restart. An older open tab must refresh after a location change; its old revision cannot stop or start anything.

General's bundled role and skills are managed files. If a managed file was edited, startup refuses and the Log names that file. Switch back to the coordinator; this alpha has no restore command or restore button. The deferred restore design is [#3023](https://github.com/songsid/AgEnD/issues/3023). AgEnD does not overwrite the edited file or touch provider credentials.
