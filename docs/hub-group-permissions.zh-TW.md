# Hub 群組權限

English: [hub-group-permissions.md](hub-group-permissions.md)

> **實驗性功能。僅限 2.3.5-alpha.8 以後的版本，預設關閉。** 群組權限讓 Hub 管理者依 Active Directory 安全性群組，決定同事登入 AgEnD Hub 後可以做什麼。管理者開啟之前，Hub 的行為和以前一樣。

目錄中的每個人仍然都能**登入** Hub。群組權限決定每個人登入後能**做**什麼：

| 權限 | 讓成員可以做什麼 |
|---|---|
| **與 Agent 對話** | 詢問擁有者分享給他的 Agent。每個人仍需要 Agent 擁有者給予存取權；光有群組權限不會開放任何 Agent。 |
| **分享 Agent** | 從自己的 Fleet 在 Hub 上分享新的 Agent，或 Agent 的新版本。每次分享仍需要擁有者本人確認。 |
| **連接 Fleet** | 自助配對自己的 AgEnD Fleet，最多到該群組設定的 **Fleet 數**（0–8）。**Fleet 數**為 0 時，即使勾選了，也不能自助配對；管理者仍可明確核准，規則如下。 |

同時屬於多個群組的人，會得到這些群組允許的所有動作；**Fleet 數**取他所屬、且允許**連接 Fleet**的群組中最大的值。列在**排除的人**中的人，會被拒絕他被排除的項目：排除優先於任何群組。

## 1. 為部門設定存取權（Hub 管理者）

### 編輯器在哪裡

群組權限需要 Hub 的目錄是**透過 LDAPS（連接埠 636）的 Active Directory**。使用其他目錄時，編輯器為唯讀，並顯示「這個 Hub 的目錄無法用於群組權限。群組權限需要透過 LDAPS（連接埠 636）的 Active Directory。」

只有 Hub 的目錄管理者能開啟。以下兩種方式都可以：

- **在 Hub 上：** 開啟側邊欄中你帳號的選單（**選單**），選擇**管理**，然後在**群組權限**卡片（標示為「實驗性」）上選擇**開啟群組權限**。
- **從你 Fleet 的 dashboard**（託管 Hub 的那個 Fleet）：**設定 → 整個 Fleet → Hub**，然後在**群組權限**卡片上選擇**在 Hub 上開啟**。會在新分頁開啟 Hub 的編輯器。

不是 Hub 管理者的人，在管理頁面會看到「只有 Hub 管理者可以查看」。如果 Hub 版本太舊、還沒有編輯器，連結會顯示「這個 Hub 還沒有群組權限。請更新 Hub 後再試。」

### 新增群組

1. 在**群組（辨別名稱）**中輸入群組的辨別名稱，例如 `CN=Hub-Members,OU=Groups,DC=example,DC=test`。
2. 選擇**新增群組**。Hub 會到你的目錄查詢這個群組（「正在查詢群組…」）。

群組必須是目錄中存在的**安全性群組**。如果不是，編輯器會直接說明：「目錄中沒有這個群組。」、「這不是安全性群組。」、「這不是辨別名稱。」或「這個群組已經在清單中。」

新加入的群組預設只有**與 Agent 對話**，**Fleet 數**為 1。視需要勾選**分享 Agent**或**連接 Fleet**。**Fleet 數**（每位成員可連接的 Fleet 數，0–8）只有在勾選**連接 Fleet**時才能修改。**移除**會把群組從清單中拿掉。

儲存之前什麼都不會改變。

### 先確認變更的影響，再儲存

只要草稿和已儲存的內容不同，編輯器就會檢查受影響的人，並顯示**這次變更的影響**（檢查中顯示「正在檢查受影響的人…」）：

| 區塊 | 意思 |
|---|---|
| **會失去目前能做的動作** | 現在能做某件事、儲存後就不能做的人。 |
| **儲存後，無法分享新的或修改過的 Agent（已分享的保留）** | 已經在 Hub 上分享的 Agent 會保留；只有新的分享與新版本會停止。 |
| **保留原狀的已分享 Agent** | 大家原本已有的項目會維持原狀：例如第一次開啟群組權限之前就已存在的一切。 |
| **這次變更會暫停** | 這次變更會暫停的 Fleet、已分享的 Agent 或對話權限（請見[暫停與恢復](#4-關閉暫停與恢復)）。 |
| **暫緩、維持不變：N 人** | 請見下方說明。 |

如果沒有人會失去任何東西，會顯示「沒有人會失去目前能做的事。」如果這次變更會讓**你自己**無法與 Agent 對話，會先警告你：「儲存後，你將無法與 Agent 對話：你不在允許對話的群組中。」

**暫緩。**「AD 沒有回報這些人的群組成員資格。現在他們不受影響：不會得到新的權限，也不會暫停他們的任何東西。下次他們操作時會再檢查一次。」暫緩的人不會讓你無法儲存。他們下次在 Hub 上操作時，Hub 會再向目錄確認，並在那時套用政策。

接著選擇**儲存**；第一次開啟時是**開啟並儲存**。看到「已儲存。」就完成了。儲存時套用的，正是檢查結果所顯示的變更：

- 如果檢查之後目錄中的群組成員資格有變，Hub 會拒絕這次儲存，顯示「檢查後有東西變了，請再檢查一次。」並自動重新檢查。看過新的結果後再儲存一次。
- 如果等太久，會顯示「這次檢查已過期，請再檢查一次。」
- 如果這期間群組權限已從另一個分頁或工作階段儲存過，或 Hub 上的 Fleet 或已分享的 Agent 有變動：「有人改了群組權限。請重新載入查看他們的版本。」

## 2. 同事登入後看到什麼

同事登入後，首頁會向他打招呼（**歡迎，*姓名***——「你想做什麼？」），並顯示兩張卡片：**與 Agent 對話**與**連接你的 Fleet**。卡片的內容取決於他所屬群組允許的動作：

| 他的存取權 | 他看到的內容 |
|---|---|
| **對話與連接 Fleet** | 兩張卡片都可用。**與 Agent 對話**有**開啟對話**；**連接你的 Fleet**顯示「你的 Fleet：N / M」、Fleet 名稱欄位與**連接我的 Fleet**。舊版 Hub 或快取中的舊版頁面仍顯示向管理員索取配對碼的說明。 |
| **只有對話** | **與 Agent 對話**可用；**連接你的 Fleet**不可用，原因是「你的存取權不包含連接 Fleet。」 |
| **沒有任何權限** | 兩張都不可用：「你的帳號可以登入，但還沒有允許任何動作。」「請聯絡你的 Hub 管理員。」 |
| **已達 Fleet 上限** | 「你已連接允許的最多 Fleet 數。可以管理它們，或請 Hub 管理員增加。」 |
| **目錄沒有回應** | 「目錄沒有回應，現在無法確認。」並有**重試**。Hub 絕不會改用舊的結果。 |
| **從未開啟群組權限** | 對話和以前一樣可以使用；**連接你的 Fleet**只顯示索取配對碼的說明。 |
| **群組權限已關閉** | 兩張卡片都不可用，顯示「已被 Hub 管理員暫停。」，以及「你的帳號可以登入，但還沒有允許任何動作。」「請聯絡你的 Hub 管理員。」 |

如果還沒有人分享 Agent 給他，對話卡片會顯示「還沒有人分享 Agent 給你。需要 Agent 的擁有者給你存取權。」不可用的卡片會說明原因：「Hub 管理員已將你的帳號排除在外。」、「你的目錄帳號目前無法使用這個功能。」或「已被 Hub 管理員暫停。」

他自己的 Fleet 會列出狀態：**使用中**、**已暫停**、**已撤銷**或**目前無法確認**。

## 3. 快速配對

允許**連接 Fleet**而且還有名額時：

1. 在 Hub 首頁的 **Fleet 名稱**中輸入你和 Hub 管理員都認得的名稱，選擇**連接我的 Fleet**。Hub 會顯示**成員位址**、**一次性代碼**，以及代碼的有效期限（十分鐘）。
2. 在該 Fleet 的網頁 dashboard 開啟**設定 → 整個 Fleet → Hub**。如果 **Hub 成員功能**下的**允許這個 Fleet 連線至 Hub**是關閉的，先開啟它。這項變更需要確認（「等待擁有者確認…」）：依確認卡片上的說明，在 General 或這個 dashboard 上確認。
3. 一開啟，配對欄位就會出現在下方，不需要重新整理頁面。把成員位址填入 **Hub 位址**、代碼填入**一次性配對碼**，再選擇**連線**。如果出現本機設定確認，完成該確認。
4. Fleet 會顯示一張附有配對指紋的**等待核准**卡片，Hub 也會顯示自己的指紋。逐一比對。在 Fleet 上選擇**和 Hub 畫面上的一致**；在 Hub 上選擇**指紋相符**。如果不同，選擇**指紋不同**，確認位址後才重新開始。兩邊的確認不能互相替代。
5. Fleet 儲存釘選資訊並連上後，Hub 才顯示**已連接**。配對不會分享任何 Agent；分享仍須自己的權限與確認。有名額時可用**連接另一個 Fleet**開始下一次配對。

每個人最多只有一個待完成的自助配對。重新開始會替換配對碼，讓舊的嘗試失效。**停止配對**或過期會釋出待完成的名額。保留的 Fleet，包括手動核准與暫停的 Fleet，都會計入日後的自助配對名額。如果目錄無法確認權限，配對會暫緩，絕不使用舊權限完成。若 Fleet 顯示結果無法確定，先照該提示處理，再決定是否重試。

Hub 會為你的其他登入工作階段、Hub 管理員與你其他已連接的 Fleet 保留安全通知。離線時通知會保留待送；舊版 Fleet 更新前不會收到新訊息。通知只有 Fleet 名稱與 ID，不含配對碼或憑證。展開**較早的通知**，並用**顯示更早的通知**查看更早保留的記錄。Fleet 上的通知提供**在 Hub 查看並撤銷**；到 Hub 後仍須正常登入，連結本身不授權。在 Hub 上按一次**撤銷此 Fleet**，只會撤銷通知指定的 Fleet。

管理者仍可明確核准同事的手動配對，即使他的群組沒有開放自助配對，或暫時無法確認群組成員資格。目錄帳號仍須有效且符合資格；刻意設定的個人「連接 Fleet」排除仍會阻擋，管理者須先解除。手動核准不會授予對話、分享或自助配對權限。核准時可以超過個人的 Fleet 數上限，但已保留的手動 Fleet 會計入日後自助配對的名額，並且一律受 Hub 整體容量限制。

## 4. 關閉、暫停與恢復

- **關閉政策：** 在編輯器中選擇**關閉**，然後儲存。儲存之前，編輯器會顯示「尚未儲存」與「儲存後才會關閉；依賴它的項目會暫停。」**復原**可以取消。儲存後顯示「已關閉——資源已暫停」。

  **關閉後，依賴群組的對話、分享與自助配對都會暫停，管理者也一樣。** 明確核准的手動配對仍可進行；失去群組資格或關閉政策不會暫停手動 Fleet。個人排除、目錄帳號失去資格或撤銷仍然有效。第一次開啟群組權限之前就存在的 Fleet 與已分享的 Agent 仍會保留登記，但在你重新開啟群組權限、**並且**在**已暫停**區塊中恢復對話權限之前（見下方），**沒有人能詢問任何 Agent**。群組權限一旦開啟過，之後可以關閉，但不會回到「從未開啟」的狀態。
- **拿掉一個群組：** **移除**該群組，確認**這次變更的影響**，然後儲存。
- **恢復已暫停的項目：** 編輯器的**已暫停**區塊會列出先前由群組允許、目前暫停的項目：Fleet、已分享的 Agent 與對話權限（「先前由群組允許、目前暫停。確認仍然需要後再逐一恢復。」）。對每個仍然需要的項目選擇**恢復**（「已恢復。」）。重新開啟群組權限不會自動恢復任何東西：由你逐項決定。
- **排除某個人：** 編輯器會顯示**排除的人**；這個版本還不能從編輯器新增排除的人。

**撤銷自己的 Fleet：** 在 Hub 首頁該 Fleet 旁，或它的安全通知中，選擇**撤銷此 Fleet**。即使失去自助配對權限，只要目錄帳號仍符合資格，就仍可撤銷。操作只針對該 Fleet 目前的世代。從群組編輯器新增或撤銷某個人，仍是後續工作。
