# AgEnD 2.3 — 開發預覽

本頁記錄 2.3 功能分支，不代表 2.2 穩定版的功能。

- 設定 → 網頁外觀可以管理 Canvas Worker 效果檔案，並儲存聊天或個人選擇。已登入的聊天（含經授權的公開連結／訪客）可播放目前放置的效果，不需 HTML 預覽同意或另一個 listener／port，一般儀表板可在「更多 → 效果」本機暫停或恢復；公開連結／訪客的聊天頁首有自己的瀏覽器顯示／關閉開關與恢復操作。個人的頁面／頁首／側邊欄／區塊選擇會在支援的 stock 頁面播放，沿用同一個 pool，外觀設定提供各槽的暫停／恢復。主機游標使用靜態圖片，保留明確指定的按鈕／文字／拖曳游標，不執行 Worker 程式。Widget 由主機繪製，不接受使用者提供的 HTML。
- Agent 可以提供 Try 試播卡片，只有已登入非公開 dashboard 的管理員明確點擊（不限 localhost）才會在裁切區塊內暫時播放，不會套用或儲存。點擊只同意本次試播，不需另開全域 HTML 預覽；試播控制與舞台以封閉的 Shadow DOM 隔離自訂 CSS，其他區域的自訂 CSS 照常啟用；關閉區塊、換頁、視窗失焦或開啟其他選單／對話框都會停止。
- Worker／隔離框架不支援，或動態／節省數據設定禁止播放時，聊天可在內容後方顯示靜態封面。公開檢視者只能讀取其可查看聊天中目前放置的效果 metadata／程式碼，不會取得效果庫、個人槽、Try 或 profile 權限；顯示開關保存在其瀏覽器。安全模式與關閉顯示會隱藏封面，沒有封面就不顯示圖片。系統減少動態效果、節省數據與兩秒基準仍然適用，待 #2118 下一項變更調整。
- 不同平台登入的個人選擇各自獨立；網頁專用的主機操作者登入，則明確共用主機選擇。個人效果取消共享後，選擇會保留為無法使用，直到使用者清除；後續資源讀取會被拒絕，參照仍會保留。聊天放置維持各自的保留執行政策。
- 播放前，主機必須確認原有介面的繪製順序與受保護區域。自訂 CSS 啟用、載入中或狀態不明時，agent 的前景效果會暫停，狀態提供前往外觀設定的入口；人類放置仍保留這項 agent 規則的例外。輸入框取得焦點時仍會停止指標資料，並保持挖除，不再停止其他區域繪製。背景效果仍須確認順序，選單／對話框、安全模式、數量及效能限制也仍適用。
- ClassicBot 聊天室現在預設會同步 web chat（`🌐 web · <名字>: …`），群組頻道也一樣，並依照全 fleet 的 `web.echo_to_channel`。**升級後，原本沒有設定 `web_echo` 的聊天室會開始同步**；要讓某個聊天室保持安靜，請在 `classicBot.yaml` 設定 `web_echo: false`（或在該聊天室的 Settings 取消勾選「Web 同步」）（#2054）。

受信任的前景平面／繪製隔離留待 2.3.x 後續處理（#1940）。目前限制請參閱[原有介面繪製設計](design/1629-stock-effect-trust.md)與[個人選擇](design/1629-owner-effect-client.md)。
