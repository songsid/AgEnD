# AgEnD 2.3 — 開發預覽

本頁記錄 2.3 功能分支，不代表 2.2 穩定版的功能。

- 設定 → 外觀可以管理 Canvas Worker 效果檔案，並儲存聊天或個人選擇。本機登入的聊天在同意預覽後可播放已放置的效果，並在「更多 → 效果」暫停或恢復。個人區域、游標與 Try 仍另行實作。Widget 由主機繪製，不接受使用者提供的 HTML。
- 預覽不可用、未同意預覽、動態／節流設定禁止播放或使用公開連結時，聊天可在內容後方顯示靜態封面。安全模式與顯示開關會隱藏它；沒有封面就不顯示圖片。公開連結不提供 Worker 程式碼或效果播放控制，顯示開關保存在此瀏覽器，與主機預設分開。
- 不同平台登入的個人選擇各自獨立；網頁專用的主機操作者登入，則明確共用主機選擇。個人效果取消共享後，選擇會保留為無法使用，直到使用者清除；後續資源讀取會被拒絕，參照仍會保留。聊天放置維持各自的保留執行政策。
- 播放前，主機必須確認原有介面的繪製順序與受保護區域。自訂 CSS 啟用、載入中或狀態不明時，agent 的前景效果會暫停，狀態提供前往外觀設定的入口；人類放置仍保留這項 agent 規則的例外。背景效果仍須確認順序，選單／對話框、安全模式、同意、數量及效能限制也仍適用。

受信任的前景平面／繪製隔離留待 2.3.x 後續處理（#1940）。目前限制請參閱[原有介面繪製設計](design/1629-stock-effect-trust.md)與[個人選擇](design/1629-owner-effect-client.md)。
