# AgEnD 2.2.0-alpha.1：網頁版大改版

> **這是 alpha。** 只給少數測試者，功能可能還會調整。正式版的變更紀錄請看 [CHANGELOG](../CHANGELOG.zh-TW.md) 的 `[2.2.0]` 段落。
> English: [2.2.0-alpha.1.md](2.2.0-alpha.1.md)

## 安裝與更新

alpha 有自己的 npm 通道 `@alpha`（#1259），穩定版和 beta 的使用者不會誤裝到。

- 安裝：`npm i -g @songsid/agend@alpha`
- 更新：`agend update`。已經裝了 alpha 的機器會留在 alpha，不會被換回 stable 或 beta；聊天裡的 `/update` 也一樣。
- 回到穩定版：`agend update --stable`

## 先看這裡：測試者須知

- **升級後每個人都要重新登入一次。** 舊的 cookie 不再被接受。在 Telegram／Discord 下 `/dashboard`，或在主機上執行 `agend web`，就能拿到登入頁網址和一組登入碼。
- **如果用 tunnel 把 dashboard 對外開放，請設定 `web.view_access: session`。** `/view` 的讀取預設不用登入，而 `/view` 會顯示 instance 的即時終端畫面。只在本機（loopback）使用的話，維持預設即可。
- **CSP 仍保留 `'unsafe-inline'`。** 每個面板都有 Content-Security-Policy，連線只限同源；但要等 dashboard 的 `onclick=` 改寫完，才能拿掉 `'unsafe-inline'`。
- **上傳的檔案存在 instance 的工作區 inbox**（`<AGEND_HOME>/workspaces/<instance>/inbox`），跟從 Telegram 收到的檔案放在同一個地方。附加了但 30 分鐘內沒送出的檔案會被刪除，fleet 中途重啟也一樣（#1273）。已送出的檔案保留 7 天，跟 Telegram 的檔案相同。
- **懷疑有不是你的登入？** 新的登入會通知 General topic。在 Telegram 下 `/dashboard revoke`，或在 Discord 下 `/dashboard` 並選 `action: revoke`，可以讓所有瀏覽器登出；主機上的 `agend web-token rotate` 也可以。

## 這版有什麼

### 1. 一次性登入碼，連結裡不再放憑證
- `/dashboard`（Telegram／Discord）或 `agend web` 會給你登入頁網址和一組 8 字元登入碼。登入碼只能用一次，5 分鐘內有效。
- 登入後建立伺服器端 session：12 小時後到期，閒置 2 小時也會到期；fleet 重啟後 session 仍在。
- 已登入的瀏覽器發出的每個寫入動作，都要通過 CSRF 與 Origin 檢查。（CLI 和腳本送的是 `X-Agend-Token` header，瀏覽器不會自動帶上它，所以不需要這兩項檢查。）
- 新的登入會通知 General topic（`web.notify_login: false` 可關掉）。
- 舊的 `?token=` 連結或書籤會開到登入頁，網址裡的 token 也會被清掉。
- CLI 和腳本照舊使用 `X-Agend-Token` header，不受影響。

### 2. 三個面板共用導覽列與 Session 選單
- `/ui`、`/view`、`/settings` 上方都有「Dashboard · View · Settings」。
- Session 選單會顯示：目前這台裝置、session 何時到期、其他已登入的裝置（每台可個別登出），以及「全部登出」。
- 打開 `/` 會直接進入 dashboard。

### 3. Web 聊天
- **Markdown**：標題、粗體、斜體、刪除線、`code`、程式碼區塊、清單、引用、分隔線、連結。訊息內容本身不能產生任何 HTML。
- **輸入**：可多行，Enter 送出、Shift+Enter 換行。送出失敗時文字會還給你。
- **紀錄**：重新整理頁面不會清空聊天紀錄；agent 的長回覆上限從 2,000 字提高到 16,000 字。
- **傳檔案與圖片**：用 📎、貼上或拖曳都可以。每則訊息最多 5 個檔，每個 10 MB，合計 25 MB；支援 PNG、JPEG、GIF、WebP、PDF 與文字檔。Agent 收到的方式和從 Telegram 收到相同；agent 在回覆裡附的檔案也會顯示在聊天裡。
- **送達狀態（ticks）**：◷ 排隊中、✓ 已交給 agent、✓✓ agent 已收到、! 沒送達、⊘ 被 Stop 取消。
- **「*name* is working…」與 Stop**：agent 工作中時，輸入框上方會出現這一列和 **Stop** 按鈕。Stop 的效果和 Telegram 的取消鍵、`/cancel` 相同：送 Esc 中斷 agent，並丟掉還在排隊的訊息。它不會停掉 instance 程序。
- **和 Telegram／Discord 是同一個對話。** 在 web 發的訊息會同步到 topic（顯示為 `🌐 web-user: …`）；agent 的回覆照常送到 Telegram／Discord，web 也會同時顯示。

### 4. `/view`
- 讀取預設不用登入（`web.view_access: open`）。改成 `session` 後，讀取也需要登入。
- 寫入一律需要登入：個人檔案、頭像、側欄順序都包含在內。
- 網址列與 localStorage 都不會再留著 token；舊版存在瀏覽器裡的 token 會自動清掉。

### 5. 連線
- 即時串流（SSE）靜默 15 秒或一直斷線時，自動改成每 5 秒 poll；兩種方式切換時不會漏訊息，也不會重複。這讓 Cloudflare Quick Tunnel 和會 buffer 的 proxy 也能用。
- 自動輪詢不算活動，不會延長閒置期限。斷線期間錯過的 ticks，重新連上時會補齊。

## 建議的測試路徑
1. 用 `/dashboard` 或 `agend web` 拿到網址和登入碼，輸入後進入 `/ui`。
2. 選一個 instance，送一則文字訊息，看 ticks 從 ✓ 變成 ✓✓；同時在 Telegram／Discord 確認也看得到這則。
3. 用 📎 附一張圖片送出，確認 agent 收得到。
4. 給一個比較久的任務，看到「is working…」後按 Stop。
5. 在 Session 選單看其他裝置，試個別登出、試全部登出。
6. 用沒登入的視窗開 `/view`：預期可以讀、不能改。
7. 開一個舊的 `?token=` 書籤：預期開到登入頁，而且網址裡的 token 會被清掉。
8. （如果有用 tunnel）透過 tunnel 開 dashboard，確認 SSE 不通時會自動改成輪詢。

## 設定
| 設定 | 預設 | 說明 |
|---|---|---|
| `web.view_access` | `open` | 改成 `session` 後，`/view` 的讀取也要登入 |
| `web.notify_login` | `true` | 改成 `false` 就不在 General 通知新的登入 |

## 這個 alpha 還沒有的
- 在 dashboard 上直接按 agent 的 prompt 按鈕（R6，#1261）
- 對外 gateway 模式（要等 D2 的決定）
- agent 回覆附自訂按鈕（C-2）、任務看板
- 聊天裡的 Markdown 表格與巢狀清單
- 拿掉 CSP 的 `'unsafe-inline'`
