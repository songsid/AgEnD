# 在已配對 Windows 電腦執行 General（alpha）

AgEnD 仍在原本的協調主機執行。到設定 → Agent 預設值 → **General 執行位置**，選擇已核准且在線的 Windows 電腦、已偵測的 Claude Code 或 Codex，以及模型。儲存後使用既有的管理員確認卡。General 必須閒置；切換會先停止原程序，確認確實結束後才啟動所選位置。聊天和管理員權限仍由協調主機處理。

主機與 Windows 各自保留對話，切換時不會複製或合併對話紀錄。每個 Windows 綁定保留自己的受管理工作目錄及對話。選擇「這台 AgEnD 主機」會經相同確認流程切回主機，有既有對話時便繼續；原 Windows 對話仍保留。

電腦離線時，AgEnD 會直接回覆離線說明，並列入「等你處理」，不會稍後自動傳送該請求，也不會另選電腦。可重新連線，或經確認切回主機。先前結果不明的輸入保留為失敗或不確定，不會變成另一段對話的輸入。

無法確認原程序結束時，切換會暫停。若有既有的程序停止復原操作，先完成復原，再重試執行位置切換。位置已儲存但啟動失敗時，可在「等你處理」使用相同位置的啟動或切回流程。協調主機重新啟動後，已選定的切換仍保留確切目標。切換後舊分頁須重新整理；舊版本的設定不能停止或啟動任何程序。

General 的內建角色與技能是受管理檔案。若遭修改，啟動會拒絕，Log 會指明檔名。可切回協調主機；此 alpha 沒有還原指令或按鈕，還原設計留在 [#3023](https://github.com/songsid/AgEnD/issues/3023)。AgEnD 不會覆寫被修改的檔案，也不會觸碰供應商憑證。
